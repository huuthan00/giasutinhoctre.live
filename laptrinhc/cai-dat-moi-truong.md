# Cai dat moi truong hoc C++

## Lua chon de day

Goi y dung mot trong hai cach sau:

1. De bat dau nhanh: dung trinh bien dich online trong 1-2 buoi dau.
2. De hoc nghiem tuc: cai VS Code va trinh bien dich C++ tren may.

Neu lop co nhieu may tinh khac nhau, giao vien nen chuan bi truoc moi truong va kiem tra bang mot file `main.cpp` don gian.

## Chuong trinh kiem tra

Tao file `main.cpp`:

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Xin chao C++!" << endl;
    return 0;
}
```

Ket qua mong muon:

```text
Xin chao C++!
```

## Cong cu goi y

- Editor: VS Code, Code::Blocks hoac Visual Studio Community.
- Compiler: g++ hoac MSVC.
- He dieu hanh: Windows, macOS hoac Linux deu duoc.

## Quy uoc lop hoc

- Moi bai tap dat trong mot file rieng, ten file khong dau, khong khoang trang.
- Vi du: `bai01_xinchao.cpp`, `bai02_tinhdiem.cpp`.
- Moi chuong trinh phai co `main()`.
- Hoc sinh phai chay thu it nhat 3 bo du lieu truoc khi nop bai.
- Loi bien dich khong bi tru diem nang neu hoc sinh biet doc va sua dan.
