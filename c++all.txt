### Buổi 01 - Làm quen C++ và môi trường lập trình

1. Mục tiêu buổi học 

* Hiểu file `.cpp` chính là file mã nguồn của C++.


* Hiểu được quá trình cơ bản: viết code, biên dịch (compile) và chạy chương trình.


* Nắm được cấu trúc tối thiểu của một chương trình C++ gồm: `#include <iostream>`, `using namespace std`, `int main()`, `return 0`.


* Biết cách dùng `cout`, `endl`, `\n` để in thông tin ra màn hình console.


* Biết đọc và tự sửa các lỗi cơ bản như: thiếu dấu `;`, thiếu dấu ngoặc, hoặc viết sai chữ hoa/chữ thường.


* Học sinh tự viết được một chương trình in thông tin cá nhân và giải thích được từng dòng code.



2. Lý thuyết chi tiết 

* **Ngôn ngữ lập trình và Biên dịch là gì?** Máy tính không hiểu tiếng người, nó chỉ hiểu mã máy (các số 0 và 1). C++ là ngôn ngữ giúp ta viết lệnh cho máy tính đọc (lưu vào file `.cpp`). Trình biên dịch (Compiler) giống như một người phiên dịch, dịch mã C++ sang ngôn ngữ máy để máy tính chạy.


> `[📸 Hình ảnh ví dụ: Sơ đồ minh họa File .cpp -> Trình biên dịch (Bánh răng) -> File chạy .exe / Màn hình đen Console]`


* 
**Cấu trúc một chương trình C++:** Bất kỳ chương trình C++ nào cũng cần một bộ khung cơ bản.


* 
`#include <iostream>`: Khai báo thư viện giúp ta nhập và xuất dữ liệu (in chữ ra màn hình).


* 
`using namespace std;`: Sử dụng không gian tên chuẩn để không phải viết dài dòng sau này.


* `int main() { ... }`: "Cánh cửa" bắt đầu của mọi chương trình. Code của bạn sẽ viết bên trong hai dấu ngoặc nhọn `{ }` này.


* 
`return 0;`: Báo hiệu chương trình đã kết thúc thành công.




* **In chữ ra màn hình:** Dùng lệnh `cout << "Nội dung cần in";`. Để xuống dòng, ta có thể thêm `\n` vào trong ngoặc kép hoặc dùng `<< endl` ở cuối.


> `[📸 Hình ảnh ví dụ: So sánh màn hình console khi có lệnh endl và khi không có lệnh endl]`


* **Các lỗi thường gặp (Lỗi cú pháp):** Máy tính rất nghiêm khắc. Nếu bạn quên dấu chấm phẩy `;` ở cuối lệnh, quên ngoặc `}`, hay viết `Cout` thay vì `cout` (C++ phân biệt chữ hoa, chữ thường), chương trình sẽ báo lỗi (chữ màu đỏ).

### Buổi 02 - Nhập dữ liệu, biến và kiểu dữ liệu

1. Mục tiêu buổi học 

* Hiểu "Biến" là nơi lưu trữ dữ liệu tạm thời trong chương trình.


* Biết cách khai báo và sử dụng các kiểu dữ liệu cơ bản: `int`, `double`, `char`, `string`, `bool`.


* Biết dùng lệnh `cin` để nhập số và `getline` để nhập chuỗi có chứa khoảng trắng.


* Hiểu được lỗi kinh điển khi dùng `cin` trước `getline` (lỗi trôi lệnh) và biết cách khắc phục bằng `cin.ignore()`.


* Biết cách đặt tên biến rõ nghĩa (ví dụ: `diemToan` thay vì `a`).


* Học sinh viết được chương trình nhập thông tin học viên, sản phẩm, điểm số và in lại ra màn hình.



2. Lý thuyết chi tiết 

* **Biến là gì?** Hãy tưởng tượng máy tính có rất nhiều "chiếc hộp" để đựng đồ. Biến (Variable) chính là tên gọi của những chiếc hộp này. Bạn cần đặt tên cho hộp để nhớ nó đựng gì (quy tắc đặt tên rõ nghĩa: không có dấu tiếng Việt, không khoảng trắng, ví dụ: `tuoi`, `hoTen` thay vì `x`, `y`).


> `[📸 Hình ảnh ví dụ: Các chiếc hộp có dán nhãn tên "Tuổi" (chứa số 15), hộp "Điểm" (chứa 8.5) và hộp "Tên" (chứa chữ "Nam")]`


* 
**Các kiểu dữ liệu (Kích cỡ và loại hộp):** 


* `int`: Dành cho số nguyên (không có phần thập phân). Vd: tuổi, số lượng.
* `double`: Dành cho số thực (có phần thập phân). Vd: điểm số, tiền.
* `string`: Dành cho văn bản, chuỗi ký tự. Vd: họ tên, địa chỉ.
* `char`: Dành cho đúng 1 ký tự. Vd: 'A', 'B'.
* `bool`: Dành cho đúng/sai (`true` hoặc `false`).


* 
**Lệnh nhập dữ liệu (cin và getline):** 


* `cin >> tenBien;`: Dùng để nhập các số hoặc chữ liền nhau. (Mũi tên chỉ vào biến).
* `getline(cin, tenBien);`: Nếu họ tên có dấu cách (vd "Le Van A"), lệnh `cin` sẽ chỉ lấy được chữ "Le". Ta bắt buộc dùng `getline` để lấy cả dòng.


* **Lỗi trôi lệnh (Trôi Enter):** Khi nhập một số bằng `cin`, máy tính để lại phím "Enter" trong bộ nhớ. Nếu lệnh ngay sau đó là `getline`, nó sẽ "ăn" luôn phím Enter đó và bỏ qua việc cho bạn nhập chữ. Cách giải quyết: Kẹp lệnh `cin.ignore();` ở giữa.


> `[📸 Hình ảnh ví dụ: Minh họa bộ đệm bàn phím (Keyboard Buffer) đang kẹt phím Enter (\n) và lệnh cin.ignore() giống như cây chổi quét dọn bộ đệm]`



3. Ví dụ minh họa 

* 
**Ví dụ 1: Nhập và in số nguyên (Tuổi)** 



```cpp
#include <iostream>
using namespace std;

int main() {
    int tuoi; // Khai báo chiếc hộp tên 'tuoi' kiểu int
    cout << "Nhap tuoi cua ban: ";
    cin >> tuoi; // Chờ người dùng nhập số từ bàn phím
    cout << "Nam nay ban " << tuoi << " tuoi." << endl;
    return 0;
}

```

*Giải thích:* Dòng 5 tạo một biến `int`. Dòng 7 dùng `cin` đưa dữ liệu từ bàn phím vào hộp `tuoi`. Dòng 8 dùng `cout` kết hợp chuỗi chữ với giá trị của biến.

* 
**Ví dụ 2: Lỗi trôi lệnh và cách khắc phục** 



```cpp
#include <iostream>
#include <string> // Cần thiết khi dùng string
using namespace std;

int main() {
    int maHocSinh;
    string hoTen;
    
    cout << "Nhap ma hoc sinh (so): ";
    cin >> maHocSinh; 
    
    cin.ignore(); // QUAN TRỌNG: Xóa phím Enter thừa
    
    cout << "Nhap ho ten: ";
    getline(cin, hoTen);
    
    cout << "Hoc sinh: " << hoTen << " - Ma: " << maHocSinh << endl;
    return 0;
}

```

*Giải thích:* Ở dòng 10, người dùng nhập số rồi bấm Enter. Dòng 12 `cin.ignore()` làm nhiệm vụ xóa dấu Enter đó đi. Nhờ vậy, dòng 15 `getline` mới hoạt động đúng và cho phép nhập cả họ tên dài có khoảng trắng.

* 
**Ví dụ 3: Quản lý sản phẩm với nhiều kiểu dữ liệu** 



```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string tenSanPham;
    int soLuong;
    double giaTien; // Dùng double cho tiền tệ
    
    cout << "Ten san pham: ";
    getline(cin, tenSanPham);
    
    cout << "So luong: ";
    cin >> soLuong;
    
    cout << "Gia tien: ";
    cin >> giaTien;
    
    cout << "\n--- THONG TIN DON HANG ---\n";
    cout << "Mat hang: " << tenSanPham << endl;
    cout << "So luong: " << soLuong << " | Gia: " << giaTien << "$" << endl;
    return 0;
}

```

*Giải thích:* Chương trình trên kết hợp biến kiểu `string`, `int`, `double`. Lệnh `getline` được gọi đầu tiên nên chưa bị dính lỗi Enter, không cần `ignore()`. Biến được đặt tên rất rõ nghĩa.

### Buổi 03 - Toán tử số học và biểu thức

**1. Mục tiêu buổi học**

* Biết dùng các phép toán `+`, `-`, `*`, `/` trong các bài toán tính toán cơ bản.


* Hiểu được thứ tự ưu tiên của phép tính và vai trò quan trọng của dấu ngoặc.


* Nhận biết và phân biệt được phép chia số nguyên và chia số thực.


* Biết dùng biến trung gian để giúp đoạn code dễ đọc, dễ hiểu hơn.


* Biết cách chọn kiểu dữ liệu `double` cho các giá trị như điểm số, tiền bạc, diện tích hay những kết quả có phần lẻ.


* Học sinh tự viết được chương trình tính điểm trung bình, tính tiền hóa đơn, chu vi và diện tích.



**2. Lý thuyết chi tiết**

* 
**Các toán tử cơ bản:** Trong C++, các phép tính cộng, trừ, nhân, chia được biểu diễn bằng các ký hiệu lần lượt là `+`, `-`, `*`, `/`.


* 
**Thứ tự ưu tiên:** Giống hệt như toán học ở trường, C++ tính nhân chia trước, cộng trừ sau. Nếu muốn thay đổi thứ tự này, bắt buộc phải dùng dấu ngoặc tròn `( )`.


> `[📸 Hình ảnh ví dụ: Biểu đồ thứ tự ưu tiên phép toán - Dấu ngoặc () -> Nhân/Chia -> Cộng/Trừ]`


* 
**Lưu ý cực kỳ quan trọng về phép chia:** Trong C++, nếu bạn lấy một số nguyên chia cho một số nguyên (ví dụ 5 / 2), kết quả sẽ bị cắt bỏ phần thập phân và chỉ lấy phần nguyên (kết quả là 2). Để có kết quả là số thực (2.5), ít nhất một trong hai số phải là số thực (ví dụ 5.0 / 2), hoặc phải ép kiểu.


* 
**Dùng biến trung gian:** Thay vì viết một biểu thức tính toán dài ngoằng và phức tạp vào lệnh in `cout`, hãy tính toán rồi lưu kết quả vào một biến trung gian trước. Việc này giúp code rất dễ đọc và dễ tìm lỗi.


* 
**Lựa chọn kiểu dữ liệu:** Khi làm việc với điểm số, tính tiền, hay tính diện tích, hãy tạo thói quen sử dụng kiểu `double` vì kết quả thường sẽ có phần thập phân.



**3. Ví dụ minh họa**

* 
**Ví dụ 1: Tính chu vi và diện tích hình chữ nhật** 



```cpp
#include <iostream>
using namespace std;

int main() {
    double chieuDai = 5.5; [cite_start]// Dùng double cho diện tích [cite: 23]
    double chieuRong = 3.0;
    
    [cite_start]// Dùng biến trung gian để code dễ đọc [cite: 22]
    double chuVi = (chieuDai + chieuRong) * 2; [cite_start]// Cần dấu ngoặc để cộng trước [cite: 21]
    double dienTich = chieuDai * chieuRong; [cite_start]// Dùng toán tử * [cite: 20]
    
    cout << "Chu vi: " << chuVi << endl;
    cout << "Dien tich: " << dienTich << endl;
    
    return 0;
```

### Buổi 04 - Chia nguyên, chia dư và bài toán chẵn lẻ

**1. Mục tiêu buổi học**

* Nắm vững cơ chế phép chia nguyên `/` khi hai toán hạng đều là số nguyên.


* Hiểu cách dùng toán tử chia lấy dư `%` và ý nghĩa của phần dư.


* Biết cách kiểm tra một số là chẵn hay lẻ bằng biểu thức `n % 2`.


* Biết kiểm tra phép tính chia hết và xử lý trường hợp mẫu số bằng 0.


* Biết ứng dụng phép `/` và `%` vào các bài toán thực tế như đổi thời gian, tách chữ số, chia nhóm.


* Học sinh viết được các bài tập: xét tính chẵn lẻ, xét tính chia hết, đổi từ giây sang định dạng giờ-phút-giây.



**2. Lý thuyết chi tiết**

* 
**Phép chia nguyên (`/`):** Khi cả tử và mẫu là số nguyên (`int`), phép chia `/` chỉ giữ lại phần thương nguyên. Ví dụ: 14 / 3 = 4 (bỏ qua phần lẻ).


* 
**Phép chia lấy dư (`%`):** Toán tử `%` chỉ lấy phần dư của phép chia. Phép tính này chỉ áp dụng cho số nguyên. Ví dụ: 14 % 3 = 2 (vì 14 chia 3 được 4, dư 2).


> `[📸 Hình ảnh ví dụ: Phép tính đặt tính rồi tính thời Tiểu học, khoanh tròn vào phần "Thương" ứng với dấu /, và phần "Số dư" ứng với dấu %]`


* 
**Ứng dụng kiểm tra chẵn / lẻ:** Một số khi chia lấy dư cho 2 (`n % 2`) thì chỉ có 2 khả năng: Nếu dư 0 thì là số chẵn; nếu dư 1 thì là số lẻ.


* 
**Kiểm tra chia hết:** Số `A` chia hết cho `B` khi và chỉ khi `A % B == 0` (nghĩa là số dư bằng 0). Lưu ý, tuyệt đối không được để số chia (mẫu số) bằng 0, nếu không chương trình sẽ bị sập (crash).


* 
**Các ứng dụng kinh điển:** Phép `/` và `%` là "cặp bài trùng" để tách các con số (tách hàng chục, đơn vị) hoặc quy đổi các đại lượng (ví dụ: chia giây thành phút, giờ).

### Buổi 05 - Rẽ nhánh if/else cơ bản

**1. Mục tiêu buổi học**

* Hiểu được khái niệm điều kiện đúng/sai trong C++.


* Biết cách viết cấu trúc `if`, `if/else` để chương trình tự đưa ra quyết định.


* Nắm vững các toán tử so sánh: `==` (bằng), `!=` (khác), `>`, `<`, `>=`, `<=`.


* Biết cách "test dữ liệu biên", ví dụ khi kiểm tra điểm đậu/rớt thì phải thử ngay các mức 5.0, 6.5, 8.0 để xem code chạy đúng không.


* Biết cách tránh lỗi kinh điển: nhầm lẫn dấu `=` (gán giá trị) với dấu `==` (so sánh bằng).


* Học sinh viết được chương trình kiểm tra đậu/rớt, số dương/âm/0, và kiểm tra điểm hợp lệ.



**2. Lý thuyết chi tiết**

* **Điều kiện Đúng / Sai (Boolean):** Máy tính đưa ra quyết định dựa trên tính đúng sai. Trong C++, `true` là đúng, `false` là sai.
* **Cấu trúc `if` (Nếu):** Dùng để bảo máy tính: "Nếu điều kiện này đúng, thì hãy làm việc này".
> `[📸 Hình ảnh ví dụ: Sơ đồ khối (Flowchart) của lệnh if: Đường đi qua một trạm kiểm soát, nếu vé hợp lệ (Đúng) thì barrier mở cho đi qua, nếu không (Sai) thì đi đường vòng]`


* **Cấu trúc `if/else` (Nếu... ngược lại thì...):** Dùng khi ta có 2 ngã rẽ. "Nếu đúng thì làm A, ngược lại thì làm B".
* **Các toán tử so sánh:** Lớn hơn (`>`), Nhỏ hơn (`<`), Lớn hơn hoặc bằng (`>=`), Nhỏ hơn hoặc bằng (`<=`), Khác nhau (`!=`).
* **Lưu ý CỰC KỲ QUAN TRỌNG:** Dấu `=` dùng để cất đồ vào hộp (gán giá trị). Dấu `==` mới là phép so sánh xem hai bên có bằng nhau hay không. Học sinh rất hay viết sai thành `if (diem = 10)` thay vì `if (diem == 10)`.

### Buổi 06 - else-if, switch và điều kiện nhiều nhánh

**1. Mục tiêu buổi học**

* Hiểu được khi nào cần dùng `else-if` để phân loại nhiều mức độ khác nhau.


* Biết cách sắp xếp các điều kiện một cách logic, từ chặt đến lỏng hoặc từ cao xuống thấp.


* Biết sử dụng cấu trúc `switch-case` để làm các menu lựa chọn rời rạc.


* Nắm được vai trò bắt buộc của `break` và `default` bên trong `switch`.


* Biết cách kết hợp nhiều điều kiện cùng lúc bằng `&&` (Và), `||` (Hoặc), `!` (Phủ định).


* Học sinh viết được chương trình menu máy tính đơn giản và chương trình xếp loại học lực.



**2. Lý thuyết chi tiết**

* **Cấu trúc `else if`:** Khi có nhiều hơn 2 ngã rẽ (ví dụ: Giỏi, Khá, Trung Bình, Yếu), thay vì lồng `if/else` quá nhiều, ta dùng `else if` để nối tiếp các điều kiện. Phải sắp xếp điều kiện từ cao xuống thấp để không bị bắt sai trường hợp.


* 
**Toán tử Logic:** Đôi khi ta cần kiểm tra nhiều điều kiện cùng lúc.


* `&&` (AND - Và): Cả 2 điều kiện phải cùng ĐÚNG. (VD: Điểm >= 0 VÀ Điểm <= 10).
* `||` (OR - Hoặc): Chỉ cần 1 trong 2 điều kiện ĐÚNG. (VD: Mật khẩu đúng HOẶC có vân tay).


* **Cấu trúc `switch-case`:** Chuyên dùng để làm Menu. Khi người dùng nhập vào một con số cụ thể (1, 2, 3...), `switch` sẽ nhảy thẳng đến `case` tương ứng.


* 
`break`: Đặt ở cuối mỗi `case` để "thắng" lại, ngăn không cho chạy tuột xuống các case bên dưới.


* 
`default`: Tương tự như `else`, nó sẽ chạy nếu người dùng nhập một con số không có trong bất kỳ `case` nào (ví dụ nhập 99 trong khi menu chỉ có từ 1 đến 3).




> `[📸 Hình ảnh ví dụ: Bảng Menu nhà hàng với các món số 1, 2, 3 so sánh ngang với cấu trúc Switch-Case trong code]`



**3. Ví dụ minh họa**

* 
**Ví dụ 1: Xếp loại học lực (Dùng else if từ cao xuống thấp)** 



```cpp
#include <iostream>
using namespace std;

int main() {
    double diem;
    cout << "Nhap diem trung binh: ";
    cin >> diem;
    
    // Phải sắp xếp từ cao xuống thấp
    if (diem >= 8.0) {
        cout << "Hoc luc Gioi!" << endl;
    } else if (diem >= 6.5) {
        cout << "Hoc luc Kha!" << endl;
    } else if (diem >= 5.0) {
        cout << "Hoc luc Trung Binh!" << endl;
    } else {
        cout << "Hoc luc Yeu!" << endl;
    }
    
    return 0;

```

Buổi 07 - Vòng lặp for và bài toán lặp biết trước số lần 

**1. Mục tiêu buổi học**

* Hiểu vòng lặp `for` gồm 3 phần chính: khởi tạo, điều kiện lặp, cập nhật.


* Biết dùng vòng lặp `for` khi đã biết trước số lần lặp lại của công việc.


* Biết cách áp dụng vòng lặp để giải quyết bài toán: tính tổng, đếm số lượng, in dãy số.


* Biết theo dõi sự thay đổi giá trị của biến đếm (thường là `i`) qua từng vòng lặp.


* Biết cách tránh lỗi kinh điển: lặp thiếu một lần hoặc lặp thừa một lần.


* Học sinh viết được chương trình tính tổng các số từ 1 đến n, đếm các số chẵn, in bảng cửu chương.



2. Lý thuyết chi tiết 

* **Vòng lặp là gì?** Khi bạn muốn in chữ "Xin chào" 100 lần, thay vì viết 100 dòng `cout`, bạn chỉ cần viết 1 dòng `cout` và bảo máy tính "hãy lặp lại việc này 100 lần".
* **Cấu trúc vòng lặp `for`:** Chuyên dùng khi ta **đã biết trước** số vòng cần chạy. Cú pháp gồm 3 phần nằm trong ngoặc tròn: `for (Khởi tạo; Điều kiện lặp; Bước nhảy) { ... }`.
* *Khởi tạo:* Biến đếm bắt đầu từ đâu (Ví dụ: `int i = 1;`).
* *Điều kiện lặp:* Chạy đến khi nào thì dừng (Ví dụ: `i <= 10;`).
* *Bước nhảy:* Sau mỗi vòng thì biến đếm thay đổi thế nào (Ví dụ: `i++` nghĩa là tăng `i` lên 1 đơn vị).


> `[📸 Hình ảnh ví dụ: Sơ đồ luồng (Flowchart) của vòng lặp for: Khởi tạo -> Kiểm tra điều kiện -> Thực thi thân vòng lặp -> Cập nhật bước nhảy -> Quay lại kiểm tra điều kiện]`


* **Lỗi lặp thừa / lặp thiếu (Off-by-one error):** Rất dễ nhầm lẫn giữa `<` và `<=`. Ví dụ, nếu muốn chạy từ 1 đến 10, phải dùng `i <= 10`. Nếu dùng `i < 10`, vòng lặp sẽ dừng ở 9 (bị thiếu 1 lần).


* 
**Biến đếm `i`:** `i` thường được dùng làm chữ viết tắt của "index" (chỉ số) hoặc "iterator" (biến lặp). Nó có thể tham gia trực tiếp vào việc tính toán bên trong vòng lặp.



3. Ví dụ minh họa 

* **Ví dụ 1: In dãy số từ 1 đến 5**

```cpp
#include <iostream>
using namespace std;

int main() {
    // i bắt đầu từ 1, chạy chừng nào i còn <= 5, mỗi lần tăng i thêm 1
    for (int i = 1; i <= 5; i++) {
        cout << i << " "; 
    }
    cout << "\nDa in xong!" << endl;
    return 0;
}

```

*Giải thích:* Máy tính tạo biến `i = 1`. Thấy `1 <= 5` là đúng, nó in số 1. Sau đó `i++` làm `i` thành 2. Lại kiểm tra `2 <= 5`, đúng, in số 2. Lặp liên tục đến khi `i = 6`, điều kiện `6 <= 5` sai, vòng lặp lập tức kết thúc.

* **Ví dụ 2: Tính tổng các số từ 1 đến N**

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    int tong = 0; // Luôn phải khởi tạo tổng = 0 trước khi cộng dồn
    
    cout << "Nhap n: ";
    cin >> n;
    
    for (int i = 1; i <= n; i++) {
        tong = tong + i; // Cộng dồn giá trị của i vào tổng
    }
    
    cout << "Tong tu 1 den " << n << " la: " << tong << endl;
    return 0;
}

```

*Giải thích:* Nếu `n = 3`, vòng lặp chạy 3 lần. Vòng 1: `tong = 0 + 1 = 1`. Vòng 2: `tong = 1 + 2 = 3`. Vòng 3: `tong = 3 + 3 = 6`. Đây là kỹ thuật "cộng dồn" cực kỳ phổ biến.

* **Ví dụ 3: In bảng cửu chương**

```cpp
#include <iostream>
using namespace std;

int main() {
    int so;
    cout << "Ban muon xem bang cuu chuong may? (1-10): ";
    cin >> so;
    
    cout << "--- BANG CUU CHUONG " << so << " ---" << endl;
    for (int i = 1; i <= 10; i++) {
        cout << so << " x " << i << " = " << so * i << endl;
    }
    
    return 0;
}

```

*Giải thích:* Vòng lặp chạy cố định 10 lần (từ 1 đến 10). Lệnh `cout` kết hợp biến `so` (cố định) và biến `i` (tăng dần) để in ra các dòng phép tính đẹp mắt.

Buổi 08 - while, do-while và lặp chưa biết trước số lần 

**1. Mục tiêu buổi học**

* Hiểu được vòng lặp `while` dùng trong trường hợp ta chưa biết trước số lần lặp.


* Hiểu vòng lặp `do-while` khác biệt ở chỗ nó luôn chạy ít nhất một lần rồi mới kiểm tra điều kiện.


* Biết cách ứng dụng để lặp lại việc nhập dữ liệu cho đến khi người dùng nhập đúng.


* Biết cách viết một menu chương trình lặp lại liên tục cho đến khi người dùng chọn nút thoát.


* Biết cách tránh lỗi "vòng lặp vô hạn" (chương trình bị treo).


* Học sinh viết được chương trình bắt nhập mật khẩu, menu lặp lại, nhập điểm đến khi hợp lệ.



2. Lý thuyết chi tiết 

* **Khi nào dùng `while`?** Vòng lặp `for` dùng khi biết phải chạy bao nhiêu lần (VD: In 10 dòng). Nhưng nếu bài toán là "Bắt người dùng nhập mật khẩu đến khi nào đúng thì thôi", ta không biết họ sẽ nhập sai 1 lần, 5 lần hay 100 lần. Lúc này phải dùng `while`.
* **Cấu trúc `while` (Kiểm tra trước - Làm sau):** `while (Điều kiện) { ... }`. Nghĩa là: Chừng nào điều kiện này còn ĐÚNG, thì tiếp tục thực hiện khối lệnh bên trong.
* **Cấu trúc `do-while` (Làm trước - Kiểm tra sau):** Khối lệnh bên trong chữ `do` sẽ được chạy ngay lập tức ít nhất 1 lần. Sau đó nó mới xem xét điều kiện ở chữ `while` phía dưới. Nếu đúng thì quay lên làm tiếp.
> `[📸 Hình ảnh ví dụ: Bảng so sánh 2 luồng: while (Hỏi vé trước khi cho vào cửa) vs do-while (Cho vào ăn thử một miếng rồi mới hỏi có muốn mua vé ăn tiếp không)]`


* **Vòng lặp vô hạn (Infinite Loop):** Là lỗi nghiêm trọng khi điều kiện của vòng lặp luôn luôn đúng và không bao giờ thoát ra được. Máy tính sẽ chạy mãi mãi đến khi treo máy. Cách sửa: Phải chắc chắn có một câu lệnh bên trong vòng lặp làm thay đổi điều kiện để nó trở thành SAI.



3. Ví dụ minh họa 

* **Ví dụ 1: Nhập mật khẩu (Dùng while)**

```cpp
#include <iostream>
using namespace std;

int main() {
    int matKhau = 0; // Khởi tạo giá trị ban đầu cố tình làm sai mật khẩu
    
    // Chừng nào mật khẩu còn chưa đúng (khác 1234)
    while (matKhau != 1234) {
        cout << "Vui long nhap mat khau: ";
        cin >> matKhau;
        
        if (matKhau != 1234) {
            cout << "Sai roi! Thu lai.\n";
        }
    }
    
    cout << "Dang nhap thanh cong!" << endl;
    return 0;
}

```

*Giải thích:* Vì ta kiểm tra `while` ngay từ đầu, nên `matKhau` phải được gán một giá trị (VD: `0`) để điều kiện `0 != 1234` là đúng, giúp vòng lặp khởi động được.

* **Ví dụ 2: Nhập điểm hợp lệ (Dùng do-while)**

```cpp
#include <iostream>
using namespace std;

int main() {
    double diem;
    
    // Làm việc nhập điểm ít nhất 1 lần
    do {
        cout << "Nhap diem (tu 0 den 10): ";
        cin >> diem;
        
        if (diem < 0 || diem > 10) {
            cout << "Diem khong hop le, vui long nhap lai!\n";
        }
    } while (diem < 0 || diem > 10); // Lặp lại nếu điểm vẫn nằm ngoài khoảng
    
    cout << "Ban da nhap diem: " << diem << endl;
    return 0;
}

```

*Giải thích:* `do-while` rất hợp với bài toán "Kiểm tra dữ liệu nhập". Ta cho phép họ nhập vào (`do`) rồi mới xét xem điểm có sai không (`while`). Nếu sai thì bắt nhập lại.

* **Ví dụ 3: Menu chương trình lặp lại**

```cpp
#include <iostream>
using namespace std;

int main() {
    int chon;
    
    do {
        cout << "\n--- MENU QUAN LY ---" << endl;
        cout << "1. Xem danh sach" << endl;
        cout << "2. Them sinh vien" << endl;
        cout << "0. Thoat" << endl;
        cout << "Ban chon: ";
        cin >> chon;
        
        // Xử lý lựa chọn
        if (chon == 1) { cout << "Dang hien thi danh sach...\n"; }
        else if (chon == 2) { cout << "Dang mo tinh nang them...\n"; }
        else if (chon == 0) { cout << "Tam biet!\n"; }
        else { cout << "Nhap sai, moi nhap lai!\n"; }
        
    } while (chon != 0); // Chỉ thoát khi người dùng nhập số 0
    
    return 0;
}

```

*Giải thích:* Dùng `do-while` bọc toàn bộ menu lại. Khách hàng xài xong tính năng 1, menu lại tự động hiện ra cho đến khi họ chủ động bấm phím 0 để thoát.

### Buổi 09 - Mảng một chiều

**1. Mục tiêu buổi học**

* Hiểu mảng một chiều lưu nhiều giá trị cùng kiểu.


* Biết khai báo mảng, nhập mảng, in mảng.


* Hiểu chỉ số mảng bắt đầu từ 0.


* Biết duyệt mảng bằng for.


* Biết tính tổng, trung bình, đếm, tìm phần tử trong mảng.


* Học sinh viết được chương trình quản lý danh sách điểm hoặc danh sách số.



**2. Lý thuyết chi tiết**

* **Mảng một chiều (Array) là gì?** Hãy tưởng tượng thay vì mua 10 chiếc hộp rời rạc để đựng 10 cuốn sách (khai báo 10 biến `int`), bạn mua một cái kệ sách có 10 ngăn dính liền nhau. Mảng chính là cái kệ sách đó, giúp lưu trữ một danh sách nhiều giá trị **cùng một kiểu dữ liệu** (ví dụ: cùng là số nguyên, hoặc cùng là chuỗi).
> `[📸 Hình ảnh ví dụ: Hình ảnh 10 chiếc hộp rời rạc (Biến) đặt cạnh 1 chiếc tủ có 10 ngăn kéo đánh số thứ tự (Mảng)]`


* **Khai báo mảng:** Cú pháp: `Kiểu_dữ_liệu Tên_mảng[Số_lượng_phần_tử];`. Ví dụ: `int diem[5];` (Tạo mảng chứa 5 điểm số).
* **Chỉ số mảng (Index):** Trong lập trình, người ta đếm từ số 0. Ngăn đầu tiên của tủ đồ là ngăn số 0. Do đó, mảng có 5 phần tử thì các chỉ số lần lượt là: 0, 1, 2, 3, 4.
* **Truy cập phần tử:** Để lấy đồ hoặc cất đồ vào ngăn tủ, ta dùng dấu ngoặc vuông `[ ]`. Ví dụ: `diem[0] = 8;` (Cất số 8 vào ngăn đầu tiên).
* **Duyệt mảng bằng `for`:** Vì chỉ số mảng tăng dần từ `0` đến `n-1`, vòng lặp `for` là công cụ sinh ra để đi qua từng ngăn của mảng một cách hoàn hảo.

**3. Ví dụ minh họa**

* **Ví dụ 1: Khai báo và in mảng cơ bản**

```cpp
#include <iostream>
using namespace std;

int main() {
    // Khai báo mảng chứa 5 phần tử và gán sẵn giá trị
    int tuoi[5] = {14, 15, 15, 16, 14};
    
    // In ra phần tử đầu tiên (chỉ số 0) và cuối cùng (chỉ số 4)
    cout << "Tuoi cua ban dau tien: " << tuoi[0] << endl;
    cout << "Tuoi cua ban cuoi cung: " << tuoi[4] << endl;
    
    return 0;
}

```

*Giải thích:* Mảng `tuoi` có kích thước 5. Phần tử `tuoi[0]` chứa giá trị 14, `tuoi[4]` chứa giá trị 14. Nếu cố tình truy cập `tuoi[5]`, chương trình sẽ báo lỗi hoặc chạy sai vì vượt quá giới hạn tủ.

* **Ví dụ 2: Nhập và in danh sách điểm (Duyệt mảng)**

```cpp
#include <iostream>
using namespace std;

int main() {
    int diem[4]; // Mảng chứa 4 con điểm
    
    // Vòng lặp để nhập dữ liệu
    cout << "Nhap 4 con diem:\n";
    for (int i = 0; i < 4; i++) {
        cout << "Nhap diem thu " << i + 1 << ": ";
        cin >> diem[i];
    }
    
    // Vòng lặp để in dữ liệu
    cout << "\nDanh sach diem vua nhap la: ";
    for (int i = 0; i < 4; i++) {
        cout << diem[i] << " ";
    }
    cout << endl;
    
    return 0;
}

```

*Giải thích:* Vòng lặp `for` với biến `i` chạy từ 0 đến 3. `diem[i]` sẽ lần lượt đại diện cho `diem[0]`, `diem[1]`, `diem[2]`, `diem[3]`.

* **Ví dụ 3: Tính tổng và trung bình mảng**

```cpp
#include <iostream>
using namespace std;

int main() {
    int danhSach[5] = {5, 7, 8, 9, 6};
    double tong = 0;
    
    // Duyệt mảng để cộng dồn vào tổng
    for (int i = 0; i < 5; i++) {
        tong = tong + danhSach[i];
    }
    
    double trungBinh = tong / 5;
    cout << "Tong cac so la: " << tong << endl;
    cout << "Trung binh la: " << trungBinh << endl;
    
    return 0;
}

```

* **Bài 1:** Viết chương trình khai báo một mảng lưu trữ 5 tên môn học (kiểu `string`). Dùng vòng lặp `for` để in danh sách các môn học đó ra màn hình.
* **Bài 2:** Viết chương trình cho phép người dùng nhập vào mảng 10 số nguyên. Sau đó dùng vòng lặp đếm xem trong mảng vừa nhập có bao nhiêu số chẵn.

### Buổi 10 - Hàm cơ bản và mini game đoán số

**1. Mục tiêu buổi học**

* Hiểu hàm giúp tách chương trình thành các phần nhỏ.


* Biết khai báo hàm, gọi hàm, tham số, giá trị trả về.


* Biết viết hàm tính toán đơn giản: tổng, max, kiểm tra chẵn lẻ.


* Hiểu void và hàm có return.


* Biết tách mini game đoán số thành các hàm nhỏ.


* Học sinh viết được mini game đoán số có giới hạn số lần thử.



**2. Lý thuyết chi tiết**

* **Hàm (Function) là gì?** Hàm giống như một "nhà máy mini" bên trong chương trình. Bạn đưa nguyên liệu (Tham số) vào nhà máy, nhà máy xử lý, và trả ra thành phẩm (Giá trị trả về). Hàm giúp chia một đoạn code dài hàng trăm dòng thành các khối nhỏ gọn gàng, dễ quản lý và có thể tái sử dụng nhiều lần.
> `[📸 Hình ảnh ví dụ: Mô hình máy xay sinh tố: Nguyên liệu vào (Tham số: dâu, sữa) -> Quá trình xay (Thân hàm) -> Sản phẩm ra (Return: ly sinh tố)]`


* **Cấu trúc của hàm:** `Kiểu_trả_về Tên_hàm(Danh_sách_tham_số) { ... thân hàm ... return giá_trị; }`
* **Void và Return:**
* Hàm có kiểu trả về (ví dụ `int`, `double`): Bắt buộc phải có từ khóa `return` để ném kết quả ra ngoài. (Như việc máy xay trả ra sinh tố).
* Hàm kiểu `void`: Là hàm chỉ thực hiện một hành động (như in ra màn hình) rồi thôi, không trả về giá trị gì cả. Không cần `return`. (Như việc máy hút bụi dọn nhà xong thì tắt).


* **Gọi hàm:** Viết tên hàm kèm theo dấu ngoặc tròn `()`. Nếu có tham số thì truyền vào bên trong ngoặc. Từ buổi 1, chúng ta đã luôn code bên trong một hàm đặc biệt, đó chính là `int main()`.

**3. Ví dụ minh họa**

* **Ví dụ 1: Hàm in lời chào (Kiểu void)**

```cpp
#include <iostream>
#include <string>
using namespace std;

// Khai báo hàm void không trả về giá trị
void xinChao(string ten) {
    cout << "Xin chao " << ten << "! Chuc mot ngay tot lanh.\n";
}

int main() {
    // Gọi hàm và truyền tham số
    xinChao("Hoc Sinh"); 
    xinChao("Gemini");
    return 0;
}

```

*Giải thích:* Hàm `xinChao` nhận vào một chuỗi `ten`. Khi ta gọi hàm trong `main` hai lần với hai tên khác nhau, hàm sẽ in ra hai câu chào tương ứng mà ta không phải viết lại code `cout`.

### Buổi 11 - Mảng hai chiều và ma trận

**1. Mục tiêu buổi học**

* Hiểu mảng hai chiều lưu dữ liệu dạng bảng gồm dòng và cột.


* Biết khai báo, nhập, in mảng hai chiều.


* Biết duyệt mảng hai chiều bằng hai vòng lặp lồng nhau.


* Biết tính tổng theo dòng, theo cột.


* Biết tìm giá trị lớn nhất, nhỏ nhất trong bảng.


* Học sinh viết được chương trình xử lý bảng điểm nhiều học sinh và nhiều môn.



**2. Lý thuyết chi tiết**

* **Mảng hai chiều là gì?** Hãy nghĩ về mảng 1 chiều như một dãy nhà trên 1 con phố. Còn mảng 2 chiều chính là một tòa nhà chung cư (có nhiều tầng, mỗi tầng có nhiều phòng) hoặc giống như bảng tính Excel (có dòng và cột).
> `[📸 Hình ảnh ví dụ: Hình ảnh bảng lưới tọa độ (Lưới Excel) minh họa các ô chứa giá trị ứng với dòng (row) và cột (column)]`


* **Khai báo mảng 2 chiều:** Cú pháp: `Kiểu_dữ_liệu Tên_mảng[Số_dòng][Số_cột];`. Ví dụ: `int bangDiem[3][4];` (Tạo một bảng có 3 dòng, mỗi dòng có 4 cột).
* **Truy cập phần tử:** Ta cần 2 chỉ số để định vị, một cho dòng và một cho cột, bắt đầu từ 0. `bangDiem[0][1]` nghĩa là lấy dữ liệu ở dòng 0, cột 1.
* **Hai vòng lặp lồng nhau:** Để duyệt mảng 2 chiều, bắt buộc phải dùng 2 vòng lặp `for` lồng vào nhau. Vòng lặp ngoài kiểm soát dòng (`i`), vòng lặp trong kiểm soát cột (`j`).

**3. Ví dụ minh họa**

* **Ví dụ 1: Khai báo và in ma trận**

```cpp
#include <iostream>
using namespace std;

int main() {
    // Khai báo ma trận 2 dòng, 3 cột và gán giá trị
    int maTran[2][3] = {
        {1, 2, 3}, // Dòng 0
        {4, 5, 6}  // Dòng 1
    };
    
    // In giá trị ở dòng 1, cột 2
    cout << "Gia tri tai dong 1, cot 2: " << maTran[1][2] << endl; // In ra 6
    
    return 0;
}

```

* **Ví dụ 2: Nhập và xuất mảng 2 chiều bằng vòng lặp lồng nhau**

```cpp
#include <iostream>
using namespace std;

int main() {
    int bang[2][3]; // 2 dòng, 3 cột
    
    cout << "Nhap du lieu cho bang 2x3:\n";
    // Duyệt theo dòng (i)
    for (int i = 0; i < 2; i++) {
        // Duyệt theo cột (j)
        for (int j = 0; j < 3; j++) {
            cout << "Nhap o [" << i << "][" << j << "]: ";
            cin >> bang[i][j];
        }
    }
    
    cout << "\nBang vua nhap la:\n";
    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 3; j++) {
            cout << bang[i][j] << "\t"; // \t dùng để tạo khoảng cách như phím Tab
        }
        cout << "\n"; // Hết một dòng thì xuống dòng
    }
    
    return 0;
}

```

* **Ví dụ 3: Tính tổng bảng điểm (Nhiều học sinh, nhiều môn)**

```cpp

}

```

### Buổi 12 - Vector và danh sách linh hoạt

**1. Mục tiêu buổi học**

* Hiểu vector là danh sách có kích thước linh hoạt.


* Biết khai báo vector, push_back, size, truy cập theo chỉ số.


* Biết duyệt vector bằng for.


* Biết thêm dữ liệu khi chưa biết trước số lượng.


* Biết so sánh vector với mảng tĩnh.


* Học sinh viết được chương trình nhập danh sách điểm hoặc sản phẩm đến khi người dùng dừng lại.



**2. Lý thuyết chi tiết**

* **Giới hạn của mảng tĩnh:** Khi khai báo mảng `int diem[5];`, kích thước của nó bị khóa chết ở mức 5. Nếu có 6 học sinh nhập học, mảng này không thể phình to ra được.
* **Vector là gì?** Vector trong C++ chính là một "mảng thông minh" (Mảng động). Nó có thể tự động co giãn kích thước. Khi bạn nhét thêm dữ liệu vào, nó sẽ tự dài ra.
> `[📸 Hình ảnh ví dụ: Minh họa Mảng (Array) là một chiếc hộp nhựa cứng, so sánh với Vector là một chiếc túi cao su có thể phồng to khi nhét thêm đồ vật]`


* **Thư viện `<vector>`:** Để dùng vector, ta phải thêm `#include <vector>`.
* **Khai báo và thêm phần tử:** Cú pháp: `vector<Kiểu_dữ_liệu> Tên_vector;`. Để thêm một phần tử vào đuôi danh sách, dùng hàm đặc biệt `.push_back(giá_trị)`.
* **Kích thước vector:** Dùng `.size()` để biết hiện tại túi đang chứa bao nhiêu đồ vật.
* **Truy cập phần tử:** Giống hệt mảng tĩnh, ta vẫn dùng ngoặc vuông `[ ]`.

**3. Ví dụ minh họa**

* **Ví dụ 1: Khai báo và thao tác cơ bản với Vector**

```cpp
#include <iostream>
#include <vector> // Bắt buộc phải có thư viện này
using namespace std;

int main() {
    vector<int> danhSach; // Khai báo một vector chứa số nguyên, ban đầu trống rỗng
    
    // Thêm các số vào cuối danh sách
    danhSach.push_back(10); 
    danhSach.push_back(20);
    danhSach.push_back(30);
    
    // Số lượng phần tử hiện tại
    cout << "Kich thuoc vector: " << danhSach.size() << endl; // Sẽ in ra 3
    
    // Truy cập phần tử y như mảng
    cout << "Phan tu thu hai: " << danhSach[1] << endl; // Sẽ in ra 20
    
    return 0;
}

```

* **Ví dụ 2: Duyệt Vector bằng vòng lặp for**

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<double> diemSo = {7.5, 8.0, 9.5}; // Có thể khởi tạo giá trị sẵn
    
    cout << "Danh sach diem cua hoc sinh la:\n";
    // Dùng .size() thay vì số cố định
    for (int i = 0; i < diemSo.size(); i++) {
        cout << diemSo[i] << " ";
    }
    cout << endl;
    
    return 0;
}

```

* **Ví dụ 3: Ứng dụng thực tế: Nhập đến khi muốn dừng**

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> tuiTien;
    int tienNhap;
    
    cout << "Nhap so tien vao tui (Nhap -1 de dung lai):\n";
    while (true) { // Vòng lặp vô hạn, ta sẽ dùng break để thoát
        cout << "Nhap: ";
        cin >> tienNhap;
        
        if (tienNhap == -1) {
            break; // Thoát vòng lặp nếu nhập -1
        }
        
        tuiTien.push_back(tienNhap); // Nhét tiền vào túi
    }
    
    cout << "\nBan da nhap " << tuiTien.size() << " mon tien.\n";
    return 0;
}

```

*Giải thích:* Nếu dùng mảng, ta không thể viết bài toán "nhập đến khi dừng" vì không biết người dùng sẽ nhập 3 hay 30 số. Vector xử lý việc này hoàn hảo thông qua `push_back`.

**4. Bài tập thực hành trên lớp**

* **Bài 1:** Viết chương trình khai báo `vector<string> gioHang`. Dùng hàm `push_back` để thêm 3 món hàng vào giỏ. Sau đó duyệt vector để in các món hàng ra.
* **Bài 2:** Dựa vào Ví dụ 3, hãy mở rộng chương trình: Sau khi người dùng nhập `-1` để dừng, hãy dùng vòng lặp `for` và `.size()` để tính tổng tất cả số tiền đang có trong `tuiTien`.
* **Bài 3:** Thử so sánh bằng cách viết chương trình yêu cầu nhập 100 con số. Cảm nhận sự tiện lợi khi không phải đoán trước số lượng giới hạn của mảng.

**5. Bài tập về nhà**

* **Bài 1:** Viết một chương trình lưu điểm học sinh. Liên tục cho phép nhập điểm. Nếu người dùng nhập điểm hợp lệ (từ 0 đến 10) thì dùng `push_back` lưu vào `vector<double>`. Nếu nhập một số ngoài khoảng 0-10, chương trình dừng nhập và in toàn bộ danh sách các con điểm đã lưu.

### Buổi 09 - Mảng một chiều

**1. Mục tiêu buổi học**

* Hiểu mảng một chiều lưu nhiều giá trị cùng kiểu.


* Biết khai báo mảng, nhập mảng, in mảng.


* Hiểu chỉ số mảng bắt đầu từ 0.


* Biết duyệt mảng bằng for.


* Biết tính tổng, trung bình, đếm, tìm phần tử trong mảng.


* Học sinh viết được chương trình quản lý danh sách điểm hoặc danh sách số.



**2. Lý thuyết chi tiết**

* **Mảng một chiều (Array) là gì?** Hãy tưởng tượng thay vì mua 10 chiếc hộp rời rạc để đựng 10 cuốn sách (khai báo 10 biến `int`), bạn mua một cái kệ sách có 10 ngăn dính liền nhau. Mảng chính là cái kệ sách đó, giúp lưu trữ một danh sách nhiều giá trị **cùng một kiểu dữ liệu** (ví dụ: cùng là số nguyên, hoặc cùng là chuỗi).
> `[📸 Hình ảnh ví dụ: Hình ảnh 10 chiếc hộp rời rạc (Biến) đặt cạnh 1 chiếc tủ có 10 ngăn kéo đánh số thứ tự (Mảng)]`


* **Khai báo mảng:** Cú pháp: `Kiểu_dữ_liệu Tên_mảng[Số_lượng_phần_tử];`. Ví dụ: `int diem[5];` (Tạo mảng chứa 5 điểm số).
* **Chỉ số mảng (Index):** Trong lập trình, người ta đếm từ số 0. Ngăn đầu tiên của tủ đồ là ngăn số 0. Do đó, mảng có 5 phần tử thì các chỉ số lần lượt là: 0, 1, 2, 3, 4.
* **Truy cập phần tử:** Để lấy đồ hoặc cất đồ vào ngăn tủ, ta dùng dấu ngoặc vuông `[ ]`. Ví dụ: `diem[0] = 8;` (Cất số 8 vào ngăn đầu tiên).
* **Duyệt mảng bằng `for`:** Vì chỉ số mảng tăng dần từ `0` đến `n-1`, vòng lặp `for` là công cụ sinh ra để đi qua từng ngăn của mảng một cách hoàn hảo.

**3. Ví dụ minh họa**

* **Ví dụ 1: Khai báo và in mảng cơ bản**

```cpp
#include <iostream>
using namespace std;

int main() {
    // Khai báo mảng chứa 5 phần tử và gán sẵn giá trị
    int tuoi[5] = {14, 15, 15, 16, 14};
    
    // In ra phần tử đầu tiên (chỉ số 0) và cuối cùng (chỉ số 4)
    cout << "Tuoi cua ban dau tien: " << tuoi[0] << endl;
    cout << "Tuoi cua ban cuoi cung: " << tuoi[4] << endl;
    
    return 0;
}

```

*Giải thích:* Mảng `tuoi` có kích thước 5. Phần tử `tuoi[0]` chứa giá trị 14, `tuoi[4]` chứa giá trị 14. Nếu cố tình truy cập `tuoi[5]`, chương trình sẽ báo lỗi hoặc chạy sai vì vượt quá giới hạn tủ.

* **Ví dụ 2: Nhập và in danh sách điểm (Duyệt mảng)**

```cpp
#include <iostream>
using namespace std;

int main() {
    int diem[4]; // Mảng chứa 4 con điểm
    
    // Vòng lặp để nhập dữ liệu
    cout << "Nhap 4 con diem:\n";
    for (int i = 0; i < 4; i++) {
        cout << "Nhap diem thu " << i + 1 << ": ";
        cin >> diem[i];
    }
    
    // Vòng lặp để in dữ liệu
    cout << "\nDanh sach diem vua nhap la: ";
    for (int i = 0; i < 4; i++) {
        cout << diem[i] << " ";
    }
    cout << endl;
    
    return 0;
}

```

*Giải thích:* Vòng lặp `for` với biến `i` chạy từ 0 đến 3. `diem[i]` sẽ lần lượt đại diện cho `diem[0]`, `diem[1]`, `diem[2]`, `diem[3]`.

* **Ví dụ 3: Tính tổng và trung bình mảng**

```cpp
#include <iostream>
using namespace std;

int main() {
    int danhSach[5] = {5, 7, 8, 9, 6};
    double tong = 0;
    
    // Duyệt mảng để cộng dồn vào tổng
    for (int i = 0; i < 5; i++) {
        tong = tong + danhSach[i];
    }
    
    double trungBinh = tong / 5;
    cout << "Tong cac so la: " << tong << endl;
    cout << "Trung binh la: " << trungBinh << endl;
    
    return 0;
}

```

**4. Bài tập thực hành trên lớp**

* **Bài 1:** Viết chương trình khai báo một mảng lưu trữ 5 tên môn học (kiểu `string`). Dùng vòng lặp `for` để in danh sách các môn học đó ra màn hình.
* **Bài 2:** Viết chương trình cho phép người dùng nhập vào mảng 10 số nguyên. Sau đó dùng vòng lặp đếm xem trong mảng vừa nhập có bao nhiêu số chẵn.
* **Bài 3:** Cho mảng `int tienTietKiem[7]` đại diện cho số tiền tiết kiệm trong 7 ngày. Hãy nhập dữ liệu cho mảng và tìm xem ngày nào (chỉ số mấy) tiết kiệm được nhiều tiền nhất (Tìm Max).

**5. Bài tập về nhà**

* **Bài 1:** Viết chương trình quản lý điểm số: Nhập số lượng học sinh N (N < 50), sau đó nhập mảng N điểm số. Tính và in ra điểm trung bình của cả lớp, đồng thời đếm số lượng học sinh đạt điểm giỏi (>= 8.0).
* **Bài 2:** Nhập một mảng 5 số nguyên. Hãy in mảng đó ra màn hình theo thứ tự đảo ngược (Ví dụ nhập 1 2 3 4 5 thì in ra 5 4 3 2 1). (Gợi ý: Cho vòng lặp `for` chạy lùi từ `4` về `0`).

### Buổi 10 - Hàm cơ bản và mini game đoán số

**1. Mục tiêu buổi học**

* Hiểu hàm giúp tách chương trình thành các phần nhỏ.


* Biết khai báo hàm, gọi hàm, tham số, giá trị trả về.


* Biết viết hàm tính toán đơn giản: tổng, max, kiểm tra chẵn lẻ.


* Hiểu void và hàm có return.


* Biết tách mini game đoán số thành các hàm nhỏ.


* Học sinh viết được mini game đoán số có giới hạn số lần thử.



**2. Lý thuyết chi tiết**

* **Hàm (Function) là gì?** Hàm giống như một "nhà máy mini" bên trong chương trình. Bạn đưa nguyên liệu (Tham số) vào nhà máy, nhà máy xử lý, và trả ra thành phẩm (Giá trị trả về). Hàm giúp chia một đoạn code dài hàng trăm dòng thành các khối nhỏ gọn gàng, dễ quản lý và có thể tái sử dụng nhiều lần.
> `[📸 Hình ảnh ví dụ: Mô hình máy xay sinh tố: Nguyên liệu vào (Tham số: dâu, sữa) -> Quá trình xay (Thân hàm) -> Sản phẩm ra (Return: ly sinh tố)]`


* **Cấu trúc của hàm:** `Kiểu_trả_về Tên_hàm(Danh_sách_tham_số) { ... thân hàm ... return giá_trị; }`
* **Void và Return:**
* Hàm có kiểu trả về (ví dụ `int`, `double`): Bắt buộc phải có từ khóa `return` để ném kết quả ra ngoài. (Như việc máy xay trả ra sinh tố).
* Hàm kiểu `void`: Là hàm chỉ thực hiện một hành động (như in ra màn hình) rồi thôi, không trả về giá trị gì cả. Không cần `return`. (Như việc máy hút bụi dọn nhà xong thì tắt).


* **Gọi hàm:** Viết tên hàm kèm theo dấu ngoặc tròn `()`. Nếu có tham số thì truyền vào bên trong ngoặc. Từ buổi 1, chúng ta đã luôn code bên trong một hàm đặc biệt, đó chính là `int main()`.

**3. Ví dụ minh họa**

* **Ví dụ 1: Hàm in lời chào (Kiểu void)**

```cpp
#include <iostream>
#include <string>
using namespace std;

// Khai báo hàm void không trả về giá trị
void xinChao(string ten) {
    cout << "Xin chao " << ten << "! Chuc mot ngay tot lanh.\n";
}

int main() {
    // Gọi hàm và truyền tham số
    xinChao("Hoc Sinh"); 
    xinChao("Gemini");
    return 0;
}

```

*Giải thích:* Hàm `xinChao` nhận vào một chuỗi `ten`. Khi ta gọi hàm trong `main` hai lần với hai tên khác nhau, hàm sẽ in ra hai câu chào tương ứng mà ta không phải viết lại code `cout`.

* **Ví dụ 2: Hàm tính tổng (Có giá trị trả về return)**

```cpp
#include <iostream>
using namespace std;

// Hàm nhận vào 2 số nguyên, trả về 1 số nguyên
int tinhTong(int a, int b) {
    int ketQua = a + b;
    return ketQua; // Trả kết quả ra ngoài
}

int main() {
    int x = 5, y = 10;
    // Hứng kết quả từ hàm tinhTong vào biến tong
    int tong = tinhTong(x, y); 
    cout << "Tong cua x va y la: " << tong << endl;
    
    // Có thể gọi trực tiếp trong cout
    cout << "Tong cua 100 va 200 la: " << tinhTong(100, 200) << endl; 
    return 0;
}

```

* **Ví dụ 3: Ứng dụng hàm vào Mini Game Đoán Số**

```cpp
#include <iostream>
using namespace std;

// Hàm kiểm tra người chơi đoán đúng hay sai
void kiemTraDoanSo(int soBiMat, int soDoan) {
    if (soDoan > soBiMat) {
        cout << "So cua ban hoi lon!\n";
    } else if (soDoan < soBiMat) {
        cout << "So cua ban hoi be!\n";
    } else {
        cout << "Chinh xac! Ban da doan trung!\n";
    }
}

int main() {
    int soBiMat = 42; 
    int soDoan;
    int soLanThu = 3;
    
    cout << "--- GAME DOAN SO (Ban co 3 lan thu) ---\n";
    
    for (int i = 1; i <= soLanThu; i++) {
        cout << "\nLan thu " << i << ". Nhap so ban doan: ";
        cin >> soDoan;
        
        kiemTraDoanSo(soBiMat, soDoan); // Gọi hàm kiểm tra
        
        if (soDoan == soBiMat) {
            break; // Thắng cuộc, thoát vòng lặp
        }
    }
    return 0;
}

```

**4. Bài tập thực hành trên lớp**

* **Bài 1:** Viết một hàm kiểu `bool` tên là `kiemTraChanLe(int n)`. Hàm sẽ `return true` nếu n là số chẵn, `return false` nếu n là số lẻ. Gọi hàm này trong `main` để kiểm tra.
* **Bài 2:** Viết một hàm `int timMax(int a, int b, int c)` nhận vào 3 số nguyên, xử lý tìm số lớn nhất và trả về số đó.
* **Bài 3:** Nâng cấp Mini game ở Ví dụ 3: Thêm tính năng nếu dùng hết 3 lần thử mà vẫn chưa đoán trúng, hãy in ra thông báo "Game Over! Số bí mật là 42".

**5. Bài tập về nhà**

* **Bài 1:** Viết một hàm `void veHinhVuong(int canh)` chuyên dùng để vẽ một hình vuông bằng dấu `*`. Trong `main`, cho người dùng nhập độ dài cạnh rồi gọi hàm để vẽ.

### Buổi 11 - Mảng hai chiều và ma trận

**1. Mục tiêu buổi học**

* Hiểu mảng hai chiều lưu dữ liệu dạng bảng gồm dòng và cột.


* Biết khai báo, nhập, in mảng hai chiều.


* Biết duyệt mảng hai chiều bằng hai vòng lặp lồng nhau.


* Biết tính tổng theo dòng, theo cột.


* Biết tìm giá trị lớn nhất, nhỏ nhất trong bảng.


* Học sinh viết được chương trình xử lý bảng điểm nhiều học sinh và nhiều môn.



**2. Lý thuyết chi tiết**

* **Mảng hai chiều là gì?** Hãy nghĩ về mảng 1 chiều như một dãy nhà trên 1 con phố. Còn mảng 2 chiều chính là một tòa nhà chung cư (có nhiều tầng, mỗi tầng có nhiều phòng) hoặc giống như bảng tính Excel (có dòng và cột).
> `[📸 Hình ảnh ví dụ: Hình ảnh bảng lưới tọa độ (Lưới Excel) minh họa các ô chứa giá trị ứng với dòng (row) và cột (column)]`


* **Khai báo mảng 2 chiều:** Cú pháp: `Kiểu_dữ_liệu Tên_mảng[Số_dòng][Số_cột];`. Ví dụ: `int bangDiem[3][4];` (Tạo một bảng có 3 dòng, mỗi dòng có 4 cột).
* **Truy cập phần tử:** Ta cần 2 chỉ số để định vị, một cho dòng và một cho cột, bắt đầu từ 0. `bangDiem[0][1]` nghĩa là lấy dữ liệu ở dòng 0, cột 1.
* **Hai vòng lặp lồng nhau:** Để duyệt mảng 2 chiều, bắt buộc phải dùng 2 vòng lặp `for` lồng vào nhau. Vòng lặp ngoài kiểm soát dòng (`i`), vòng lặp trong kiểm soát cột (`j`).

**3. Ví dụ minh họa**

* **Ví dụ 1: Khai báo và in ma trận**

```cpp
        {4, 5, 6}  // Dòng 1
    };
    
    // In giá trị ở dòng 1, cột 2
    cout << "Gia tri tai dong 1, cot 2: " << maTran[1][2] << endl; // In ra 6
    
    return 0;
}

```

### Buổi 12 - Vector và danh sách linh hoạt

**1. Mục tiêu buổi học**

* Hiểu vector là danh sách có kích thước linh hoạt.


* Biết khai báo vector, push_back, size, truy cập theo chỉ số.


* Biết duyệt vector bằng for.


* Biết thêm dữ liệu khi chưa biết trước số lượng.


* Biết so sánh vector với mảng tĩnh.


* Học sinh viết được chương trình nhập danh sách điểm hoặc sản phẩm đến khi người dùng dừng lại.



**2. Lý thuyết chi tiết**

* **Giới hạn của mảng tĩnh:** Khi khai báo mảng `int diem[5];`, kích thước của nó bị khóa chết ở mức 5. Nếu có 6 học sinh nhập học, mảng này không thể phình to ra được.
* **Vector là gì?** Vector trong C++ chính là một "mảng thông minh" (Mảng động). Nó có thể tự động co giãn kích thước. Khi bạn nhét thêm dữ liệu vào, nó sẽ tự dài ra.
> `[📸 Hình ảnh ví dụ: Minh họa Mảng (Array) là một chiếc hộp nhựa cứng, so sánh với Vector là một chiếc túi cao su có thể phồng to khi nhét thêm đồ vật]`


* **Thư viện `<vector>`:** Để dùng vector, ta phải thêm `#include <vector>`.
* **Khai báo và thêm phần tử:** Cú pháp: `vector<Kiểu_dữ_liệu> Tên_vector;`. Để thêm một phần tử vào đuôi danh sách, dùng hàm đặc biệt `.push_back(giá_trị)`.
* **Kích thước vector:** Dùng `.size()` để biết hiện tại túi đang chứa bao nhiêu đồ vật.
* **Truy cập phần tử:** Giống hệt mảng tĩnh, ta vẫn dùng ngoặc vuông `[ ]`.

**3. Ví dụ minh họa**

* **Ví dụ 1: Khai báo và thao tác cơ bản với Vector**

```cpp
#include <iostream>
#include <vector> // Bắt buộc phải có thư viện này
using namespace std;

int main() {
    vector<int> danhSach; // Khai báo một vector chứa số nguyên, ban đầu trống rỗng
    
    // Thêm các số vào cuối danh sách
    danhSach.push_back(10); 
    danhSach.push_back(20);
    danhSach.push_back(30);
    
    // Số lượng phần tử hiện tại
    cout << "Kich thuoc vector: " << danhSach.size() << endl; // Sẽ in ra 3
    
    // Truy cập phần tử y như mảng
    cout << "Phan tu thu hai: " << danhSach[1] << endl; // Sẽ in ra 20
    
    return 0;
}

```

### Buổi 13 - Sắp xếp nổi bọt và chọn trực tiếp

**1. Mục tiêu buổi học**

* Hiểu được mục tiêu của thuật toán sắp xếp là đưa dữ liệu từ trạng thái lộn xộn về đúng thứ tự mong muốn.


* Biết mô phỏng thuật toán Bubble Sort (Nổi bọt) bằng việc so sánh từng cặp phần tử liền kề và đổi chỗ chúng.


* Biết mô phỏng thuật toán Selection Sort (Chọn trực tiếp) bằng việc tìm phần tử nhỏ nhất/lớn nhất rồi đổi chỗ về đầu mảng.


* Biết cách in mảng sau từng lượt duyệt để có thể nhìn rõ quá trình sắp xếp diễn ra như thế nào.


* Biết cách chỉnh sửa điều kiện so sánh để sắp xếp danh sách tăng dần hoặc giảm dần.


* Học sinh tự tay viết được chương trình sắp xếp một danh sách điểm số bằng các thuật toán cơ bản này.



**2. Lý thuyết chi tiết**

* **Tại sao phải sắp xếp?** Sắp xếp giúp ta dễ dàng tìm kiếm và thống kê. Hãy tưởng tượng việc tìm một bạn có điểm cao nhất trong bảng điểm 100 người chưa sắp xếp sẽ mệt mỏi thế nào so với một bảng điểm đã được xếp từ cao xuống thấp.


* **Đổi chỗ (Swap):** Trong C++, để đổi chỗ 2 ly nước A và B, ta cần một chiếc ly cạn C làm trung gian. (Cất nước ly A sang C -> Đổ nước ly B sang A -> Đổ nước ly C về B) .


* **Thuật toán Nổi bọt (Bubble Sort):** Lần lượt so sánh 2 số đứng cạnh nhau. Nếu số đứng trước lớn hơn số đứng sau (khi xếp tăng dần), ta lập tức đổi chỗ chúng. Cứ lặp lại nhiều vòng như vậy, số lớn nhất sẽ từ từ "nổi" dần về phía cuối mảng giống như bong bóng khí.


> `[📸 Hình ảnh ví dụ: Mô phỏng bong bóng: Các con số lớn màu đỏ được khoanh vùng so sánh theo cặp 2 số liền kề và tráo đổi vị trí dịch chuyển dần về cuối mảng]`


* **Thuật toán Chọn trực tiếp (Selection Sort):** Tìm con số nhỏ nhất trong danh sách. Lấy nó đổi chỗ với con số đang đứng ở vị trí đầu tiên. Sau đó, tiếp tục tìm con số nhỏ nhất trong phần còn lại và đổi chỗ đưa lên vị trí thứ hai. Cứ thế cho đến hết.


* 
**In quá trình sắp xếp:** Bằng việc đặt lệnh `cout` in mảng ở cuối mỗi vòng lặp `for` lớn, ta có thể theo dõi xem thuật toán đang làm đúng hay không.



**3. Ví dụ minh họa**

* **Ví dụ 1: Bubble Sort cơ bản (Sắp xếp tăng dần)**

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> diem = {8, 3, 9, 2, 5};
    int n = diem.size();

    // Vòng lặp ngoài kiểm soát số lượt đi qua mảng
    for (int i = 0; i < n - 1; i++) {
        // Vòng lặp trong đi so sánh các cặp liền kề
        for (int j = 0; j < n - i - 1; j++) {
            if (diem[j] > diem[j+1]) { // Nếu số trước lớn hơn số sau
                // Đổi chỗ (Swap)
                int tam = diem[j];
                diem[j] = diem[j+1];
                diem[j+1] = tam;
            }
        }
    }

    cout << "Mang sau khi Bubble Sort (Tang dan): ";
    for (int i = 0; i < n; i++) {
        cout << diem[i] << " ";
    }
    return 0;
}

```

*Giải thích:* Vòng lặp `j` so sánh cặp `diem[j]` và `diem[j+1]`. Dòng `int tam = diem[j];` chính là bước dùng ly trung gian để đổi chỗ.

* **Ví dụ 2: Selection Sort (Sắp xếp giảm dần)**

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> diem = {6, 1, 10, 4, 8};
    int n = diem.size();

    for (int i = 0; i < n - 1; i++) {
        int viTriMax = i; // Giả sử phần tử hiện tại là lớn nhất
        
        // Tìm vị trí của phần tử lớn nhất trong phần còn lại
        for (int j = i + 1; j < n; j++) {
            if (diem[j] > diem[viTriMax]) {
                viTriMax = j;
            }
        }
        
        // Đổi chỗ phần tử lớn nhất tìm được với phần tử ở đầu mảng (vị trí i)
        int tam = diem[i];
        diem[i] = diem[viTriMax];
        diem[viTriMax] = tam;
    }

    cout << "Mang sau khi Selection Sort (Giam dan): ";
    for (int i = 0; i < n; i++) {
        cout << diem[i] << " ";
    }
    return 0;
}

```

*Giải thích:* Selection Sort không đổi chỗ liên tục như Bubble Sort, nó đi tìm cái lớn nhất (hoặc nhỏ nhất) rồi mới đổi chỗ 1 lần ở cuối mỗi vòng lặp `i`.

* **Ví dụ 3: In mảng sau từng lượt (Xem quá trình)**

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> a = {4, 2, 7, 1};
    int n = a.size();

    for (int i = 0; i < n - 1; i++) {
        // Thuật toán Selection Sort tìm Min
        int posMin = i;
        for (int j = i + 1; j < n; j++) {
            if (a[j] < a[posMin]) posMin = j;
        }
        // Đổi chỗ
        int tam = a[i]; a[i] = a[posMin]; a[posMin] = tam;
        
        // In ra mảng sau mỗi vòng lặp lớn
        cout << "Luot " << i + 1 << ": ";
        for (int k = 0; k < n; k++) cout << a[k] << " ";
        cout << endl;
    }
    return 0;
}

```

### Buổi 14 - Tìm kiếm tuyến tính và bảng xếp hạng

**1. Mục tiêu buổi học**

### Buổi 16 - Xử lý chuỗi và Caesar Cipher

**1. Mục tiêu buổi học**

* Biết kết hợp vòng lặp để duyệt từng ký tự trong biến chuỗi (string) để xử lý logic.


* Biết cách kiểm tra một ký tự ở mức độ cơ bản: xem nó là chữ cái hay là chữ số, hay là một dấu khoảng trắng.


* Biết cách chủ động chuyển đổi một chữ viết hoa thành viết thường (và ngược lại) thông qua biến đổi bảng mã ký tự.


* Hiểu được ý tưởng cơ bản của kỹ thuật mã hóa Caesar: Dịch chuyển các ký tự đi một số bước nhất định trong bảng chữ cái (ví dụ A dịch 3 bước thành D).


* Biết áp dụng xử lý chuỗi để tạo ra một mini tool làm ứng dụng bảo mật đơn giản.


* Học sinh tự tay viết được toàn bộ chương trình mã hóa và giải mã theo chuẩn Caesar Cipher cơ bản.



**2. Lý thuyết chi tiết**

* **Mã ASCII (Lý thuyết cốt lõi):** Máy tính không hiểu chữ "A". Nó lưu chữ "A" dưới dạng một con số (số 65). Chữ "B" là 66, "C" là 67... Chữ thường "a" là 97. Tức là các ký tự thực chất là các CON SỐ ẩn danh.


* 
**Kiểm tra ký tự:** Nhờ mã ASCII, ta có thể kiểm tra một ký tự `c` có phải chữ cái in hoa không bằng biểu thức toán học: `if (c >= 'A' && c <= 'Z')`.


* 
**Đổi chữ thường thành chữ hoa:** Từ "a" (97) muốn thành "A" (65), ta chỉ cần lấy giá trị đó trừ đi 32. Ngược lại, hoa thành thường thì cộng thêm 32. (Lưu ý: Chỉ thực hiện với các chữ cái).


* **Mã hoá Caesar Cipher:** Kỹ thuật mã hoá nổi tiếng của Julius Caesar. Để giấu thông tin, ông dịch tất cả chữ cái trong thư đi K bước. Ví dụ K = 3: chữ 'A' + 3 = 'D', chữ 'B' + 3 = 'E'. Người nhận biết được "chìa khóa" K=3 thì lấy mật thư trừ lại đi 3 bước để giải mã.


> `[📸 Hình ảnh ví dụ: Hai vòng tròn bảng chữ cái đồng tâm lồng vào nhau, vòng trong bị xoay lệch đi 3 nấc so với vòng ngoài để minh họa cách tạo mã Caesar]`

### Buổi 19 - Tham chiếu và truyền tham số

**1. Mục tiêu buổi học**

* Hiểu truyền tham trị và truyền tham chiếu khác nhau như thế nào, biết khi nào dùng dấu `&` trong tham số hàm.


* Biết viết hàm hoán đổi hai số bằng tham chiếu và biết truyền vector vào hàm để xử lý.


* Biết tránh sửa dữ liệu ngoài ý muốn và học sinh viết được hàm nhập vector, sửa giá trị, tính tổng bằng tham số.


* Mọi ví dụ cần được minh họa bằng code chi tiết, dễ đọc.



**2. Lý thuyết chi tiết**

* **Truyền Tham Trị (Pass by Value):** Khi bạn đưa biến `x` vào hàm, máy tính đi "photocopy" giá trị của `x` đưa cho hàm. Hàm có sửa bản copy đó thế nào thì bản gốc `x` ở bên ngoài cũng không bị suy suyển.
* **Truyền Tham Chiếu (Pass by Reference):** Bằng cách thêm dấu và (`&`) vào trước tên tham số (ví dụ `int &a`), bạn không đưa bản copy nữa, mà đưa thẳng chìa khóa bản gốc cho hàm. Lúc này, hàm sửa `a` tức là biến truyền vào ở ngoài `main` bị đổi theo.
> `[📸 Hình ảnh ví dụ: Minh họa sự khác biệt: Tham trị (Copy tờ giấy đưa cho bạn xem, bạn xé đi tờ giấy gốc vẫn còn) vs Tham chiếu (Cùng chia sẻ chung 1 tài liệu trên Google Docs, một người xóa chữ thì tài liệu gốc mất chữ)]`


* **Ứng dụng lớn nhất của Tham chiếu:**
1. Dùng để viết hàm sửa đổi dữ liệu (như hàm `hoanDoi()`).
2. Truyền Vector: Vector chứa cả ngàn dữ liệu. Nếu dùng tham trị (copy), máy tính mất rất nhiều công để photocopy cả ngàn dữ liệu đó -> Giật, lag. Truyền bằng `&` giúp truy cập cực nhanh.



**3. Ví dụ minh họa**

* **Ví dụ 1: Sự khác biệt cực lớn của dấu `&**`

```cpp
#include <iostream>
using namespace std;

// Hàm 1: Photocopy (Tham trị)
void tangThem_ThamTri(int a) {
    a = a + 10;
}

// Hàm 2: Sửa bản gốc (Tham chiếu)
void tangThem_ThamChieu(int &a) {
    a = a + 10;
}

int main() {
    int diem = 5;
    
    tangThem_ThamTri(diem);
    cout << "Sau ham 1: " << diem << endl; // Vẫn in ra 5
    
    tangThem_ThamChieu(diem);
    cout << "Sau ham 2: " << diem << endl; // In ra 15
    return 0;
}

```

### Buổi 20 - Bộ nhớ nhập môn và xử lý vector trong hàm

**1. Mục tiêu buổi học**

* Hiểu cơ bản về biến, vùng nhớ, giá trị được lưu trong biến.


* Hiểu vector có thể thay đổi kích thước và biết truyền vector vào hàm bằng tham chiếu để tránh copy không cần thiết.


* Biết thêm, xóa, sửa dữ liệu trong vector ở mức cơ bản.


* Biết kiểm tra chỉ số hợp lệ trước khi truy cập và học sinh viết được các hàm xử lý danh sách điểm/sản phẩm bằng vector.


* Đảm bảo lý thuyết được giải thích dễ hiểu với học sinh 15 tuổi.



**2. Lý thuyết chi tiết**

* **Vùng nhớ (Memory):** Khi khởi chạy ứng dụng, hệ điều hành cấp cho nó một mảnh đất (RAM) để ở. Khi bạn khai báo `int x = 5;`, bạn đang xin cấp một ô đất nhỏ, cắm biển tên "x" và cất số 5 vào đó.
* **Tối ưu truyền Vector:** Bằng cách truyền tham chiếu `&`, ta đưa cho hàm địa chỉ của mảnh đất thay vì bắt máy tính nhân bản toàn bộ mảnh đất đó, giúp bộ nhớ RAM không bị đầy và phần mềm chạy nhanh hơn rất nhiều.
* **Kiểm tra biên (Boundary Check):** Vector mạnh mẽ nhưng cũng dễ làm sập chương trình. Nếu vector có 3 phần tử (chỉ số 0, 1, 2) mà bạn gọi `v[5]`, chương trình sẽ báo lỗi tràn bộ nhớ (Out of Range). Do đó, hàm sửa dữ liệu bắt buộc phải kiểm tra: `if (viTri >= 0 && viTri < v.size())` thì mới cho truy cập.
* **Xóa phần tử trong Vector:** Dùng hàm `.erase()`. Tuy nhiên, lệnh này yêu cầu truyền vào một cái gọi là `iterator` (con trỏ vị trí). Cú pháp đơn giản để xóa phần tử ở vị trí thứ `i` là: `v.erase(v.begin() + i);`.
> `[📸 Hình ảnh ví dụ: Minh họa lệnh v.erase(): Một chiếc móc câu lấy một viên gạch ra khỏi hàng gạch Vector, các viên gạch phía sau tự động trượt lên lấp đầy khoảng trống]`

* **Ví dụ 1: Hàm sửa dữ liệu an toàn (Chống sập ứng dụng)**


* **Ví dụ 2: Hàm xóa dữ liệu trong Vector**

```cpp
#include <iostream>
#include <vector>
using namespace std;

void xoaPhanTu(vector<int> &ds, int viTriXoa) {
    if (viTriXoa >= 0 && viTriXoa < ds.size()) {
        // Cú pháp đặc biệt: ds.begin() lấy vị trí gốc, cộng thêm vị trí cần xóa
        ds.erase(ds.begin() + viTriXoa);
        cout << "Da xoa!\n";
    }
}

int main() {
    vector<int> gioHang = {100, 200, 300};
    xoaPhanTu(gioHang, 1); // Xóa mặt hàng số 200 (ở vị trí index 1)
    
    for (int i = 0; i < gioHang.size(); i++) cout << gioHang[i] << " ";
    // Sẽ in ra: 100 300
    return 0;
}
```

**1. Mục tiêu buổi học**

* Các ví dụ lập trình console ưu tiên mã nguồn rõ ràng, dễ bảo trì.



**2. Lý thuyết chi tiết**

* **Giới hạn của biến thông thường:** Để lưu 1 học sinh, ta cần 3 mảng rời rạc: `maSV`, `tenSV`, `diemSV`. Sẽ rất rườm rà và dễ nhầm chỉ số nếu ta muốn sắp xếp thông tin.
* **Struct (Cấu trúc) là gì?** C++ cho phép ta tạo ra một "khuôn đúc" mới gom tất cả 3 thông tin trên lại làm 1 khối. Ta gọi khối đó là `HocSinh`. Struct chính là bước đệm tuyệt vời để hiểu về Lập trình Hướng đối tượng sau này.

* **Vector Struct:** Biến Struct được đối xử như một kiểu dữ liệu bình thường. Do đó ta có quyền tạo ra danh sách cực mạnh: `vector<HocSinh> danhSach;`.

### Buổi 22 - File I/O và ôn tập giai đoạn 2

**1. Mục tiêu buổi học**

* Biết đọc và ghi file text cơ bản bằng ifstream/ofstream và biết lưu danh sách ra file, đọc lại danh sách.


* Biết kiểm tra file mở thành công hay không và ôn tập toàn bộ kiến thức vector, struct, hàm, menu.


* Biết chia chương trình quản lý thành các hàm rõ ràng và học sinh viết được mini app lưu/đọc danh sách đơn giản.


* Tổng hợp kiến thức kết thúc Giai đoạn 2 của khóa học.



**2. Lý thuyết chi tiết**

* **Tại sao phải dùng File?** Mọi biến `int`, `vector` đều nằm trên RAM. Nếu bạn tắt cửa sổ console (màn hình đen), toàn bộ dữ liệu bạn nhập nãy giờ sẽ bốc hơi. Để dữ liệu tồn tại vĩnh viễn, ta phải lưu chúng xuống ổ cứng dưới dạng tệp văn bản (`.txt`).
* **Thư viện `<fstream>` (File Stream):** Cung cấp 2 công cụ chính:
* `ofstream` (Output File Stream): Luồng xuất, dùng để **GHI** dữ liệu từ RAM xuống file txt. (Cách dùng giống hệt `cout`).
* `ifstream` (Input File Stream): Luồng nhập, dùng để **ĐỌC** dữ liệu từ file txt đưa ngược lên RAM. (Cách dùng giống hệt `cin`).


* **Quy trình 3 bước:**
1. Mở file. (Nhớ kiểm tra xem mở có thành công không, lỡ file bị xóa thì sao?).
2. Thực hiện thao tác Ghi hoặc Đọc.
3. ĐÓNG file (`.close()`). Đây là thao tác bắt buộc để hệ điều hành lưu file lại an toàn.


> `[📸 Hình ảnh ví dụ: Minh họa quy trình: RAM máy tính -> Mở đường ống nước (ofstream) -> Nước (Data) chảy vào bể chứa (File .txt trên ổ cứng) -> Đóng van (close)]`



**3. Ví dụ minh họa**

* **Ví dụ 1: Ghi thông tin xuống file (Save)**

```cpp
#include <iostream>
#include <fstream> // Bắt buộc
#include <string>
using namespace std;

int main() {
    // 1. Mở file để ghi (Nếu file chưa có, nó sẽ tự tạo)
    ofstream fileGhi("data.txt");
    
    if (fileGhi.is_open()) {
        // 2. Ghi dữ liệu giống y hệt cout
        fileGhi << "Ban dang hoc bai File trong C++\n";
        fileGhi << "Diem so: " << 10 << endl;
        
        // 3. Đóng file
        fileGhi.close();
        cout << "Da luu xuong o cung thanh cong!\n";
    } else {
        cout << "Loi tao file!\n";
    }
    
    return 0;
}

```

*Ghi chú:* Sau khi chạy code, hướng dẫn học sinh vào thư mục chứa code mở tệp `data.txt` bằng Notepad để tận mắt nhìn thấy dữ liệu.

* Biết sửa từng trường dữ liệu của một phần tử.


* Biết xóa phần tử bằng erase.


* Biết kiểm tra mã có tồn tại trước khi thao tác.


* Học sinh viết được chức năng thêm, sửa, xóa cho danh sách struct.



**2. Lý thuyết chi tiết**

* **Thêm mới (Create):** Khởi tạo một biến `struct` tạm thời, cho người dùng nhập thông tin vào biến đó (lưu ý dùng `cin.ignore()` nếu nhập chữ sau số), cuối cùng đẩy cả khối struct đó vào `vector` bằng `.push_back()`.
* **Cơ chế tìm trước khi Sửa/Xóa:** Bạn không thể sửa đồ nếu không biết nó nằm ở đâu. Do đó, phải viết vòng lặp tìm kiếm xem Mã sản phẩm mà người dùng nhập có khớp với bất kỳ sản phẩm nào trong mảng không. Nếu tìm thấy, ta lưu lại vị trí (index `i`). Nếu duyệt hết mảng mà không thấy, ta báo lỗi.
> `[📸 Hình ảnh ví dụ: Một robot rà quét dọc theo kệ hàng (Vector). Robot quét mã vạch (ID) từng món đồ. Khi tìm thấy mã khớp, robot tiến hành dán nhãn giá mới (Sửa) hoặc gắp món đồ đó ném ra khỏi kệ (Xóa)]`


* **Xóa bằng `.erase()`:** Khi đã có vị trí `index` cần xóa, ta dùng lệnh `ds.erase(ds.begin() + index);`. Lệnh này sẽ rút món đồ đó ra, và các phần tử phía sau sẽ tự động dồn lên lấp khoảng trống.

### Buổi 26 - Tìm min, max và lọc dữ liệu

**1. Mục tiêu buổi học**

* Biết tìm giá trị lớn nhất, nhỏ nhất trong danh sách.


* Biết tìm đối tượng có điểm/giá cao nhất hoặc thấp nhất.


* Biết lọc các phần tử thỏa điều kiện.


* Biết đếm số lượng phần tử thỏa điều kiện.


* Biết tính trung bình trên danh sách.


* Học sinh viết được thống kê cơ bản cho danh sách dữ liệu.



**2. Lý thuyết chi tiết**

* **Thuật toán Tìm Min / Max:** Để tìm học sinh cao điểm nhất, ta không so sánh điểm của một bạn với 10, mà ta đặt "Niềm tin" vào bạn đầu tiên trong danh sách (Cắm cờ `viTriMax = 0`). Sau đó ta duyệt từ người thứ hai trở đi, hễ thấy ai điểm cao hơn cái người đang cầm cờ, ta lập tức giật cờ trao cho người mới (`viTriMax = i`). Chạy hết mảng, ai cầm cờ thì người đó là Max.
> `[📸 Hình ảnh ví dụ: Mô phỏng tìm Min/Max: Đặt một bục vinh quang. Đưa người đầu tiên lên bục. Đi xét từng người còn lại, nếu thấy ai cao hơn người trên bục thì đuổi người trên bục xuống và cho người cao hơn lên thay thế]`


* **Lọc dữ liệu (Filter):** Việc lọc bản chất chính là Tìm kiếm nhưng điều kiện lớn hơn. Thay vì `if (diem == 8)`, ta dùng `if (diem >= 8)` để in ra toàn bộ học sinh giỏi.
* **Thống kê:** Bằng cách gộp vòng lặp duyệt mảng với một biến `tong = 0` và biến `dem = 0`, ta có thể tính ra Tổng doanh thu, số lượng hóa đơn, và tính được giá trị Trung bình (Tổng / Số lượng).

### Buổi 27 - Bubble Sort chi tiết

**1. Mục tiêu buổi học**

* Hiểu Bubble Sort so sánh từng cặp phần tử liền kề.


* Biết đổi chỗ khi sai thứ tự.


* Biết số vòng lặp ngoài và vòng lặp trong.


* Biết tối ưu nhỏ bằng biến swapped.


* Biết sắp xếp vector theo điểm/giá.


* Học sinh viết được Bubble Sort tăng dần, giảm dần và giải thích từng bước.



**2. Lý thuyết chi tiết**

* **Cơ chế Nổi Bọt trên Struct:** Ở Buổi 13, ta sắp xếp một mảng các con số. Giờ đây, ta sắp xếp một danh sách các "đối tượng" (như Sản phẩm). Nguyên lý không đổi: Ta đem *Giá* của Sản phẩm `j` so sánh với *Giá* của Sản phẩm `j+1`. Nếu sai thứ tự, ta sẽ lấy 2 cái hộp Sản phẩm nguyên vẹn tráo đổi chỗ cho nhau (chứ không chỉ tráo cái nhãn giá tiền).
> `[📸 Hình ảnh ví dụ: Minh họa Bubble Sort trên danh sách Struct: 2 Khối hộp chứa toàn bộ dữ liệu (Mã, Tên, Điểm) bị nhấc lên và hoán đổi vị trí nguyên khối cho nhau khi Điểm của khối bên trái lớn hơn khối bên phải]`


* **Vòng lặp trong và ngoài:**
* Vòng `i` (ngoài): Đi bao nhiêu lượt? (Cần đi `n-1` lượt để mảng được sắp xếp).
* Vòng `j` (trong): Đi so sánh cặp liền kề. Chú ý điều kiện `j < n - i - 1` vì sau mỗi lượt `i`, những con số lớn nhất (hoặc nhỏ nhất) đã nằm gọn ở cuối mảng, ta không cần so sánh lại phần đuôi đó nữa.


* **Tối ưu với `swapped`:** Nếu danh sách đã được xếp đúng ngay từ đầu, vòng lặp chạy sẽ rất phí thời gian. Ta tạo một cờ hiệu `bool swapped`. Nếu qua 1 lượt vòng lặp mà không có cặp nào bị đổi chỗ (`swapped == false`), nghĩa là mảng đã hoàn hảo, ta cho dừng thuật toán ngay lập tức.

**3. Ví dụ minh họa**

* **Ví dụ 1: Bubble Sort xếp Học Sinh theo Điểm Tăng Dần**

```cpp
#include <iostream>
#include <vector>
#include <string>
using namespace std;

struct HocSinh { string ten; double diem; };

void sapXepTangDan(vector<HocSinh> &ds) {
    int n = ds.size();
    
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - i - 1; j++) {
            // So sánh tiêu chí: Điểm số
            if (ds[j].diem > ds[j+1].diem) { 
                // Sai thứ tự -> Hoán đổi toàn bộ CẤU TRÚC struct
                HocSinh tam = ds[j];
                ds[j] = ds[j+1];
                ds[j+1] = tam;
            }
        }
    }
    cout << "Da sap xep danh sach tang dan theo diem!\n";
}

```

* **Ví dụ 2: Bubble Sort Tối ưu (Xếp giảm dần)**

```cpp
void sapXepGiamDan_ToiUu(vector<HocSinh> &ds) {
    int n = ds.size();
    bool daDoiCho; // Cờ hiệu tối ưu
    
    for (int i = 0; i < n - 1; i++) {
        daDoiCho = false; 
        
        for (int j = 0; j < n - i - 1; j++) {
            if (ds[j].diem < ds[j+1].diem) { // Đổi dấu < để xếp giảm dần
                HocSinh tam = ds[j];
                ds[j] = ds[j+1];
                ds[j+1] = tam;
                daDoiCho = true; // Ghi nhận là có sự đổi chỗ
            }
        }
        
        // Nếu duyệt qua 1 vòng mà không đổi chỗ ai, mảng đã đúng thứ tự
        if (daDoiCho == false) {
            break; 
        }
    }
    cout << "Da sap xep danh sach giam dan toi uu!\n";
}

```

### Buổi 28 - Selection Sort và Insertion Sort

**1. Mục tiêu buổi học**

* Hiểu Selection Sort chọn phần tử nhỏ/lớn nhất đưa về đúng vị trí.


* Hiểu Insertion Sort chèn phần tử vào dãy đã sắp xếp.


* Biết so sánh hai cách sắp xếp bằng mô phỏng từng bước.


* Biết sắp xếp danh sách số và danh sách struct.


* Biết khi nào code sắp xếp tự viết giúp học sinh hiểu bản chất.


* Học sinh viết được Selection Sort và Insertion Sort cơ bản.



**2. Lý thuyết chi tiết**

* **Selection Sort (Sắp xếp chọn):** Nếu Bubble Sort là đổi chỗ liên tục các cặp đứng cạnh nhau, thì Selection Sort tĩnh lặng hơn. Nó dùng vòng lặp nhìn lướt qua toàn bộ mảng để TÌM ra phần tử nhỏ nhất. Sau đó, nó mới tiến hành đổi chỗ phần tử đó với vị trí đầu tiên. Cứ như thế tìm cái nhỏ nhì, nhỏ ba... Thuật toán này số lần hoán đổi (Swap) ít hơn hẳn Bubble Sort.
* **Insertion Sort (Sắp xếp chèn):** Đây là cách bạn chơi bài Tiến Lên. Khi bạn rút một lá bài mới lên, bạn nhìn dãy bài đang có trên tay, trượt lá bài mới dọc theo dãy, và "nhét" nó vào đúng khe hở giữa hai lá bài sao cho giữ nguyên thứ tự.
> `[📸 Hình ảnh ví dụ: Mô phỏng người chơi bài Tiến lên. Trên tay cầm dãy bài (3, 5, 8). Rút được lá bài 6. Lá bài 6 được trượt qua số 8 và chèn vào khe giữa số 5 và số 8 (Minh họa Insertion Sort)]`


* **So sánh:**
* *Bubble Sort:* Dễ viết nhất, nhưng chạy chậm nhất nếu mảng bị ngược hoàn toàn.
* *Selection Sort:* Dễ tư duy (Tìm Min -> Swap), số lần tráo đổi ít, tốt cho mảng mà việc "nhấc lên hạ xuống" tốn sức.
* *Insertion Sort:* Chạy cực nhanh (gần như tức thì) nếu mảng *gần như đã sắp xếp xong*.



**3. Ví dụ minh họa**

* **Ví dụ 1: Selection Sort trên Struct (Xếp Giảm dần theo Điểm)**

```cpp
#include <iostream>
#include <vector>
#include <string>
using namespace std;

struct HocSinh { string ten; double diem; };

void selectionSortGiamDan(vector<HocSinh> &ds) {
    int n = ds.size();
    
    // Chỉ cần đi đến phần tử kế cuối
    for (int i = 0; i < n - 1; i++) {
        int viTriMax = i; // Đặt niềm tin ban đầu
        
        // Đi tìm phần tử có điểm cao nhất trong phần còn lại
        for (int j = i + 1; j < n; j++) {
            if (ds[j].diem > ds[viTriMax].diem) {
                viTriMax = j; // Cập nhật người cao điểm hơn
            }
        }
        
        // Hoán đổi 1 lần duy nhất sau khi đã duyệt xong
        if (viTriMax != i) {
            HocSinh tam = ds[i];
            ds[i] = ds[viTriMax];
            ds[viTriMax] = tam;
        }
    }
}

```

* **Ví dụ 2: Insertion Sort Cơ bản (Xếp Tăng dần theo Điểm)**

```cpp
void insertionSortTangDan(vector<HocSinh> &ds) {
    int n = ds.size();
    
    // Bắt đầu từ lá bài thứ hai (index 1)
    for (int i = 1; i < n; i++) {
        HocSinh baiRutLen = ds[i]; // Rút lá bài i lên
        int j = i - 1;
        
        // Dời các lá bài lớn hơn về bên phải để tạo khe trống
        while (j >= 0 && ds[j].diem > baiRutLen.diem) {
            ds[j + 1] = ds[j]; // Trượt bài sang phải
            j = j - 1;
        }
        
        // Nhét lá bài vừa rút vào khe hở tìm được
        ds[j + 1] = baiRutLen; 
    }
}

```

### Buổi 29 - Binary Search (Tìm kiếm nhị phân)

**1. Mục tiêu buổi học**

* Hiểu Binary Search chỉ dùng khi dữ liệu đã sắp xếp.


* Biết biến left, right, mid.


* Biết cập nhật khoảng tìm kiếm sau mỗi lần so sánh.


* Biết xử lý tìm thấy và không tìm thấy.


* Biết so sánh Binary Search với Linear Search.


* Học sinh viết được Binary Search trên mảng/vector số đã sắp xếp.



**2. Lý thuyết chi tiết**

* 
**Điều kiện bắt buộc:** Binary Search (Tìm kiếm nhị phân) chạy cực kỳ nhanh, nhưng nó có một điểm yếu chí mạng: Dữ liệu bắt buộc phải được sắp xếp trước đó thì thuật toán mới hoạt động đúng.


* **Ý tưởng thuật toán:** Tương tự như cách bạn tra từ điển. Nếu muốn tìm từ "Lập trình", bạn không lật từng trang từ đầu đến cuối (Linear Search). Bạn mở ngay giữa cuốn sách (biến `mid`). Nếu trang giữa là vần "M", bạn biết chắc chữ "L" nằm ở nửa bên trái. Bạn lập tức xé bỏ nửa bên phải (cập nhật lại `right`), và tiếp tục chia đôi nửa bên trái.


> `[📸 Hình ảnh ví dụ: Mô phỏng Binary Search: Một cuốn từ điển đang được lật mở ở chính giữa. Các biến Left (chỉ trang đầu), Right (chỉ trang cuối) và Mid (chỉ trang giữa) đang di chuyển thu hẹp phạm vi tìm kiếm]`


* **Ba biến kiểm soát:**
* 
`left`: Vị trí đầu tiên của phạm vi tìm kiếm.


* 
`right`: Vị trí cuối cùng của phạm vi tìm kiếm.


* 
`mid`: Vị trí nằm ngay chính giữa (`(left + right) / 2`).




* **Vòng lặp:** Quá trình chia đôi lặp lại chừng nào `left <= right`. Nếu `left` vượt qua `right`, nghĩa là phạm vi tìm kiếm đã thu hẹp đến mức biến mất (không tìm thấy).



**3. Ví dụ minh họa**

* **Ví dụ 1: Cài đặt Binary Search trên danh sách số**

```cpp
#include <iostream>
#include <vector>
using namespace std;

int binarySearch(vector<int> ds, int x) {
    int left = 0;
    int right = ds.size() - 1;
    
    // Lặp khi phạm vi tìm kiếm vẫn còn hợp lệ
    while (left <= right) {
        int mid = (left + right) / 2; // Tìm điểm giữa
        
        if (ds[mid] == x) {
            return mid; // Tìm thấy, trả về vị trí
        } else if (ds[mid] < x) {
            left = mid + 1; // x lớn hơn số ở giữa, vứt bỏ nửa bên trái
        } else {
            right = mid - 1; // x nhỏ hơn số ở giữa, vứt bỏ nửa bên phải
        }
    }
    return -1; // Không tìm thấy
}

int main() {
    // Mảng bắt buộc phải có thứ tự tăng dần
    vector<int> danhSach = {2, 5, 8, 12, 16, 23, 38, 56, 72, 91};
    int soCanTim = 23;
    
    int ketQua = binarySearch(danhSach, soCanTim);
    if (ketQua != -1) cout << "Tim thay " << soCanTim << " tai vi tri " << ketQua << "\n";
    else cout << "Khong tim thay!\n";
    
    return 0;
}

```

* **Bài 1:** Viết chương trình có mảng `{10, 20, 30, 40, 50, 60}`. Yêu cầu người dùng nhập số cần tìm và dùng Binary Search để tìm.
* **Bài 2:** Thử xáo trộn mảng ở Bài 1 thành `{50, 20, 60, 10, 30, 40}`. Chạy lại Binary Search và quan sát xem hàm có tìm ra kết quả đúng không để hiểu rõ lý do phải sắp xếp trước.

### Buổi 30 - std::sort và comparator

* Biết sort vector số tăng dần, giảm dần.


* Biết viết comparator cho struct.


* Biết sắp xếp theo một tiêu chí: điểm, tên, giá.

* Học sinh viết được sắp xếp danh sách học sinh/sản phẩm bằng std::sort.



**2. Lý thuyết chi tiết**

* 
**Tại sao cần `std::sort`?** Những thuật toán Bubble Sort hay Selection Sort rất tuyệt để rèn luyện tư duy thuật toán. Tuy nhiên, trong môi trường làm việc thực tế, dữ liệu có thể lên tới hàng triệu dòng. Các lập trình viên C++ luôn sử dụng hàm `std::sort` có sẵn vì nó siêu tốc và ổn định.


* **Thư viện `<algorithm>`:** Để gọi được `std::sort`, bắt buộc phải include thư viện này.
* **Cú pháp cơ bản:** `sort(vector.begin(), vector.end());` (Tự động sắp xếp tăng dần).
* **Hàm so sánh (Comparator):** Khi sắp xếp những con số, C++ biết số 5 lớn hơn 3. Nhưng khi bạn sắp xếp một Danh sách `HocSinh` (Struct), C++ sẽ bị bối rối vì không biết nên xếp theo Điểm, xếp theo Mã hay xếp theo Tên. Lúc này ta phải tự viết một hàm "trọng tài" (Comparator) để dạy C++ cách so sánh 2 học sinh.


> `[📸 Hình ảnh ví dụ: Một cái cân đĩa (Comparator) đang đặt 2 khối Struct HocSinh lên 2 bên. Hình ảnh minh họa việc lập trình viên đang dạy chiếc cân đó chỉ quan tâm đến trọng lượng của hộp (Điểm số) để quyết định bên nào nặng hơn]`

* **Ví dụ 2: Dùng Comparator xếp Danh sách Struct**

```cpp

#include <vector>
#include <string>
#include <algorithm>
```

### Buổi 32 - Sắp xếp nhiều tiêu chí

**1. Mục tiêu buổi học**

* Biết sắp xếp theo giá tăng dần, nếu bằng giá thì mã tăng dần.


* Biết trình bày kết quả sau sắp xếp.


* Biết tránh comparator sai logic.


* Học sinh viết được sắp xếp danh sách struct theo 2 tiêu chí.



**2. Lý thuyết chi tiết**

* **Xung đột khi xếp hạng:** Trong thực tế, có rất nhiều học sinh đạt cùng 9.0 điểm. Nếu chỉ sắp xếp theo điểm, thứ tự của các bạn đồng điểm sẽ lộn xộn. Lúc này ta cần Tiêu chí phụ (Tiêu chí 2): "Xếp theo điểm từ cao xuống thấp. Nhưng nếu 2 bạn bằng điểm nhau, thì xét tên theo bảng chữ cái A-Z".
* **Xây dựng Logic Comparator:** Ta dùng cấu trúc `if - else if` bên trong hàm Comparator.
* `if (diem khác nhau)` -> Xếp theo điểm.
* 
`if (diem bằng nhau)` -> Đi xem xét đến tên.




* **Lỗi logic kinh điển (Sai Luật Trọng Tài):** Hàm Trọng tài phải trả về `false` nếu a và b hoàn toàn giống nhau. Đừng bao giờ viết `return a.diem >= b.diem;`. Chỉ được dùng dấu `>` hoặc `<` nghiêm ngặt, tuyệt đối không dùng `>=` hay `<=` trong Comparator của `std::sort`. Nếu cố tình dùng, chương trình sẽ báo lỗi "Segmentation Fault" (Lỗi bộ nhớ).


> `[📸 Hình ảnh ví dụ: Sơ đồ luồng (Flowchart) của Comparator nhiều tiêu chí. Kim cương 1: So sánh Điểm -> Nếu bằng nhau rẽ sang Kim cương 2: So sánh Tên -> Trả về Kết quả True/False]`



**3. Ví dụ minh họa**

* **Ví dụ 1: Comparator 2 tiêu chí (Giá tăng dần, Mã tăng dần)**

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
using namespace std;

struct SanPham { int ma; string ten; int gia; };

// Trọng tài xử lý 2 tiêu chí
bool soSanh2TieuChi(SanPham a, SanPham b) {
    if (a.gia != b.gia) {
        // Tiêu chí 1: Nếu giá khác nhau, xếp giá tăng dần
        return a.gia < b.gia; 
    } else {
        // Tiêu chí 2: Nếu giá bằng nhau, xếp theo Mã số tăng dần
        return a.ma < b.ma; 
    }
}

int main() {
    vector<SanPham> ds = {
        {105, "Vo tap", 10000},
        {101, "But bi", 5000},
        {103, "But chi", 5000}, // Đồng giá với Bút bi
        {102, "Gom", 8000}
    };
    
    sort(ds.begin(), ds.end(), soSanh2TieuChi);
    
    cout << "--- DANH SACH SAU KHI XEP ---\n";
    for (int i = 0; i < ds.size(); i++) {
        // In định dạng thẳng cột, dễ nhìn
        cout << "- Ma: " << ds[i].ma << " | Gia: " << ds[i].gia << " | Ten: " << ds[i].ten << "\n";
    }
    return 0;
}

```

*Giải thích:* Nhờ Comparator nhiều tiêu chí, sản phẩm `But bi` (Mã 101) sẽ được xếp tự động nằm trên `But chi` (Mã 103) mặc dù cả 2 đồng giá 5000.

**4. Bài tập thực hành trên lớp**

* **Bài 1:** Viết Comparator xếp danh sách Sinh viên: Tiêu chí 1 là Điểm số Giảm Dần. Nếu Điểm số bằng nhau, xét Tiêu chí 2 là Tên Tăng Dần (A->Z).
* **Bài 2:** (Tìm lỗi) Cho đoạn code `bool cmp(HocSinh a, HocSinh b) { return a.diem >= b.diem; }`. Hãy chỉ ra tại sao nó sai logic và sửa lại cho đúng quy tắc của C++.

* **Skeleton Code (Code khung xương):** Là viết sẵn vỏ bọc của các hàm nhưng bên trong chưa có logic tính toán. Việc này giúp chương trình chạy được Menu ngay lập tức mà chưa cần code chi tiết.

**3. Ví dụ minh họa (Tạo Skeleton Code)**

```cpp
#include <iostream>
#include <vector>
#include <string>
using namespace std;

// 1. DỮ LIỆU
struct Sach { int ma; string ten; };
vector<Sach> thuVien;

// 2. KHUNG HÀM (Chưa có ruột)
void hienThiMenu() {
    cout << "\n--- QUAN LY THU VIEN ---\n";
    cout << "1. Xem sach\n2. Them sach\n0. Thoat\n";
    cout << "Chon: ";
}

void xemSach() {
    cout << "[He thong]: Dang in danh sach...\n"; // Thông báo giả
}

void themSach() {
    cout << "[He thong]: Dang mo chuc nang them...\n";
}

// 3. MAIN (Điều phối)
int main() {
    int chon;
    do {
        hienThiMenu();
        cin >> chon;
        switch (chon) {
            case 1: xemSach(); break;
            case 2: themSach(); break;
            case 0: cout << "Tam biet!\n"; break;
            default: cout << "Nhap sai!\n"; break;
        }
    } while (chon != 0);
    return 0;
}

```

### Buổi 40 - Bảo vệ sản phẩm cuối khóa

**1. Mục tiêu buổi học**

* Học sinh tự tin demo được sản phẩm chạy trực tiếp trên máy tính.


* Học sinh giải thích được bài toán, cấu trúc dữ liệu, chức năng và các đoạn code chính.


* Học sinh trả lời được các câu hỏi chất vấn: dùng struct nào, vector lưu gì, hàm nào quan trọng, tìm kiếm/sắp xếp ở đâu.


* Học sinh trình bày được những lỗi (Bugs) đã gặp phải trong quá trình làm và cách tự sửa lỗi.


* Học sinh nêu được điểm mạnh, hạn chế của app và hướng phát triển tiếp theo (nếu có thời gian).


* Hoàn thiện 100% yêu cầu sản phẩm cuối khóa: code chạy được, menu rõ ràng, có dữ liệu mẫu, demo ổn định và phần bảo vệ ngắn gọn.



**2. Tiêu chí chấm điểm Bảo vệ (Giáo viên phổ biến)**

* **Kỹ năng Lập trình (50%):** Code chạy không bị văng lỗi (Crash). Có sử dụng đủ `struct`, `vector`, `hàm`, và 1 thuật toán Sắp xếp / Tìm kiếm.


* 
**Kỹ năng Trình bày (30%):** Demo rõ ràng, nói to, đúng trọng tâm kịch bản.


* **Kỹ năng Hỏi - Đáp (20%):** Hiểu mình đang code gì, không copy bài trên mạng. Trả lời được cách khắc phục lỗi.


> `[📸 Hình ảnh ví dụ: Một bảng tiêu chí chấm điểm (Rubric) với 3 cột: Kỹ năng Lập trình, Kỹ năng Trình bày, Kỹ năng Hỏi đáp cùng các thang điểm minh họa]`



**3. Khung câu hỏi thường gặp khi Bảo vệ (Dành cho học sinh ôn tập)**

* **Câu 1:** "Hàm tìm kiếm của em trả về giá trị gì?" -> Trả lời: Trả về vị trí (index `i`) của phần tử trong mảng `vector`, nếu không thấy thì trả về `-1`.


* **Câu 2:** "Em gặp khó khăn gì lớn nhất khi làm dự án này?" -> Trả lời: Em hay bị lỗi Trôi lệnh khi nhập chữ và số xen kẽ. Sau đó em đã tự sửa bằng cách thêm `cin.ignore()`.


* **Câu 3:** "Nếu sau này có nhiều thời gian hơn, em muốn cải tiến gì?" -> Trả lời: Em muốn làm thêm một chức năng lọc danh sách theo ngày tháng, và làm giao diện màu sắc hơn thay vì chỉ toàn chữ trắng đen.
