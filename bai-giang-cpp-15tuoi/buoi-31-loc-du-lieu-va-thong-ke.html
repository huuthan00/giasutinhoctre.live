Buổi 31: Lọc dữ liệu và thống kê

Bài giảng chi tiết cho tiết học 90 phút: lý thuyết, ví dụ code, giải thích từng bước, bài tập trên lớp và bài tập về nhà.

Lý thuyếtNội dung được triển khai chi tiết theo từng khái niệm.
Code mẫuCác ví dụ C++ console có giải thích từng bước.
Thực hànhBài tập trên lớp và bài tập về nhà rõ yêu cầu.

1. Mục tiêu buổi học

  • Biết in báo cáo thống kê gọn, dễ đọc.
  • Biết kết hợp lọc với tìm kiếm và sắp xếp.
  • Biết kiểm tra danh sách rỗng trước khi thống kê.
  • Học sinh viết được chức năng báo cáo thống kê cho mini app.

2. Lý thuyết chi tiết

  • Thống kê chuyên sâu: Khi ứng dụng quản lý đã lớn, người chủ không muốn xem danh sách hàng ngàn sản phẩm. Họ chỉ muốn xem: "Có bao nhiêu món dưới 100k?", "Tổng tiền hàng hiện tại là bao nhiêu?".
  • Kiểm tra rỗng: Nguyên tắc sinh tồn khi viết hàm thống kê: Luôn luôn kiểm tra if (ds.size() == 0) { báo lỗi và return; } ngay dòng đầu tiên. Nếu mảng trống mà ta lại đem chia cho số lượng để tìm Trung bình, phần mềm sẽ báo lỗi chia cho 0 và sập ngay lập tức.

In báo cáo (Reporting): Báo cáo phải gọn gàng, chia thành các phần rõ rệt, kết hợp những đường viền đẹp mắt bằng các dấu = hay - trên màn hình console.

Minh họa chi tiết

Ý tưởng trực quan: Một mẫu Dashboard (bảng điều khiển) mini bằng giao diện đen trắng Console. Hiển thị dòng viền ngang ============, Tổng doanh thu, Số lượng SP và Trung bình giá nằm canh hàng dọc ngăn nắp

  • Cách trình bày: Vẽ màn hình console có tiêu đề, đường kẻ, các dòng thống kê canh hàng: tổng, số lượng, trung bình.
  • Ví dụ thao tác: Dùng setw để căn cột khi in Ten, So luong, Gia, Thanh tien.
  • Điểm cần chốt: Chốt rằng output đẹp giúp demo sản phẩm dễ hiểu và chuyên nghiệp hơn.
  • Câu hỏi kiểm tra nhanh: Thông tin thống kê nào nên đặt ở đầu báo cáo để người xem nắm nhanh tình hình?

3. Ví dụ minh họa

Ví dụ 1: Viết module Báo cáo Thống kê An toàn

#include <iostream>
#include <vector>
#include <string>
using namespace std;

struct SanPham { string ten; int gia; int soLuong; };

void inBaoCaoThongKe(vector<SanPham> ds) {
    // 1. Kiểm tra mảng rỗng
    if (ds.size() == 0) {
        cout << "Kho hang dang trong, khong the thong ke!\n";
        return;
    }

    // 2. Tính toán
    double tongGiaTriKho = 0;
    int spGiaRe = 0; // Đếm số sản phẩm dưới 50k

    for (int i = 0; i < ds.size(); i++) {
        tongGiaTriKho += (ds[i].gia * ds[i].soLuong);
        if (ds[i].gia < 50000) spGiaRe++;
    }

    // 3. Trình bày gọn, dễ đọc
    cout << "\n====================================\n";
    cout << "       BAO CAO THONG KE KHO        \n";
    cout << "====================================\n";
    cout << "- Tong mat hang: " << ds.size() << "\n";
    cout << "- Tong gia tri kho: " << tongGiaTriKho << " VND\n";
    cout << "- So luong mat hang gia re (< 50k): " << spGiaRe << "\n";
    cout << "====================================\n";
}

Ví dụ 2: Kết hợp Lọc và Sắp xếp

#include <algorithm> // Để gọi lệnh sort
// Viết comparator sắp xếp số lượng giảm dần
bool theoSoLuong(SanPham a, SanPham b) { return a.soLuong > b.soLuong; }

void thongKeTonKhoNhieu(vector<SanPham> ds) {
    // 1. Lọc: Nhét các sản phẩm thỏa điều kiện vào một danh sách tạm
    vector<SanPham> dsLoc;
    for (int i = 0; i < ds.size(); i++) {
        if (ds[i].soLuong > 100) { // Tồn kho lớn
            dsLoc.push_back(ds[i]);
        }
    }

    // 2. Sắp xếp danh sách tạm đó
    sort(dsLoc.begin(), dsLoc.end(), theoSoLuong);

    // 3. In ra Báo cáo
    cout << "\n--- TOP HANG TON KHO NHIEU ---\n";
    for (int i = 0; i < dsLoc.size(); i++) {
        cout << dsLoc[i].ten << " (Ton: " << dsLoc[i].soLuong << ")\n";
    }
}

4. Bài tập thực hành trên lớp

  • Bài 1: Khởi tạo một vector<HocSinh> chứa danh sách 5 bạn (Mã, Tên, Điểm). Viết hàm thống kê in ra màn hình Bảng báo cáo gồm: Tổng số học sinh Khá Giỏi (>= 6.5), Tổng số học sinh cần Cố gắng (< 6.5), và Điểm trung bình của toàn lớp.
  • Bài 2: Thử truyền một vector trống không có phần tử nào vào hàm ở Bài 1, quan sát xem hàm báo lỗi an toàn (nhờ size() == 0) hay bị sập (crash).
