Buổi 01: Làm quen C++ và môi trường lập trình

Bài giảng chi tiết cho tiết học 90 phút: lý thuyết, ví dụ code, giải thích từng bước, bài tập trên lớp và bài tập về nhà.

Lý thuyếtNội dung được triển khai chi tiết theo từng khái niệm.
Code mẫuCác ví dụ C++ console có giải thích từng bước.
Thực hànhBài tập trên lớp và bài tập về nhà rõ yêu cầu.

1. Mục tiêu buổi học

  • Hiểu file .cpp chính là file mã nguồn của C++.
  • Hiểu được quá trình cơ bản: viết code, biên dịch (compile) và chạy chương trình.
  • Nắm được cấu trúc tối thiểu của một chương trình C++ gồm: #include <iostream>, using namespace std, int main(), return 0.
  • Biết cách dùng cout, endl, \n để in thông tin ra màn hình console.
  • Biết đọc và tự sửa các lỗi cơ bản như: thiếu dấu ;, thiếu dấu ngoặc, hoặc viết sai chữ hoa/chữ thường.
  • Học sinh tự viết được một chương trình in thông tin cá nhân và giải thích được từng dòng code.

2. Lý thuyết chi tiết

  • Ngôn ngữ lập trình và Biên dịch là gì? Máy tính không hiểu tiếng người, nó chỉ hiểu mã máy (các số 0 và 1). C++ là ngôn ngữ giúp ta viết lệnh cho máy tính đọc (lưu vào file .cpp). Trình biên dịch (Compiler) giống như một người phiên dịch, dịch mã C++ sang ngôn ngữ máy để máy tính chạy.
Minh họa chi tiết

Ý tưởng trực quan: Sơ đồ minh họa File .cpp -> Trình biên dịch (Bánh răng) -> File chạy .exe / Màn hình đen Console

  • Cách trình bày: Vẽ 3 ô lớn theo chiều trái sang phải: hello.cpp -> Compiler -> hello.exe / Console. Cho học sinh tự điền mũi tên Viết code, Biên dịch, Chạy.
  • Ví dụ thao tác: Dùng chương trình cout << "Xin chao";, sau đó cố tình xóa dấu ; để chỉ ra lỗi nằm ở bước biên dịch, chưa phải lỗi khi chạy.
  • Điểm cần chốt: Chốt rằng C++ không chạy trực tiếp file .cpp; code phải qua compiler trước.
  • Câu hỏi kiểm tra nhanh: Nếu chương trình báo lỗi trước khi hiện màn hình console, lỗi đang ở giai đoạn nào?

Cấu trúc một chương trình C++: Bất kỳ chương trình C++ nào cũng cần một bộ khung cơ bản.

#include <iostream>: Khai báo thư viện giúp ta nhập và xuất dữ liệu (in chữ ra màn hình).

using namespace std;: Sử dụng không gian tên chuẩn để không phải viết dài dòng sau này.

  • int main() { ... }: "Cánh cửa" bắt đầu của mọi chương trình. Code của bạn sẽ viết bên trong hai dấu ngoặc nhọn { } này.

return 0;: Báo hiệu chương trình đã kết thúc thành công.

  • In chữ ra màn hình: Dùng lệnh cout << "Nội dung cần in";. Để xuống dòng, ta có thể thêm \n vào trong ngoặc kép hoặc dùng << endl ở cuối.
Minh họa chi tiết

Ý tưởng trực quan: So sánh màn hình console khi có lệnh endl và khi không có lệnh endl

  • Cách trình bày: Vẽ hai khung console đặt cạnh nhau: khung 1 in ba câu dính liền, khung 2 in ba câu mỗi câu một dòng.
  • Ví dụ thao tác: So sánh cout << "A" << "B";, cout << "A\nB"; và cout << "A" << endl << "B";.
  • Điểm cần chốt: Chốt rằng endl và \n đều giúp xuống dòng, nhưng phải đặt đúng vị trí trong output.
  • Câu hỏi kiểm tra nhanh: Nếu muốn in họ tên ở dòng 1, lớp ở dòng 2, cần thêm gì vào câu lệnh cout?
  • Các lỗi thường gặp (Lỗi cú pháp): Máy tính rất nghiêm khắc. Nếu bạn quên dấu chấm phẩy ; ở cuối lệnh, quên ngoặc }, hay viết Cout thay vì cout (C++ phân biệt chữ hoa, chữ thường), chương trình sẽ báo lỗi (chữ màu đỏ).

3. Ví dụ minh họa

Ví dụ 1: Xin chào thế giới! (Chương trình C++ đầy đủ đầu tiên)

#include <iostream>
using namespace std;

int main() {
    cout << "Xin chao the gioi!" << endl;
    return 0;
}

Giải thích từng bước:
Dòng 1-2: Gọi thư viện chuẩn để chuẩn bị xuất chữ.
Dòng 4: Bắt đầu thân chương trình main.
Dòng 5: Lệnh cout đẩy dòng chữ "Xin chao the gioi!" ra màn hình. endl giúp con trỏ nhấp nháy chuyển xuống dòng mới. Lưu ý dấu ; ở cuối.
Dòng 6: Báo chương trình kết thúc tốt đẹp.

Ví dụ 2: In nhiều dòng thông tin cá nhân

#include <iostream>
using namespace std;

int main() {
    cout << "Ho va ten: Nguyen Van A\n";
    cout << "Nam nay minh 15 tuoi." << endl;
    cout << "So thich: Choi game, Lap trinh.";
    return 0;
}

Giải thích từng bước:
Ta dùng \n ngay bên trong chuỗi ở dòng 5 để xuống dòng. Dòng 6 dùng endl. Dòng 7 không xuống dòng. Cả 2 cách \n và endl đều giúp văn bản không bị dính liền vào nhau.

Ví dụ 3: Đọc và sửa lỗi thiếu dấu chấm phẩy

#include <iostream>
using namespace std;

int main() {
    cout << "Toi dang hoc sua loi" // LỖI: Thiếu dấu chấm phẩy
    return 0;
}

Giải thích: Khi chạy, màn hình sẽ hiện lỗi đỏ chỉ vào dòng chữ return 0; báo rằng "expected ';' before return". Học sinh cần nhìn lên dòng ngay trước đó và thêm ; vào cuối lệnh cout.

4. Bài tập thực hành trên lớp

  • Bài 1: Viết chương trình in ra họ tên, tuổi và trường học của em trên 3 dòng khác nhau.
  • Bài 2: Vẽ một hình chữ nhật bằng các dấu * in ra màn hình console (Gợi ý: Dùng 3 lệnh cout liên tiếp với cấu trúc cout << "*\n";).
  • Bài 3: Giáo viên cung cấp một đoạn code bị thiếu 2 dấu ; và bị viết sai chữ int Main(). Học sinh hãy tìm, sửa lại và chạy thành công.

5. Bài tập về nhà

  • Bài 1: Viết chương trình in ra thời khóa biểu ngày Mai của em (Gồm: Tiết 1, Tiết 2, Tiết 3...).
  • Bài 2: Dùng lệnh cout thiết kế một bức thư ngắn hoặc một bài thơ 4 dòng gửi cho bạn thân. Chú ý sử dụng endl hoặc \n để trình bày đẹp mắt.

6. Checklist cuối buổi

Học sinh tự trả lời các câu hỏi:

  • File .cpp chứa gì và phải làm gì để chạy được nó?
  • 4 thành phần bắt buộc phải có của một chương trình C++ là gì?
  • Lệnh nào dùng để in ra màn hình? Lệnh nào để xuống dòng?
  • Tôi đã tự sửa được lỗi quên dấu ; chưa?
