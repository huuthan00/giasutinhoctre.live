Buổi 26: Tìm min, max và lọc dữ liệu

Bài giảng chi tiết cho tiết học 90 phút: lý thuyết, ví dụ code, giải thích từng bước, bài tập trên lớp và bài tập về nhà.

1. Mục tiêu buổi học

  • Biết tìm giá trị lớn nhất, nhỏ nhất trong danh sách.
  • Biết tìm đối tượng có điểm/giá cao nhất hoặc thấp nhất.
  • Biết lọc các phần tử thỏa điều kiện.
  • Biết đếm số lượng phần tử thỏa điều kiện.
  • Biết tính trung bình trên danh sách.
  • Học sinh viết được thống kê cơ bản cho danh sách dữ liệu.

2. Lý thuyết chi tiết

  • Thuật toán Tìm Min / Max: Để tìm học sinh cao điểm nhất, ta không so sánh điểm của một bạn với 10, mà ta đặt "Niềm tin" vào bạn đầu tiên trong danh sách (Cắm cờ viTriMax = 0). Sau đó ta duyệt từ người thứ hai trở đi, hễ thấy ai điểm cao hơn cái người đang cầm cờ, ta lập tức giật cờ trao cho người mới (viTriMax = i). Chạy hết mảng, ai cầm cờ thì người đó là Max.
Minh họa chi tiết

Ý tưởng trực quan: Mô phỏng tìm Min/Max: Đặt một bục vinh quang. Đưa người đầu tiên lên bục. Đi xét từng người còn lại, nếu thấy ai cao hơn người trên bục thì đuổi người trên bục xuống và cho người cao hơn lên thay thế

  • Cách trình bày: Vẽ một bục max hiện tại. Đặt phần tử đầu tiên lên bục, sau đó từng phần tử còn lại thách đấu.
  • Ví dụ thao tác: Dùng dãy 7, 3, 9, 5: bắt đầu max = 7, gặp 9 thì thay max, gặp 5 thì giữ nguyên.
  • Điểm cần chốt: Chốt rằng tìm min/max cần một biến lưu ứng viên tốt nhất hiện tại.
  • Câu hỏi kiểm tra nhanh: Vì sao không nên khởi tạo max bằng 0 nếu dữ liệu có thể toàn số âm?
  • Lọc dữ liệu (Filter): Việc lọc bản chất chính là Tìm kiếm nhưng điều kiện lớn hơn. Thay vì if (diem == 8), ta dùng if (diem >= 8) để in ra toàn bộ học sinh giỏi.
  • Thống kê: Bằng cách gộp vòng lặp duyệt mảng với một biến tong = 0 và biến dem = 0, ta có thể tính ra Tổng doanh thu, số lượng hóa đơn, và tính được giá trị Trung bình (Tổng / Số lượng).

3. Ví dụ minh họa

Ví dụ 1: Tìm đối tượng có giá trị lớn nhất (Max)

#include <iostream>
#include <vector>
#include <string>
using namespace std;

struct SanPham { string ten; int gia; };

void timSanPhamDatNhat(vector<SanPham> ds) {
    if (ds.size() == 0) return; // Bảo vệ nếu danh sách trống

    int viTriMax = 0; // Giả sử SP đầu tiên (index 0) là đắt nhất

    for (int i = 1; i < ds.size(); i++) {
        // So sánh giá của phần tử i với giá của phần tử đang giữ kỷ lục
        if (ds[i].gia > ds[viTriMax].gia) {
            viTriMax = i; // Cập nhật lại kỷ lục mới
        }
    }

    cout << "San pham dat nhat la: " << ds[viTriMax].ten
         << " voi gia " << ds[viTriMax].gia << " VND\n";
}

Ví dụ 2: Lọc dữ liệu thỏa điều kiện (Filter)

void locSanPhamGiaRe(vector<SanPham> ds) {
    int mucGia;
    cout << "Ban muon tim SP duoi muc gia bao nhieu? ";
    cin >> mucGia;

    cout << "--- CAC SAN PHAM PHU HOP ---\n";
    for (int i = 0; i < ds.size(); i++) {
        if (ds[i].gia <= mucGia) {
            cout << ds[i].ten << " - Gia: " << ds[i].gia << "\n";
        }
    }
}

Ví dụ 3: Đếm và tính trung bình

void thongKeGiaTri(vector<SanPham> ds) {
    if (ds.size() == 0) {
        cout << "Kho hang trong!\n"; return;
    }

    double tongGia = 0;
    for (int i = 0; i < ds.size(); i++) {
        tongGia = tongGia + ds[i].gia;
    }

    double trungBinh = tongGia / ds.size();
    cout << "Tong so luong san pham: " << ds.size() << "\n";
    cout << "Tong gia tri kho hang: " << tongGia << "\n";
    cout << "Gia trung binh 1 SP: " << trungBinh << "\n";
}

4. Bài tập thực hành trên lớp

  • Bài 1: Viết hàm tìm Học sinh có điểm thấp nhất (Min) trong vector<HocSinh>. In ra tên và điểm của học sinh đó.
  • Bài 2: Viết hàm thống kê (Lọc): Duyệt qua danh sách học sinh và đếm xem có bao nhiêu bạn phải thi lại (Điểm < 5.0).
  • Bài 3: Kết hợp lại: Tìm và in ra điểm trung bình của toàn bộ lớp, sau đó in ra danh sách những bạn có điểm LỚN HƠN điểm trung bình của lớp.
