Buổi 18: Kiểm thử hàm và menu console

Bài giảng chi tiết cho tiết học 90 phút: lý thuyết, ví dụ code, giải thích từng bước, bài tập trên lớp và bài tập về nhà.

Lý thuyếtNội dung được triển khai chi tiết theo từng khái niệm.
Code mẫuCác ví dụ C++ console có giải thích từng bước.
Thực hànhBài tập trên lớp và bài tập về nhà rõ yêu cầu.

1. Mục tiêu buổi học

  • Hiểu cần test hàm bằng dữ liệu mẫu và biết viết menu console có nhiều chức năng.
  • Biết tách mỗi lựa chọn trong menu thành một hàm và biết xử lý lựa chọn sai.
  • Biết lặp menu đến khi người dùng chọn thoát và học sinh viết được menu quản lý nhỏ có 3-4 chức năng.
  • Đáp ứng thời lượng 90 phút qua các ví dụ gắn với học sinh.

2. Lý thuyết chi tiết

  • Kiểm thử hàm (Testing): Sau khi viết xong một hàm tính toán, ta không nên viết vội các hàm khác. Hãy gọi hàm đó ngay trong main và nhét thử "dữ liệu giả" (dummy data) vào xem nó có chạy đúng không. Đây gọi là tư duy làm phần mềm chuẩn.
  • Tích hợp Menu: Một chương trình hoàn thiện sẽ hiển thị danh sách chức năng. Khi người dùng nhập số (1, 2, 3), chương trình dùng switch-case để phân luồng, gọi đến các hàm con tương ứng, sau đó vòng lặp do-while sẽ tự động hiển thị lại Menu.
Minh họa chi tiết

Ý tưởng trực quan: Lưu đồ hệ thống: Start -> Hiện Menu -> Người dùng chọn nhánh (Switch 1, 2, 3) -> Chạy hàm xử lý nhánh -> Quay lại Hiện Menu (Vòng lặp) hoặc Thoát

  • Cách trình bày: Vẽ luồng: Start -> hiện menu -> nhập lựa chọn -> switch -> gọi hàm xử lý -> quay lại menu hoặc thoát.
  • Ví dụ thao tác: Dùng menu 1 thêm, 2 xem, 0 thoát. Lần theo lựa chọn 1 để thấy chương trình chạy hàm thêm rồi quay lại menu.
  • Điểm cần chốt: Chốt rằng menu console thường kết hợp do-while và switch-case.
  • Câu hỏi kiểm tra nhanh: Biến nào nên dùng để lưu lựa chọn của người dùng trong menu?

3. Ví dụ minh họa

Ví dụ 1: Test hàm bằng dữ liệu cứng (Hardcode)

#include <iostream>
using namespace std;

// Viết hàm tính giá giảm
double tinhGiaGiam(double giaGoc, int phanTram) {
    return giaGoc - (giaGoc * phanTram / 100);
}

int main() {
    // TEST HÀM trước khi làm chức năng nhập/xuất phức tạp
    cout << "Test 1 (Giam 10% cua 100): " << tinhGiaGiam(100, 10) << " -> Mong doi: 90\n";
    cout << "Test 2 (Giam 50% cua 200): " << tinhGiaGiam(200, 50) << " -> Mong doi: 100\n";
    // Nếu in ra đúng kết quả mong đợi thì hàm đã an toàn để dùng!
    return 0;
}

Ví dụ 2: Khung Menu Console chuyên nghiệp

#include <iostream>
using namespace std;

void chucNang1() { cout << "\n>>> Thuc hien chuc nang THEM...\n"; }
void chucNang2() { cout << "\n>>> Thuc hien chuc nang XEM...\n"; }

int main() {
    int chon;
    do {
        cout << "\n==========================";
        cout << "\n   PHAN MEM QUAN LY";
        cout << "\n==========================";
        cout << "\n1. Them san pham";
        cout << "\n2. Xem danh sach";
        cout << "\n0. Thoat";
        cout << "\n==========================";
        cout << "\nChon chuc nang: ";
        cin >> chon;

        // Tách mỗi lựa chọn gọi đúng 1 hàm
        switch (chon) {
            case 1: chucNang1(); break;
            case 2: chucNang2(); break;
            case 0: cout << "Dang thoat...\n"; break;
            default: cout << "Loi! Vui long chon tu 0 den 2.\n"; break;
        }
    } while (chon != 0); // Lặp đến khi chọn 0

    return 0;
}

4. Bài tập thực hành trên lớp

  • Bài 1: Viết 3 hàm tĩnh: void veHinhVuong(), void veTamGiac(), void veDuongThang().
  • Bài 2: Lắp 3 hàm ở Bài 1 vào một vòng lặp Menu do-while có cấu trúc giống Ví dụ 2. Cho người dùng nhập số 1, 2, 3 để vẽ các hình tương ứng và số 0 để tắt ứng dụng.
  • Bài 3: Thử test chức năng của Menu bằng cách cố tình nhập số "99". Chương trình phải báo "Lỗi, chọn sai" và hiển thị lại Menu.

5. Bài tập về nhà

  • Bài 1: Tạo một Mini App "Quản lý chi tiêu". Có Menu: 1. Nạp thêm tiền, 2. Tiêu tiền, 3. Xem số dư, 0. Thoát. (Gợi ý: Cần một biến toàn cục int soDu = 0; ở trên cùng, hoặc truyền biến bằng tham chiếu cho các hàm xử lý).

6. Checklist cuối buổi

  • Việc test hàm ngay sau khi viết có tác dụng gì?
  • Tại sao Menu thường được bọc trong vòng lặp do-while thay vì for?
  • Lệnh switch-case hoạt động cùng với các hàm con mang lại sự gọn gàng như thế nào cho main()?
