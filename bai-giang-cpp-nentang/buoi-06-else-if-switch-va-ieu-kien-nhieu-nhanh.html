Buổi 06: else-if, switch và điều kiện nhiều nhánh

Bài giảng chi tiết cho tiết học 90 phút: lý thuyết, ví dụ code, giải thích từng bước, bài tập trên lớp và bài tập về nhà.

Lý thuyếtNội dung được triển khai chi tiết theo từng khái niệm.
Code mẫuCác ví dụ C++ console có giải thích từng bước.
Thực hànhBài tập trên lớp và bài tập về nhà rõ yêu cầu.

1. Mục tiêu buổi học

  • Hiểu được khi nào cần dùng else-if để phân loại nhiều mức độ khác nhau.
  • Biết cách sắp xếp các điều kiện một cách logic, từ chặt đến lỏng hoặc từ cao xuống thấp.
  • Biết sử dụng cấu trúc switch-case để làm các menu lựa chọn rời rạc.
  • Nắm được vai trò bắt buộc của break và default bên trong switch.
  • Biết cách kết hợp nhiều điều kiện cùng lúc bằng && (Và), || (Hoặc), ! (Phủ định).
  • Học sinh viết được chương trình menu máy tính đơn giản và chương trình xếp loại học lực.

2. Lý thuyết chi tiết

  • Cấu trúc else if: Khi có nhiều hơn 2 ngã rẽ (ví dụ: Giỏi, Khá, Trung Bình, Yếu), thay vì lồng if/else quá nhiều, ta dùng else if để nối tiếp các điều kiện. Phải sắp xếp điều kiện từ cao xuống thấp để không bị bắt sai trường hợp.

Toán tử Logic: Đôi khi ta cần kiểm tra nhiều điều kiện cùng lúc.

  • && (AND - Và): Cả 2 điều kiện phải cùng ĐÚNG. (VD: Điểm >= 0 VÀ Điểm <= 10).
  • || (OR - Hoặc): Chỉ cần 1 trong 2 điều kiện ĐÚNG. (VD: Mật khẩu đúng HOẶC có vân tay).
  • Cấu trúc switch-case: Chuyên dùng để làm Menu. Khi người dùng nhập vào một con số cụ thể (1, 2, 3...), switch sẽ nhảy thẳng đến case tương ứng.

break: Đặt ở cuối mỗi case để "thắng" lại, ngăn không cho chạy tuột xuống các case bên dưới.

default: Tương tự như else, nó sẽ chạy nếu người dùng nhập một con số không có trong bất kỳ case nào (ví dụ nhập 99 trong khi menu chỉ có từ 1 đến 3).

Minh họa chi tiết

Ý tưởng trực quan: Bảng Menu nhà hàng với các món số 1, 2, 3 so sánh ngang với cấu trúc Switch-Case trong code

  • Cách trình bày: Vẽ menu nhà hàng: 1. Com, 2. Pho, 3. Bun, 0. Thoat. Nối từng số với một case tương ứng.
  • Ví dụ thao tác: Cho học sinh nhập choice = 2, lần theo code để thấy chương trình nhảy đúng vào case 2.
  • Điểm cần chốt: Chốt rằng switch phù hợp khi lựa chọn là các giá trị rời rạc, và break giúp dừng sau khi xử lý xong một case.
  • Câu hỏi kiểm tra nhanh: Nếu quên break sau case 1, điều gì có thể xảy ra?

3. Ví dụ minh họa

Ví dụ 1: Xếp loại học lực (Dùng else if từ cao xuống thấp)

#include <iostream>
using namespace std;

int main() {
    double diem;
    cout << "Nhap diem trung binh: ";
    cin >> diem;

    // Phải sắp xếp từ cao xuống thấp
    if (diem >= 8.0) {
        cout << "Hoc luc Gioi!" << endl;
    } else if (diem >= 6.5) {
        cout << "Hoc luc Kha!" << endl;
    } else if (diem >= 5.0) {
        cout << "Hoc luc Trung Binh!" << endl;
    } else {
        cout << "Hoc luc Yeu!" << endl;
    }

    return 0;
}

Giải thích: Nếu người dùng nhập 8.5, điều kiện đầu tiên đúng, in "Giỏi" và kết thúc luôn cấu trúc. Nhờ việc sắp xếp từ trên xuống, nếu code trôi xuống được diem >= 6.5, nghĩa là chắc chắn điểm đó đã nhỏ hơn 8.0.

Ví dụ 2: Kết hợp điều kiện với &&

#include <iostream>
using namespace std;

int main() {
    double diem;
    cout << "Nhap diem (tu 0 den 10): ";
    cin >> diem;

    // Điểm hợp lệ phải lớn hơn hoặc bằng 0 VÀ nhỏ hơn hoặc bằng 10
    if (diem >= 0 && diem <= 10) {
        cout << "Diem hop le!" << endl;
    } else {
        cout << "Diem sai! Vui long nhap lai." << endl;
    }

    return 0;
}

Ví dụ 3: Menu máy tính đơn giản với Switch-Case

#include <iostream>
using namespace std;

int main() {
    int luaChon;
    cout << "--- MENU GIAI TRI ---" << endl;
    cout << "1. Choi game" << endl;
    cout << "2. Nghe nhac" << endl;
    cout << "3. Doc truyen" << endl;
    cout << "Chon chuc nang (1-3): ";
    cin >> luaChon;

    switch (luaChon) {
        case 1:
            cout << "Dang mo game..." << endl;
            break; // Cực kỳ quan trọng để dừng lại
        case 2:
            cout << "Dang phat nhac..." << endl;
            break;
        case 3:
            cout << "Dang mo sach..." << endl;
            break;
        default:
            cout << "Lua chon khong ton tai!" << endl;
            break;
    }
    return 0;
}

4. Bài tập thực hành trên lớp

  • Bài 1: Viết chương trình nhập vào một tháng (từ 1 đến 12). In ra màn hình tháng đó thuộc mùa nào (Xuân, Hạ, Thu, Đông) sử dụng else if và toán tử &&.
  • Bài 2: Xóa thử chữ break ở case 1 trong Ví dụ 3, nhập số 1 và quan sát hiện tượng "rơi tự do" (fall-through) của switch-case để hiểu tại sao break lại quan trọng.
  • Bài 3: Viết một menu gọi món ăn sáng gồm 4 món (Phở, Bún, Cơm, Bánh Mì). Sử dụng switch-case để in ra giá tiền tương ứng khi khách chọn số.

5. Bài tập về nhà

  • Bài 1: Viết một "Máy tính mini". Yêu cầu nhập vào 2 số nguyên. Sau đó in ra menu chọn phép tính: 1. Cộng, 2. Trừ, 3. Nhân, 4. Chia. Tùy theo người dùng nhập số nào mà thực hiện phép tính tương ứng và in kết quả ra. (Nhớ chú ý kiểm tra mẫu số khác 0 khi làm phép chia ).
  • Bài 2: Viết chương trình tính tiền cước taxi. Biết rằng: 2km đầu tiên giá 15.000đ/km. Từ km thứ 3 trở đi giá 12.000đ/km. Hãy nhập vào số km và in ra tổng tiền.

6. Checklist cuối buổi

  • Trong switch-case, chuyện gì xảy ra nếu tôi quên viết break?
