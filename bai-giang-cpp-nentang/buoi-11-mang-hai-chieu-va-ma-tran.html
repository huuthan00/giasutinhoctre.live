Buổi 11: Mảng hai chiều và ma trận

Bài giảng chi tiết cho tiết học 90 phút: lý thuyết, ví dụ code, giải thích từng bước, bài tập trên lớp và bài tập về nhà.

Lý thuyếtNội dung được triển khai chi tiết theo từng khái niệm.
Code mẫuCác ví dụ C++ console có giải thích từng bước.
Thực hànhBài tập trên lớp và bài tập về nhà rõ yêu cầu.

1. Mục tiêu buổi học

  • Hiểu mảng hai chiều lưu dữ liệu dạng bảng gồm dòng và cột.
  • Biết khai báo, nhập, in mảng hai chiều.
  • Biết duyệt mảng hai chiều bằng hai vòng lặp lồng nhau.
  • Biết tính tổng theo dòng, theo cột.
  • Biết tìm giá trị lớn nhất, nhỏ nhất trong bảng.
  • Học sinh viết được chương trình xử lý bảng điểm nhiều học sinh và nhiều môn.

2. Lý thuyết chi tiết

  • Mảng hai chiều là gì? Hãy nghĩ về mảng 1 chiều như một dãy nhà trên 1 con phố. Còn mảng 2 chiều chính là một tòa nhà chung cư (có nhiều tầng, mỗi tầng có nhiều phòng) hoặc giống như bảng tính Excel (có dòng và cột).
Minh họa chi tiết

Ý tưởng trực quan: Hình ảnh bảng lưới tọa độ (Lưới Excel) minh họa các ô chứa giá trị ứng với dòng (row) và cột (column)

  • Cách trình bày: Vẽ bảng 3 dòng 4 cột, ghi chỉ số dòng bên trái và chỉ số cột phía trên.
  • Ví dụ thao tác: Cho học sinh xác định ô a[1][2] bằng cách đi tới dòng 1, cột 2. Sau đó duyệt bằng hai vòng lặp lồng nhau.
  • Điểm cần chốt: Chốt rằng mảng hai chiều phù hợp với dữ liệu dạng bảng: điểm nhiều học sinh, nhiều môn.
  • Câu hỏi kiểm tra nhanh: Muốn tính tổng một dòng trong ma trận, vòng lặp nào giữ nguyên và vòng lặp nào thay đổi?
  • Khai báo mảng 2 chiều: Cú pháp: Kiểu_dữ_liệu Tên_mảng[Số_dòng][Số_cột];. Ví dụ: int bangDiem[3][4]; (Tạo một bảng có 3 dòng, mỗi dòng có 4 cột).
  • Truy cập phần tử: Ta cần 2 chỉ số để định vị, một cho dòng và một cho cột, bắt đầu từ 0. bangDiem[0][1] nghĩa là lấy dữ liệu ở dòng 0, cột 1.
  • Hai vòng lặp lồng nhau: Để duyệt mảng 2 chiều, bắt buộc phải dùng 2 vòng lặp for lồng vào nhau. Vòng lặp ngoài kiểm soát dòng (i), vòng lặp trong kiểm soát cột (j).

3. Ví dụ minh họa

Ví dụ 1: Khai báo và in ma trận

#include <iostream>
using namespace std;

int main() {
    // Khai báo ma trận 2 dòng, 3 cột và gán giá trị
    int maTran[2][3] = {
        {1, 2, 3}, // Dòng 0
        {4, 5, 6}  // Dòng 1
    };

    // In giá trị ở dòng 1, cột 2
    cout << "Gia tri tai dong 1, cot 2: " << maTran[1][2] << endl; // In ra 6

    return 0;
}

Ví dụ 2: Nhập và xuất mảng 2 chiều bằng vòng lặp lồng nhau

#include <iostream>
using namespace std;

int main() {
    int bang[2][3]; // 2 dòng, 3 cột

    cout << "Nhap du lieu cho bang 2x3:\n";
    // Duyệt theo dòng (i)
    for (int i = 0; i < 2; i++) {
        // Duyệt theo cột (j)
        for (int j = 0; j < 3; j++) {
            cout << "Nhap o [" << i << "][" << j << "]: ";
            cin >> bang[i][j];
        }
    }

    cout << "\nBang vua nhap la:\n";
    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 3; j++) {
            cout << bang[i][j] << "\t"; // \t dùng để tạo khoảng cách như phím Tab
        }
        cout << "\n"; // Hết một dòng thì xuống dòng
    }

    return 0;
}

Ví dụ 3: Tính tổng bảng điểm (Nhiều học sinh, nhiều môn)

#include <iostream>
using namespace std;

int main() {
    // Giả sử có 2 học sinh, mỗi bạn có 3 cột điểm (Toán, Văn, Anh)
    int diem[2][3] = {
        {8, 7, 9}, // Điểm của học sinh 0
        {6, 5, 8}  // Điểm của học sinh 1
    };

    // Tính tổng điểm từng học sinh (Tính theo dòng)
    for (int i = 0; i < 2; i++) {
        int tongHocSinh = 0;
        for (int j = 0; j < 3; j++) {
            tongHocSinh += diem[i][j];
        }
        cout << "Tong diem cua Hoc sinh " << i << " la: " << tongHocSinh << endl;
    }

    return 0;
}

4. Bài tập thực hành trên lớp

  • Bài 1: Viết chương trình khởi tạo một mảng 2 chiều kích thước 3x3 chứa các số tự nhiên từ 1 đến 9. In mảng đó ra màn hình dưới dạng lưới.
  • Bài 2: Tiếp tục với mảng ở Bài 1, hãy viết vòng lặp để tính tổng tất cả các phần tử có trong mảng.
  • Bài 3: Viết chương trình quản lý doanh thu. Mảng 2 chiều có kích thước 3x4 đại diện cho doanh thu của 3 cửa hàng trong 4 tuần. Hãy tìm xem cửa hàng nào có 1 tuần bán được doanh thu cao nhất (Tìm Max trong mảng 2 chiều).

5. Bài tập về nhà

  • Bài 1: Viết chương trình nhập vào một ma trận kích thước 3x3. Hãy in ra các số nằm trên "đường chéo chính" của ma trận đó. (Gợi ý: Các phần tử nằm trên đường chéo chính sẽ có chỉ số dòng bằng với chỉ số cột, tức là i == j).

6. Checklist cuối buổi

  • int a[3][4] thì có bao nhiêu ô chứa dữ liệu tất cả?
  • Tại sao vòng lặp duyệt mảng 2 chiều lại luôn cần 2 biến i và j?
  • Để tính tổng một dòng, thì biến tong = 0 phải đặt ở bên ngoài vòng lặp i hay ở giữa vòng lặp i và j?
