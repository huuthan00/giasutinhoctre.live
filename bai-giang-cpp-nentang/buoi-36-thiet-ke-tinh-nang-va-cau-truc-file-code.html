Buổi 36: Thiết kế tính năng và cấu trúc file code

Bài giảng chi tiết cho tiết học 90 phút: lý thuyết, ví dụ code, giải thích từng bước, bài tập trên lớp và bài tập về nhà.

Lý thuyếtNội dung được triển khai chi tiết theo từng khái niệm.
Code mẫuCác ví dụ C++ console có giải thích từng bước.
Thực hànhBài tập trên lớp và bài tập về nhà rõ yêu cầu.

1. Mục tiêu buổi học

  • Biết chia sản phẩm thành các phần logic: phần chứa dữ liệu, phần chứa hàm xử lý, phần menu hiển thị, và file lưu trữ txt.
  • Biết thiết kế struct phù hợp với đề tài đã chọn.
  • Biết lập danh sách các hàm cần có trước khi code.
  • Biết vẽ luồng chạy của chương trình bằng các bước tuần tự.
  • Biết tạo file code ban đầu (skeleton code) có bộ khung rõ ràng.
  • Học sinh tự tạo được bộ khung code skeleton cho dự án cuối khóa của mình.

2. Lý thuyết chi tiết

  • Quy tắc Kiến trúc phần mềm: Đừng viết một mạch từ trên xuống dưới trong hàm main(). Hãy chia code ra thành 3 khu vực (Blocks):
  • Khu vực 1: Khai báo thư viện và struct.
  • Khu vực 2: Khai báo tên các hàm (Prototype) và viết thân hàm.
  • Khu vực 3: Hàm main() chỉ chứa Menu và lệnh gọi hàm.
Minh họa chi tiết

Ý tưởng trực quan: Sơ đồ hình khối minh họa Cấu trúc file Code. Khối đỉnh: Libraries & Struct. Khối giữa: Functions (Thêm, Sửa, Xóa). Khối đáy: Main Menu (Switch-case)

  • Cách trình bày: Vẽ ba tầng: thư viện và struct ở trên, các hàm xử lý ở giữa, main và menu ở dưới điều phối.
  • Ví dụ thao tác: Cho học sinh đặt từng đoạn code của dự án vào đúng tầng để tránh file lộn xộn.
  • Điểm cần chốt: Chốt rằng cấu trúc file rõ giúp dễ sửa, dễ demo và dễ trả lời khi bảo vệ.
  • Câu hỏi kiểm tra nhanh: Hàm themSach() nên nằm trong phần nào của file?
  • Skeleton Code (Code khung xương): Là viết sẵn vỏ bọc của các hàm nhưng bên trong chưa có logic tính toán. Việc này giúp chương trình chạy được Menu ngay lập tức mà chưa cần code chi tiết.

3. Ví dụ minh họa (Tạo Skeleton Code)

#include <iostream>
#include <vector>
#include <string>
using namespace std;

// 1. DỮ LIỆU
struct Sach { int ma; string ten; };
vector<Sach> thuVien;

// 2. KHUNG HÀM (Chưa có ruột)
void hienThiMenu() {
    cout << "\n--- QUAN LY THU VIEN ---\n";
    cout << "1. Xem sach\n2. Them sach\n0. Thoat\n";
    cout << "Chon: ";
}

void xemSach() {
    cout << "[He thong]: Dang in danh sach...\n"; // Thông báo giả
}

void themSach() {
    cout << "[He thong]: Dang mo chuc nang them...\n";
}

// 3. MAIN (Điều phối)
int main() {
    int chon;
    do {
        hienThiMenu();
        cin >> chon;
        switch (chon) {
            case 1: xemSach(); break;
            case 2: themSach(); break;
            case 0: cout << "Tam biet!\n"; break;
            default: cout << "Nhap sai!\n"; break;
        }
    } while (chon != 0);
    return 0;
}

4. Bài tập thực hành trên lớp

  • Bài 1: Áp dụng Lý thuyết thiết kế file code, em hãy gõ toàn bộ khung xương (Skeleton code) cho đề tài dự án của em vào máy tính.
  • Bài 2: Chạy thử chương trình. Bấm lần lượt các phím số trong Menu xem các dòng chữ "[Hệ thống]: Đang..." có hiện ra đúng như thiết kế không.

5. Bài tập về nhà

  • Bài 1: Bổ sung toàn bộ các biến cấu trúc vào struct dự án của em cho đầy đủ. (Ví dụ: Sach thì thêm tacGia, namXuatBan, giaTien).

6. Checklist cuối buổi

  • Skeleton code (Code khung xương) có lợi ích gì khi làm dự án lớn?
  • Em đã hoàn thiện việc lập danh sách các hàm cần có cho đề tài của mình chưa?.
