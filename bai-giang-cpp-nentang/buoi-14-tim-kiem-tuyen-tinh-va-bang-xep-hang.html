Buổi 14: Tìm kiếm tuyến tính và bảng xếp hạng

Bài giảng chi tiết cho tiết học 90 phút: lý thuyết, ví dụ code, giải thích từng bước, bài tập trên lớp và bài tập về nhà.

Code mẫuCác ví dụ C++ console có giải thích từng bước.
Thực hànhBài tập trên lớp và bài tập về nhà rõ yêu cầu.

1. Mục tiêu buổi học

  • Hiểu thuật toán tìm kiếm tuyến tính (Linear Search) chính là việc duyệt xét từng phần tử từ đầu đến cuối danh sách.
  • Biết cách tìm và lấy ra vị trí của một giá trị được chỉ định bên trong mảng/vector.
  • Biết cách xử lý hai trường hợp: Tìm thấy thành công và Không tìm thấy (vắng mặt) trong danh sách.
  • Biết cách thu thập và tìm ra nhiều kết quả cùng lúc nếu chúng thỏa mãn một điều kiện cho trước.
  • Kết hợp các kiến thức tìm kiếm với danh sách điểm để tạo ra một bảng xếp hạng học sinh cơ bản.
  • Học sinh viết được chức năng tìm học sinh theo điểm số hoặc một cụm tên ngắn.

2. Lý thuyết chi tiết

  • Tìm kiếm tuyến tính (Linear Search): Đây là cách tìm kiếm tự nhiên nhất của con người. Nếu bạn muốn tìm số 7 trong một danh sách, bạn sẽ mở ngăn số 0 ra xem có phải số 7 không, nếu không thì mở ngăn số 1, ngăn số 2... cho đến khi thấy số 7 hoặc hết mảng thì thôi.
Minh họa chi tiết

Ý tưởng trực quan: Một hàng tủ đồ locker. Một người bảo vệ đi mở cửa từng tủ từ trái sang phải để tìm chiếc túi xách màu đỏ (Minh họa Linear Search)

  • Cách trình bày: Vẽ một dãy tủ, người tìm kiếm mở lần lượt từ trái sang phải.
  • Ví dụ thao tác: Dùng danh sách An, Binh, Chi, Dung, tìm Chi: kiểm tra An, Binh, rồi mới thấy Chi.
  • Điểm cần chốt: Chốt rằng Linear Search không cần dữ liệu sắp xếp, nhưng có thể phải duyệt hết danh sách.
  • Câu hỏi kiểm tra nhanh: Nếu tìm phần tử không tồn tại, Linear Search sẽ kiểm tra bao nhiêu phần tử?

Lưu lại vị trí (Index): Khi tìm thấy, điều ta cần trả về không phải là giá trị đó (vì ta đã biết giá trị đó rồi), mà ta cần trả về vị trí (chỉ số) của nó trong mảng.

  • Cờ hiệu (Flag) cho trường hợp Không tìm thấy: Ta thường tạo một biến phụ (ví dụ int viTri = -1). Khi duyệt mảng, nếu tìm thấy ta gán viTri = i. Sau vòng lặp, nếu viTri vẫn bằng -1 (tức là không hề thay đổi), ta kết luận là giá trị đó không tồn tại trong danh sách.

Tìm nhiều kết quả: Thay vì dừng lại (dùng break) khi tìm thấy số đầu tiên, ta cứ để vòng lặp chạy hết mảng, mỗi lần tìm thấy một giá trị đúng, ta in nó ra hoặc lưu nó vào một mảng mới.

3. Ví dụ minh họa

Ví dụ 1: Tìm kiếm vị trí của một điểm số

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> danhSach = {4, 7, 2, 9, 6, 8};
    int soCanTim = 9;
    int viTri = -1; // -1 nghĩa là chưa tìm thấy

    // Duyệt từ đầu đến cuối
    for (int i = 0; i < danhSach.size(); i++) {
        if (danhSach[i] == soCanTim) {
            viTri = i; // Đã tìm thấy, lưu vị trí lại
            break;     // Dừng tìm kiếm ngay
        }
    }

    if (viTri != -1) {
        cout << "Da tim thay so " << soCanTim << " tai vi tri thu " << viTri << endl;
    } else {
        cout << "Khong tim thay so " << soCanTim << " trong danh sach!" << endl;
    }
    return 0;
}

Ví dụ 2: Tìm tất cả học sinh đạt điểm 10 (Tìm nhiều kết quả)

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> diem = {6, 10, 8, 10, 5, 10, 7};
    int soLuongDiem10 = 0;

    cout << "Nhung hoc sinh dat diem 10 nam o vi tri: ";
    for (int i = 0; i < diem.size(); i++) {
        if (diem[i] == 10) {
            cout << i << " ";
            soLuongDiem10++; // Đếm số lượng tìm được
        }
    }

    if (soLuongDiem10 == 0) {
        cout << "(Khong co ai)"; // Xử lý nếu không tìm thấy
    }
    cout << "\nTong cong co " << soLuongDiem10 << " ban dat diem 10." << endl;
    return 0;
}

Ví dụ 3: Linear Search trong Hàm

#include <iostream>
#include <vector>
using namespace std;

// Hàm tìm kiếm, trả về vị trí. Trả về -1 nếu không có
int timKiemTuyenTinh(vector<int> mang, int giaTri) {
    for (int i = 0; i < mang.size(); i++) {
        if (mang[i] == giaTri) {
            return i; // Dùng return để thoát hàm ngay lập tức
        }
    }
    return -1;
}

int main() {
    vector<int> sanPham = {101, 205, 308, 440};
    int maCanTim;
    cout << "Nhap ma san pham can tim: ";
    cin >> maCanTim;

    int ketQua = timKiemTuyenTinh(sanPham, maCanTim);
    if (ketQua != -1) cout << "Tim thay o vi tri: " << ketQua << endl;
    else cout << "San pham khong ton tai!\n";

    return 0;
}

4. Bài tập thực hành trên lớp

  • Bài 1: Viết chương trình quản lý thư viện. Khai báo mảng vector<int> maSach = {10, 24, 35, 48, 59};. Cho người dùng nhập một mã sách, kiểm tra xem quyển sách đó có nằm trong thư viện hay không.
  • Bài 2: Cho danh sách điểm vector<double> diemSo = {5.5, 9.0, 4.0, 7.5, 3.5};. Viết chương trình tìm và in ra vị trí của tất cả những học sinh có điểm dưới trung bình (< 5.0).
  • Bài 3: Nhập một số ngẫu nhiên N vào danh sách. Nếu N chưa có trong danh sách thì dùng hàm push_back để thêm vào. Nếu đã có thì thông báo "Bị trùng, không thêm".

5. Bài tập về nhà

  • Bài 1: Viết chương trình "Bảng Xếp Hạng". Yêu cầu khai báo hai vector song song: vector<string> ten = {"An", "Binh", "Chau"}; và vector<int> diem = {8, 10, 9};. Cho người dùng nhập vào một cái tên. Hãy tìm vị trí của tên đó trong mảng ten, sau đó in ra con điểm tương ứng bên mảng diem.

  • Làm sao để chương trình báo "Không tìm thấy" thay vì im lặng kết thúc?
