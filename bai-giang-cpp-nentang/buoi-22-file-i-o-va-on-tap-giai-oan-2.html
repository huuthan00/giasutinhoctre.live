Buổi 22: File I/O và ôn tập giai đoạn 2

Bài giảng chi tiết cho tiết học 90 phút: lý thuyết, ví dụ code, giải thích từng bước, bài tập trên lớp và bài tập về nhà.

Lý thuyếtNội dung được triển khai chi tiết theo từng khái niệm.
Code mẫuCác ví dụ C++ console có giải thích từng bước.
Thực hànhBài tập trên lớp và bài tập về nhà rõ yêu cầu.

1. Mục tiêu buổi học

  • Biết đọc và ghi file text cơ bản bằng ifstream/ofstream và biết lưu danh sách ra file, đọc lại danh sách.
  • Biết kiểm tra file mở thành công hay không và ôn tập toàn bộ kiến thức vector, struct, hàm, menu.
  • Biết chia chương trình quản lý thành các hàm rõ ràng và học sinh viết được mini app lưu/đọc danh sách đơn giản.
  • Tổng hợp kiến thức kết thúc Giai đoạn 2 của khóa học.

2. Lý thuyết chi tiết

  • Tại sao phải dùng File? Mọi biến int, vector đều nằm trên RAM. Nếu bạn tắt cửa sổ console (màn hình đen), toàn bộ dữ liệu bạn nhập nãy giờ sẽ bốc hơi. Để dữ liệu tồn tại vĩnh viễn, ta phải lưu chúng xuống ổ cứng dưới dạng tệp văn bản (.txt).
  • Thư viện <fstream> (File Stream): Cung cấp 2 công cụ chính:
  • ofstream (Output File Stream): Luồng xuất, dùng để GHI dữ liệu từ RAM xuống file txt. (Cách dùng giống hệt cout).
  • ifstream (Input File Stream): Luồng nhập, dùng để ĐỌC dữ liệu từ file txt đưa ngược lên RAM. (Cách dùng giống hệt cin).
  • Quy trình 3 bước:
  1. Mở file. (Nhớ kiểm tra xem mở có thành công không, lỡ file bị xóa thì sao?).
  2. Thực hiện thao tác Ghi hoặc Đọc.
  3. ĐÓNG file (.close()). Đây là thao tác bắt buộc để hệ điều hành lưu file lại an toàn.
Minh họa chi tiết

Ý tưởng trực quan: Minh họa quy trình: RAM máy tính -> Mở đường ống nước (ofstream) -> Nước (Data) chảy vào bể chứa (File .txt trên ổ cứng) -> Đóng van (close)

  • Cách trình bày: Vẽ dữ liệu từ RAM chảy qua ống ofstream vào file .txt; chiều ngược lại dùng ifstream.
  • Ví dụ thao tác: Minh họa ghi một danh sách 3 học sinh ra file rồi đọc lại để in lên console.
  • Điểm cần chốt: Chốt rằng file giúp dữ liệu không mất sau khi tắt chương trình, nhưng phải kiểm tra mở file thành công.
  • Câu hỏi kiểm tra nhanh: Nếu file không mở được, chương trình nên tiếp tục xử lý hay báo lỗi?

3. Ví dụ minh họa

Ví dụ 1: Ghi thông tin xuống file (Save)

#include <iostream>
#include <fstream> // Bắt buộc
#include <string>
using namespace std;

int main() {
    // 1. Mở file để ghi (Nếu file chưa có, nó sẽ tự tạo)
    ofstream fileGhi("data.txt");

    if (fileGhi.is_open()) {
        // 2. Ghi dữ liệu giống y hệt cout
        fileGhi << "Ban dang hoc bai File trong C++\n";
        fileGhi << "Diem so: " << 10 << endl;

        // 3. Đóng file
        fileGhi.close();
        cout << "Da luu xuong o cung thanh cong!\n";
    } else {
        cout << "Loi tao file!\n";
    }

    return 0;
}

Ghi chú: Sau khi chạy code, hướng dẫn học sinh vào thư mục chứa code mở tệp data.txt bằng Notepad để tận mắt nhìn thấy dữ liệu.

Ví dụ 2: Đọc thông tin từ file (Load)

#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main() {
    // 1. Mở file để đọc
    ifstream fileDoc("data.txt");
    string dongChu;

    // Kiểm tra file có tồn tại không
    if (fileDoc.is_open()) {
        // 2. Đọc từng dòng cho đến khi hết file
        while (getline(fileDoc, dongChu)) {
            cout << dongChu << endl; // In lên màn hình
        }

        // 3. Đóng file
        fileDoc.close();
    } else {
        cout << "File khong ton tai hoac bi loi!\n";
    }
    return 0;
}

Ví dụ 3: Ôn tập - Lưu danh sách Struct (Mini App Đọc/Ghi)

#include <iostream>
#include <fstream>
#include <vector>
using namespace std;

struct SanPham { int ma; int gia; };

void luuDanhSach(vector<SanPham> &ds) {
    ofstream f("sanpham.txt");
    if (f.is_open()) {
        f << ds.size() << "\n"; // Lưu số lượng trước để sau này dễ đọc
        for (int i = 0; i < ds.size(); i++) {
            f << ds[i].ma << " " << ds[i].gia << "\n";
        }
        f.close();
        cout << "Luu file xong!\n";
    }
}

int main() {
    vector<SanPham> ds = {{101, 5000}, {102, 7500}};
    luuDanhSach(ds); // Sẽ sinh ra file txt chứa số liệu
    return 0;
}

  • Bài 2: (Ôn tập Vector + Hàm) Viết một hàm tính tổng của mảng. Nhưng thay vì in tổng ra console bằng cout, hãy truyền ofstream vào và in cái tổng đó ra file kết quả.
  • Bài 3: Chạy thử Ví dụ 2 với một tên file không hề tồn tại (vd: loi.txt). Quan sát lệnh kiểm tra is_open() bắt lỗi như thế nào.
