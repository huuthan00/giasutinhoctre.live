Buổi 33: Tích hợp mini app quản lý

Bài giảng chi tiết cho tiết học 90 phút: lý thuyết, ví dụ code, giải thích từng bước, bài tập trên lớp và bài tập về nhà.

Lý thuyếtNội dung được triển khai chi tiết theo từng khái niệm.
Code mẫuCác ví dụ C++ console có giải thích từng bước.
Thực hànhBài tập trên lớp và bài tập về nhà rõ yêu cầu.

1. Mục tiêu buổi học

  • Biết gom các chức năng đã học thành một chương trình quản lý.
  • Có menu: thêm, hiển thị, tìm kiếm, sửa, xóa, sắp xếp, thống kê, thoát.
  • Biết tách code thành các hàm riêng.
  • Biết dùng vector làm dữ liệu chính.
  • Biết kiểm tra lỗi nhập cơ bản.
  • Học sinh hoàn thành mini app quản lý phiên bản đầu.

2. Lý thuyết chi tiết

  • Lắp ráp mô hình (Integration): 32 buổi trước, chúng ta luyện tập rèn rũa từng mảnh ghép rời rạc: Hàm thêm, Hàm xóa, Cấu trúc if-else, Vòng lặp. Buổi hôm nay là lúc lắp ráp toàn bộ chúng lại thành một cỗ máy Mini App chạy hoàn chỉnh.
  • Quản lý dữ liệu tập trung: Tạo duy nhất một biến vector<Struct> dataMain; ở bên trong hàm main(). Sau đó, truyền tham chiếu biến này vào mọi nhánh của chức năng thông qua Menu.
  • Bắt lỗi cơ bản (Validation): Không được để người dùng nhập Giá tiền là số âm, hoặc nhập Mã là chữ. Trước khi đẩy struct vào mảng bằng push_back(), phải dùng lệnh if để chặn các thông tin vô lý đó lại.
Minh họa chi tiết

Ý tưởng trực quan: Một bản vẽ lắp ráp Robot. Các bộ phận rời rạc (Hàm Thêm, Hàm Xóa, Hàm Thống Kê) kết nối vào khung trục trung tâm (Hàm Main chứa Switch-Case) để tạo thành một Mini App hoàn chỉnh

  • Cách trình bày: Vẽ mini app như robot: main là thân chính, các hàm thêm/xóa/thống kê là bộ phận được gắn vào.
  • Ví dụ thao tác: Cho học sinh đánh dấu mỗi chức năng trong menu đang gọi hàm nào.
  • Điểm cần chốt: Chốt rằng tích hợp app là ghép các hàm đã học thành một luồng sử dụng hoàn chỉnh.
  • Câu hỏi kiểm tra nhanh: Nếu menu chọn 3 là tìm kiếm, hàm nào nên được gọi và dữ liệu nào được truyền vào?

3. Ví dụ minh họa

  • Khung sườn Mini App hoàn chỉnh
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
using namespace std;

struct MonAn { int ma; string ten; }; // Dữ liệu chính

// Các hàm tách biệt (Ví dụ viết ngắn gọn, thực tế viết dài như các bài trước)
void themMon(vector<MonAn> &ds) {
    MonAn m;
    cout << "Nhap Ma: "; cin >> m.ma;
    if (m.ma < 0) { // Bắt lỗi cơ bản
        cout << "Ma khong duoc am!\n"; return;
    }
    cin.ignore();
    cout << "Nhap Ten: "; getline(cin, m.ten);
    ds.push_back(m);
    cout << "Da them!\n";
}

void xemDanhSach(vector<MonAn> ds) {
    if(ds.empty()) { cout << "Rong!\n"; return; }
    for(int i=0; i<ds.size(); i++) cout << ds[i].ma << " - " << ds[i].ten << "\n";
}

int main() {
    vector<MonAn> thucDon; // Trái tim của ứng dụng
    int chon;

    do {
        cout << "\n=== APP QUAN LY THUC DON ===\n";
        cout << "1. Them Mon\n2. Xem Danh Sach\n3. Thoat\n";
        cout << "Chon: "; cin >> chon;

        // Điều phối dữ liệu qua các hàm
        switch(chon) {
            case 1: themMon(thucDon); break;
            case 2: xemDanhSach(thucDon); break;
            case 3: cout << "Dang thoat...\n"; break;
            default: cout << "Loi, chon lai!\n";
        }
    } while (chon != 3);

    return 0;
}

Ghi chú: Nhấn mạnh với học sinh rằng một Mini App thực tế sẽ có case kéo dài từ 1 đến 8 (bao gồm cả Sửa, Xóa, Sắp xếp, Thống kê).

4. Bài tập thực hành trên lớp

  • Bài 1: Dành 45 phút hoàn thiện lại mã nguồn của Project "Quản lý Sinh Viên/Sản phẩm" mà học sinh đã làm lẻ tẻ từ buổi 23 đến nay. Gom tất cả vào chung một file .cpp.
  • Bài 2: Thêm validation (Kiểm tra lỗi nhập) vào hàm them(): Điểm số của sinh viên không được phép vượt ra khỏi giới hạn 0 - 10. Nếu người dùng nhập sai, in ra "Điểm không hợp lệ, hủy thêm mới".

5. Bài tập về nhà

  • Bài 1: Tự kiểm thử (Test) ứng dụng của mình. Hãy chạy ứng dụng lên, nhập liên tục các tùy chọn sai (ví dụ: đòi xóa một mã không tồn tại, đòi xem danh sách khi danh sách chưa có gì). Ghi chép lại các lỗi gặp phải để buổi sau xử lý.

6. Checklist cuối buổi

  • Hàm main() của bạn có vượt quá 50 dòng code không? (Nếu có là bạn quên "tách hàm" rồi đấy!)
  • Ứng dụng có bị sập khi người dùng đòi In thống kê trong lúc danh sách chưa có dữ liệu không?
