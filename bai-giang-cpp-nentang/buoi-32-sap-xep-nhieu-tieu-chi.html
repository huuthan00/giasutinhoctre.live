Buổi 32: Sắp xếp nhiều tiêu chí

Bài giảng chi tiết cho tiết học 90 phút: lý thuyết, ví dụ code, giải thích từng bước, bài tập trên lớp và bài tập về nhà.

Lý thuyếtNội dung được triển khai chi tiết theo từng khái niệm.
Code mẫuCác ví dụ C++ console có giải thích từng bước.
Thực hànhBài tập trên lớp và bài tập về nhà rõ yêu cầu.

1. Mục tiêu buổi học

  • Biết sắp xếp theo giá tăng dần, nếu bằng giá thì mã tăng dần.
  • Biết trình bày kết quả sau sắp xếp.
  • Biết tránh comparator sai logic.
  • Học sinh viết được sắp xếp danh sách struct theo 2 tiêu chí.

2. Lý thuyết chi tiết

  • Xung đột khi xếp hạng: Trong thực tế, có rất nhiều học sinh đạt cùng 9.0 điểm. Nếu chỉ sắp xếp theo điểm, thứ tự của các bạn đồng điểm sẽ lộn xộn. Lúc này ta cần Tiêu chí phụ (Tiêu chí 2): "Xếp theo điểm từ cao xuống thấp. Nhưng nếu 2 bạn bằng điểm nhau, thì xét tên theo bảng chữ cái A-Z".
  • Xây dựng Logic Comparator: Ta dùng cấu trúc if - else if bên trong hàm Comparator.
  • if (diem khác nhau) -> Xếp theo điểm.

if (diem bằng nhau) -> Đi xem xét đến tên.

  • Lỗi logic kinh điển (Sai Luật Trọng Tài): Hàm Trọng tài phải trả về false nếu a và b hoàn toàn giống nhau. Đừng bao giờ viết return a.diem >= b.diem;. Chỉ được dùng dấu > hoặc < nghiêm ngặt, tuyệt đối không dùng >= hay <= trong Comparator của std::sort. Nếu cố tình dùng, chương trình sẽ báo lỗi "Segmentation Fault" (Lỗi bộ nhớ).
Minh họa chi tiết

Ý tưởng trực quan: Sơ đồ luồng (Flowchart) của Comparator nhiều tiêu chí. Kim cương 1: So sánh Điểm -> Nếu bằng nhau rẽ sang Kim cương 2: So sánh Tên -> Trả về Kết quả True/False

  • Cách trình bày: Vẽ flowchart: so sánh tiêu chí 1, nếu khác thì quyết định; nếu bằng nhau mới chuyển sang tiêu chí 2.
  • Ví dụ thao tác: Ví dụ sắp xếp điểm giảm dần, nếu bằng điểm thì tên tăng dần.
  • Điểm cần chốt: Chốt rằng comparator nhiều tiêu chí phải xử lý rõ trường hợp bằng nhau.
  • Câu hỏi kiểm tra nhanh: Nếu hai học sinh cùng điểm 8.5, tiêu chí phụ nào sẽ quyết định thứ tự?

3. Ví dụ minh họa

Ví dụ 1: Comparator 2 tiêu chí (Giá tăng dần, Mã tăng dần)

#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
using namespace std;

struct SanPham { int ma; string ten; int gia; };

// Trọng tài xử lý 2 tiêu chí
bool soSanh2TieuChi(SanPham a, SanPham b) {
    if (a.gia != b.gia) {
        // Tiêu chí 1: Nếu giá khác nhau, xếp giá tăng dần
        return a.gia < b.gia;
    } else {
        // Tiêu chí 2: Nếu giá bằng nhau, xếp theo Mã số tăng dần
        return a.ma < b.ma;
    }
}

int main() {
    vector<SanPham> ds = {
        {105, "Vo tap", 10000},
        {101, "But bi", 5000},
        {103, "But chi", 5000}, // Đồng giá với Bút bi
        {102, "Gom", 8000}
    };

    sort(ds.begin(), ds.end(), soSanh2TieuChi);

    cout << "--- DANH SACH SAU KHI XEP ---\n";
    for (int i = 0; i < ds.size(); i++) {
        // In định dạng thẳng cột, dễ nhìn
        cout << "- Ma: " << ds[i].ma << " | Gia: " << ds[i].gia << " | Ten: " << ds[i].ten << "\n";
    }
    return 0;
}

Giải thích: Nhờ Comparator nhiều tiêu chí, sản phẩm But bi (Mã 101) sẽ được xếp tự động nằm trên But chi (Mã 103) mặc dù cả 2 đồng giá 5000.

4. Bài tập thực hành trên lớp

  • Bài 1: Viết Comparator xếp danh sách Sinh viên: Tiêu chí 1 là Điểm số Giảm Dần. Nếu Điểm số bằng nhau, xét Tiêu chí 2 là Tên Tăng Dần (A->Z).
  • Bài 2: (Tìm lỗi) Cho đoạn code bool cmp(HocSinh a, HocSinh b) { return a.diem >= b.diem; }. Hãy chỉ ra tại sao nó sai logic và sửa lại cho đúng quy tắc của C++.

5. Bài tập về nhà

  • Bài 1: Tạo một danh sách 5 mặt hàng tạp hóa (Mã SP, Tên SP, Giá tiền, Số lượng). Viết Comparator để sắp xếp ưu tiên hiển thị những món "Gần hết hàng" lên trên (Số lượng tăng dần). Nếu 2 món có số lượng bằng nhau, ưu tiên đưa món "Giá trị cao" lên trước (Giá giảm dần).
