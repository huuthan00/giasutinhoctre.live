Buổi 05: Rẽ nhánh if/else cơ bản

Bài giảng chi tiết cho tiết học 90 phút: lý thuyết, ví dụ code, giải thích từng bước, bài tập trên lớp và bài tập về nhà.

Lý thuyếtNội dung được triển khai chi tiết theo từng khái niệm.
Code mẫuCác ví dụ C++ console có giải thích từng bước.
Thực hànhBài tập trên lớp và bài tập về nhà rõ yêu cầu.

1. Mục tiêu buổi học

  • Hiểu được khái niệm điều kiện đúng/sai trong C++.
  • Biết cách viết cấu trúc if, if/else để chương trình tự đưa ra quyết định.
  • Nắm vững các toán tử so sánh: == (bằng), != (khác), >, <, >=, <=.
  • Biết cách "test dữ liệu biên", ví dụ khi kiểm tra điểm đậu/rớt thì phải thử ngay các mức 5.0, 6.5, 8.0 để xem code chạy đúng không.
  • Biết cách tránh lỗi kinh điển: nhầm lẫn dấu = (gán giá trị) với dấu == (so sánh bằng).
  • Học sinh viết được chương trình kiểm tra đậu/rớt, số dương/âm/0, và kiểm tra điểm hợp lệ.

2. Lý thuyết chi tiết

  • Điều kiện Đúng / Sai (Boolean): Máy tính đưa ra quyết định dựa trên tính đúng sai. Trong C++, true là đúng, false là sai.
  • Cấu trúc if (Nếu): Dùng để bảo máy tính: "Nếu điều kiện này đúng, thì hãy làm việc này".
Minh họa chi tiết

Ý tưởng trực quan: Sơ đồ khối (Flowchart) của lệnh if: Đường đi qua một trạm kiểm soát, nếu vé hợp lệ (Đúng) thì barrier mở cho đi qua, nếu không (Sai) thì đi đường vòng

  • Cách trình bày: Vẽ hình thoi Điều kiện đúng?, nhánh trái true, nhánh phải false, mỗi nhánh đi tới một hành động khác nhau.
  • Ví dụ thao tác: Dùng tình huống score >= 5: đúng thì in Dat, sai thì in Chua dat. Cho học sinh thử với 4.9, 5.0, 8.0.
  • Điểm cần chốt: Chốt rằng if không phải phép tính, mà là điểm ra quyết định dựa trên điều kiện đúng/sai.
  • Câu hỏi kiểm tra nhanh: Tại sao bài kiểm tra điểm phải thử đúng mốc 5.0, không chỉ thử 4 và 8?
  • Cấu trúc if/else (Nếu... ngược lại thì...): Dùng khi ta có 2 ngã rẽ. "Nếu đúng thì làm A, ngược lại thì làm B".
  • Các toán tử so sánh: Lớn hơn (>), Nhỏ hơn (<), Lớn hơn hoặc bằng (>=), Nhỏ hơn hoặc bằng (<=), Khác nhau (!=).
  • Lưu ý CỰC KỲ QUAN TRỌNG: Dấu = dùng để cất đồ vào hộp (gán giá trị). Dấu == mới là phép so sánh xem hai bên có bằng nhau hay không. Học sinh rất hay viết sai thành if (diem = 10) thay vì if (diem == 10).

3. Ví dụ minh họa

Ví dụ 1: Kiểm tra Đậu / Rớt

#include <iostream>
using namespace std;

int main() {
    double diem;
    cout << "Nhap diem cua ban: ";
    cin >> diem;

    // Nếu điểm lớn hơn hoặc bằng 5.0 thì đậu
    if (diem >= 5.0) {
        cout << "Chuc mung! Ban da thi dau." << endl;
    } else {
        // Ngược lại (nhỏ hơn 5.0)
        cout << "Rat tiec, ban can co gang hon." << endl;
    }

    return 0;
}

Giải thích: Lệnh if kiểm tra biến diem. Nếu người dùng nhập 6.5, điều kiện 6.5 >= 5.0 là đúng, dòng "Chúc mừng" được in ra. Nếu nhập 4.5, máy tính bỏ qua dòng "Chúc mừng" và nhảy thẳng xuống phần else để in ra dòng "Rất tiếc". Hãy test với mức điểm biên là 5.0.

Ví dụ 2: Kiểm tra số Âm / Dương / 0

#include <iostream>
using namespace std;

int main() {
    int so;
    cout << "Nhap mot so nguyen: ";
    cin >> so;

    if (so > 0) {
        cout << "Day la so duong." << endl;
    } else {
        if (so < 0) {
            cout << "Day la so am." << endl;
        } else {
            cout << "Day la so 0." << endl;
        }
    }
    return 0;
}

Giải thích: Đây là ví dụ về if/else lồng nhau. Đầu tiên kiểm tra số dương. Nếu không phải số dương (vào else), ta lại kiểm tra tiếp xem nó là số âm hay số 0 bằng một cặp if/else nhỏ bên trong.

Ví dụ 3: Lỗi sai dấu bằng = và ==

#include <iostream>
using namespace std;

int main() {
    int matKhau = 123;

    // SAI LẦM KINH ĐIỂN: Dùng 1 dấu =
    // if (matKhau = 999) { ... } -> Lỗi logic, máy sẽ gán matKhau thành 999

    // CÁCH VIẾT ĐÚNG: Dùng 2 dấu ==
    if (matKhau == 999) {
        cout << "Mat khau dung!" << endl;
    } else {
        cout << "Mat khau sai!" << endl;
    }

    return 0;
}

4. Bài tập thực hành trên lớp

  • Bài 1: Viết chương trình nhập vào số tuổi. Nếu tuổi >= 18, in ra "Đủ tuổi xem phim bạo lực", ngược lại in "Bạn chưa đủ tuổi".
  • Bài 2: Kết hợp kiến thức buổi 4, viết chương trình nhập một số nguyên và kiểm tra xem số đó là số chẵn hay số lẻ.
  • Bài 3: Viết chương trình nhập vào một năm, kiểm tra xem năm đó có phải năm 2024 không (Chú ý sử dụng đúng toán tử so sánh bằng).

5. Bài tập về nhà

  • Bài 1: Viết chương trình tính tiền vé xem phim. Giá gốc là 100k. Nếu khách hàng mang thẻ học sinh (nhập 1 là có thẻ, nhập 0 là không có thẻ), thì in ra giá vé đã giảm còn 70k. Nếu không, in ra giá gốc.
  • Bài 2: Nhập vào 2 số nguyên a và b. So sánh và in ra màn hình con số lớn hơn.
