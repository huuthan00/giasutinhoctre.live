Buổi 16: Xử lý chuỗi và Caesar Cipher

Bài giảng chi tiết cho tiết học 90 phút: lý thuyết, ví dụ code, giải thích từng bước, bài tập trên lớp và bài tập về nhà.

Lý thuyếtNội dung được triển khai chi tiết theo từng khái niệm.
Code mẫuCác ví dụ C++ console có giải thích từng bước.
Thực hànhBài tập trên lớp và bài tập về nhà rõ yêu cầu.

1. Mục tiêu buổi học

  • Biết kết hợp vòng lặp để duyệt từng ký tự trong biến chuỗi (string) để xử lý logic.
  • Biết cách kiểm tra một ký tự ở mức độ cơ bản: xem nó là chữ cái hay là chữ số, hay là một dấu khoảng trắng.
  • Biết cách chủ động chuyển đổi một chữ viết hoa thành viết thường (và ngược lại) thông qua biến đổi bảng mã ký tự.
  • Hiểu được ý tưởng cơ bản của kỹ thuật mã hóa Caesar: Dịch chuyển các ký tự đi một số bước nhất định trong bảng chữ cái (ví dụ A dịch 3 bước thành D).
  • Biết áp dụng xử lý chuỗi để tạo ra một mini tool làm ứng dụng bảo mật đơn giản.
  • Học sinh tự tay viết được toàn bộ chương trình mã hóa và giải mã theo chuẩn Caesar Cipher cơ bản.

2. Lý thuyết chi tiết

  • Mã ASCII (Lý thuyết cốt lõi): Máy tính không hiểu chữ "A". Nó lưu chữ "A" dưới dạng một con số (số 65). Chữ "B" là 66, "C" là 67... Chữ thường "a" là 97. Tức là các ký tự thực chất là các CON SỐ ẩn danh.

Kiểm tra ký tự: Nhờ mã ASCII, ta có thể kiểm tra một ký tự c có phải chữ cái in hoa không bằng biểu thức toán học: if (c >= 'A' && c <= 'Z').

Đổi chữ thường thành chữ hoa: Từ "a" (97) muốn thành "A" (65), ta chỉ cần lấy giá trị đó trừ đi 32. Ngược lại, hoa thành thường thì cộng thêm 32. (Lưu ý: Chỉ thực hiện với các chữ cái).

  • Mã hoá Caesar Cipher: Kỹ thuật mã hoá nổi tiếng của Julius Caesar. Để giấu thông tin, ông dịch tất cả chữ cái trong thư đi K bước. Ví dụ K = 3: chữ 'A' + 3 = 'D', chữ 'B' + 3 = 'E'. Người nhận biết được "chìa khóa" K=3 thì lấy mật thư trừ lại đi 3 bước để giải mã.
Minh họa chi tiết

Ý tưởng trực quan: Hai vòng tròn bảng chữ cái đồng tâm lồng vào nhau, vòng trong bị xoay lệch đi 3 nấc so với vòng ngoài để minh họa cách tạo mã Caesar

  • Cách trình bày: Vẽ hai vòng chữ cái: vòng ngoài là chữ gốc, vòng trong lệch 3 vị trí là chữ sau mã hóa.
  • Ví dụ thao tác: Mã hóa A -> D, B -> E, C -> F, rồi thử từ CAT thành FDW.
  • Điểm cần chốt: Chốt rằng Caesar Cipher là dịch ký tự theo một số bước cố định trong bảng chữ cái.
  • Câu hỏi kiểm tra nhanh: Nếu dịch 3 bước, chữ Z cần quay vòng về chữ nào?

3. Ví dụ minh họa

Ví dụ 1: Kiểm tra các loại ký tự trong chuỗi

#include <iostream>
#include <string>
using namespace std;

int main() {
    string text = "Password123!";
    int soChuCai = 0, soChuSo = 0;

    // Duyệt qua toàn bộ ký tự
    for (int i = 0; i < text.length(); i++) {
        char c = text[i];

        // Kiểm tra xem có phải chữ cái không
        if ((c >= 'A' && c <= 'Z') || (c >= 'a' && c <= 'z')) {
            soChuCai++;
        }
        // Kiểm tra xem có phải chữ số không
        else if (c >= '0' && c <= '9') {
            soChuSo++;
        }
    }

    cout << "Chuoi co " << soChuCai << " chu cai va " << soChuSo << " chu so." << endl;
    return 0;
}

Ví dụ 2: Mini Tool viết hoa toàn bộ chuỗi

#include <iostream>
#include <string>
using namespace std;

int main() {
    string ten = "nGuYeN vAn a";

    for (int i = 0; i < ten.length(); i++) {
        // Chỉ đổi nếu nó đang là chữ cái thường
        if (ten[i] >= 'a' && ten[i] <= 'z') {
            ten[i] = ten[i] - 32; // Công thức đổi thường thành hoa
        }
    }

    cout << "Sau khi viet hoa: " << ten << endl; // Kết quả: NGUYEN VAN A
    return 0;
}

Ví dụ 3: Mã hóa Caesar Cipher cơ bản

#include <iostream>
#include <string>
using namespace std;

int main() {
    string matThu = "HELLO";
    int khoaK = 3; // Dịch chuyển 3 bước

    cout << "Ban goc: " << matThu << endl;

    // Quá trình Mã Hóa
    for (int i = 0; i < matThu.length(); i++) {
        matThu[i] = matThu[i] + khoaK; // Cộng thêm K vào để biến đổi chữ
    }
    cout << "Sau khi ma hoa: " << matThu << endl; // Sẽ in ra: KHOOR

    // Quá trình Giải Mã
    for (int i = 0; i < matThu.length(); i++) {
        matThu[i] = matThu[i] - khoaK; // Trừ K đi để về chữ cũ
    }
    cout << "Sau khi giai ma: " << matThu << endl; // Trở lại: HELLO

    return 0;
}

4. Bài tập thực hành trên lớp

  • Bài 1: Viết chương trình nhập vào một đoạn chat. Dùng vòng lặp kiểm tra và tự động "Che mờ" tất cả các chữ số (0-9) thành dấu * (Ví dụ: "Toi co 50k" -> "Toi co k").
  • Bài 2: Nâng cấp Ví dụ 2: Viết chương trình nhận vào một tên nhập lộn xộn. Hãy chuyển toàn bộ chuỗi thành chữ thường (Bằng cách cộng 32), sau đó chỉnh sửa riêng ký tự [0] thành chữ hoa (trừ 32) để tên được viết hoa chữ cái đầu.
  • Bài 3: Chạy thử Ví dụ 3 với chuỗi matThu = "XYZ". Bạn sẽ thấy lỗi sinh ra các ký tự kỳ lạ. Hãy suy nghĩ lý do (Do cộng thêm 3 bị vượt qua chữ Z).
