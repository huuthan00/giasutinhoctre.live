Buổi 25: Tìm kiếm tuyến tính theo mã và tên

Bài giảng chi tiết cho tiết học 90 phút: lý thuyết, ví dụ code, giải thích từng bước, bài tập trên lớp và bài tập về nhà.

Lý thuyếtNội dung được triển khai chi tiết theo từng khái niệm.
Code mẫuCác ví dụ C++ console có giải thích từng bước.
Thực hànhBài tập trên lớp và bài tập về nhà rõ yêu cầu.

1. Mục tiêu buổi học

  • Biết tìm kiếm tuyến tính trên vector.
  • Biết tìm theo mã chính xác.
  • Biết tìm theo tên ở mức cơ bản.
  • Biết trả về vị trí phần tử tìm thấy.
  • Biết xử lý không tìm thấy và tìm thấy nhiều kết quả.
  • Học sinh viết được chức năng tìm học sinh/sản phẩm theo mã hoặc tên.

2. Lý thuyết chi tiết

  • Tìm kiếm chính xác (Tìm theo Mã): Mã ID là duy nhất (không có 2 sinh viên trùng mã). Do đó, khi tìm kiếm theo mã, nếu ta thấy sự trùng khớp ==, ta có thể break dừng vòng lặp ngay lập tức vì không cần tìm thêm nữa.
  • Tìm kiếm tương đối / Tìm nhiều kết quả (Tìm theo Tên): Một lớp có thể có nhiều bạn tên "Hải". Do đó, khi tìm theo tên, ta không được dùng lệnh break khi thấy kết quả đầu tiên. Ta phải để vòng lặp chạy từ đầu đến cuối danh sách, cứ thấy tên khớp là in ra.
Minh họa chi tiết

Ý tưởng trực quan: Bảng minh họa: Cột Tìm theo ID (Số thứ tự chứng minh nhân dân) chỉ trỏ tới duy nhất 1 người. Cột Tìm theo Tên (Nguyễn Văn A) trỏ tới 3 người khác nhau trong danh sách

  • Cách trình bày: Vẽ bảng hai cột: tìm theo ID trả về một người duy nhất, tìm theo tên có thể trả về nhiều người.
  • Ví dụ thao tác: Cho ví dụ id = SV03 chỉ có một kết quả, nhưng tên An có thể có Nguyen An, Le An, Tran An.
  • Điểm cần chốt: Chốt rằng tìm theo mã thường là chính xác, tìm theo tên cần chuẩn bị trường hợp nhiều kết quả.
  • Câu hỏi kiểm tra nhanh: Hàm tìm theo mã nên trả về một vị trí hay một danh sách vị trí?
  • Đếm số lượng kết quả: Để xử lý việc "Không tìm thấy" trong bài toán tìm tên, ta dùng một biến int soKetQua = 0;. Mỗi lần tìm thấy, ta tăng biến này lên 1. Sau vòng lặp, nếu soKetQua == 0, chứng tỏ không có ai tên như vậy.

3. Ví dụ minh họa

Ví dụ 1: Tìm chính xác theo Mã (Dừng ngay khi thấy)

#include <iostream>
#include <vector>
#include <string>
using namespace std;

struct KhachHang { int ma; string ten; };

void timTheoMa(vector<KhachHang> ds) {
    int maTim;
    cout << "Nhap Ma KH can tim: "; cin >> maTim;

    bool daTimThay = false; // Biến cờ hiệu true/false

    for (int i = 0; i < ds.size(); i++) {
        if (ds[i].ma == maTim) {
            cout << "=> Da thay: Khach hang " << ds[i].ten << "\n";
            daTimThay = true;
            break; // Thoát ngay, tiết kiệm thời gian chạy
        }
    }

    if (daTimThay == false) cout << "Khong co Khach hang nay!\n";
}

Ví dụ 2: Tìm theo Tên (Liệt kê tất cả kết quả)

void timTheoTen(vector<KhachHang> ds) {
    string tenTim;
    cout << "Nhap Ten KH can tim: ";
    cin.ignore();
    getline(cin, tenTim);

    int soKetQua = 0; // Dùng để đếm

    cout << "--- KET QUA TIM KIEM ---\n";
    for (int i = 0; i < ds.size(); i++) {
        // So sánh bằng (Tên phải nhập chính xác hoàn toàn)
        if (ds[i].ten == tenTim) {
            cout << "- Ma: " << ds[i].ma << " | Ten: " << ds[i].ten << "\n";
            soKetQua++;
        }
    }

    if (soKetQua == 0) {
        cout << "(Khong tim thay khach hang nao ten la " << tenTim << ")\n";
    } else {
        cout << "=> Tim thay " << soKetQua << " nguoi.\n";
    }
}

4. Bài tập thực hành trên lớp

  • Bài 1: Cho vector<Sach> chứa danh sách sách trong thư viện. Viết hàm tìm kiếm theo tên sách. Nếu tìm thấy, in ra thông tin sách, nếu không in ra báo lỗi.
  • Bài 2: (Nâng cao nhỏ): Làm thế nào để giải quyết vấn đề nhập chữ hoa, chữ thường khi tìm kiếm? Hãy thử yêu cầu người dùng nhập tên bằng chữ viết thường, và dùng thuật toán (ở Buổi 16) đưa tên sách về chữ thường trước khi so sánh ==.
