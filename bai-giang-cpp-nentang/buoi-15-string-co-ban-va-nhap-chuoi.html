Buổi 15: String cơ bản và nhập chuỗi

Bài giảng chi tiết cho tiết học 90 phút: lý thuyết, ví dụ code, giải thích từng bước, bài tập trên lớp và bài tập về nhà.

Lý thuyếtNội dung được triển khai chi tiết theo từng khái niệm.
Code mẫuCác ví dụ C++ console có giải thích từng bước.
Thực hànhBài tập trên lớp và bài tập về nhà rõ yêu cầu.

1. Mục tiêu buổi học

  • Nắm vững kiểu dữ liệu string được dùng chuyên biệt để lưu trữ văn bản, câu chữ.
  • Phân biệt rõ sự khác nhau giữa việc nhập chuỗi bằng cin và lệnh getline.
  • Biết cách kiểm tra độ dài của chuỗi (có bao nhiêu ký tự) bằng phương thức .length() hoặc .size().
  • Hiểu rằng string có thể coi như một "mảng các ký tự", biết cách dùng chỉ số (index) để truy cập từng chữ cái.
  • Biết cách sử dụng phép toán cộng + để nối chuỗi và các toán tử để so sánh chuỗi cơ bản.
  • Học sinh viết được chương trình nhập thông tin họ tên, đếm độ dài chữ và in tách rời từng ký tự.

2. Lý thuyết chi tiết

  • Thư viện <string>: Chuỗi văn bản trong C++ được hỗ trợ bởi kiểu string. Bạn có thể lưu 1 chữ cái "A" hoặc cả một bài văn dài.
  • cin vs getline:
  • Lệnh cin >> chỉ đọc đến khi gặp dấu khoảng trắng (dấu cách) đầu tiên là nó dừng. (Nhập "Nguyen Van A" nó chỉ lưu "Nguyen").
  • Lệnh getline(cin, tenBien); sẽ thu thập mọi thứ trên dòng đó cho đến khi bạn ấn phím Enter.
  • Lấy độ dài chuỗi: Dùng tenBien.length() hoặc tenBien.size(). Chú ý: Dấu cách và dấu chấm câu đều được đếm là 1 ký tự!
Minh họa chi tiết

Ý tưởng trực quan: Chuỗi "HELLO WORLD", mỗi chữ cái và khoảng trắng nằm trong một ô vuông có đánh số chỉ số từ 0 đến 10 bên dưới

  • Cách trình bày: Vẽ chuỗi thành các ô ký tự: H, E, L, L, O, khoảng trắng, W... bên dưới ghi chỉ số 0, 1, 2...
  • Ví dụ thao tác: Cho học sinh đọc s[0], s[4], s.length(), rồi thử duyệt từng ký tự bằng vòng lặp.
  • Điểm cần chốt: Chốt rằng string có thể xem như một dãy ký tự, truy cập được bằng chỉ số.
  • Câu hỏi kiểm tra nhanh: Trong chuỗi CODE, ký tự ở chỉ số 2 là gì?
  • String là một mảng ký tự (char): Chữ H trong chữ "HELLO" nằm ở vị trí số 0. Bạn có thể lấy chữ H ra bằng cách gọi chỉ số [0] giống y hệt như mảng.
  • Nối chuỗi và So sánh: Bạn có thể lấy chuỗi "Xin" + chuỗi "Chào" để được "XinChào". Phép == giúp kiểm tra xem hai mật khẩu người dùng nhập có khớp nhau hay không.

3. Ví dụ minh họa

Ví dụ 1: Khai báo, nhập tên và đo độ dài

#include <iostream>
#include <string> // Phải có thư viện này
using namespace std;

int main() {
    string hoTen;
    cout << "Nhap ho va ten cua ban: ";
    getline(cin, hoTen); // Dùng getline để lấy được cả họ và tên

    // Đo độ dài của chuỗi
    cout << "Ten cua ban dai " << hoTen.length() << " ky tu (tinh ca khoang trang)." << endl;

    return 0;
}

Ví dụ 2: Truy cập từng ký tự trong chuỗi

#include <iostream>
#include <string>
using namespace std;

int main() {
    string matKhau = "Gemini AI";

    // In ký tự đầu tiên và cuối cùng
    cout << "Ky tu dau tien: " << matKhau[0] << endl;
    cout << "Ky tu cuoi cung: " << matKhau[matKhau.length() - 1] << endl;

    // Duyệt in dọc từng chữ cái (như mảng)
    cout << "In tung chu cai doc:\n";
    for (int i = 0; i < matKhau.length(); i++) {
        cout << matKhau[i] << endl;
    }

    return 0;
}

Giải thích: Vòng lặp for chạy từ 0 đến bé hơn độ dài chuỗi, kết hợp matKhau[i] giúp ta đi qua từng chữ cái.

Ví dụ 3: Nối và So sánh chuỗi

#include <iostream>
#include <string>
using namespace std;

int main() {
    string ho = "Nguyen";
    string ten = "An";

    // Nối chuỗi bằng toán tử + (nhớ thêm khoảng trắng ở giữa)
    string hoVaTen = ho + " " + ten;
    cout << "Ho ten day du: " << hoVaTen << endl;

    // So sánh chuỗi
    string pass1 = "12345", pass2 = "12345";
    if (pass1 == pass2) {
        cout << "Mat khau khop nhau!" << endl;
    }

    return 0;
}

4. Bài tập thực hành trên lớp

  • Bài 1: Viết chương trình yêu cầu người dùng nhập họ tên của mình. Sau đó in ra màn hình chỉ ký tự đầu tiên và ký tự cuối cùng trong tên của họ.
  • Bài 2: Khai báo một chuỗi string loiChuc = "Chuc Mung Nam Moi";. Dùng vòng lặp duyệt qua chuỗi và đếm xem trong câu đó có bao nhiêu khoảng trắng.
  • Bài 3: Viết hệ thống tạo mật khẩu. Yêu cầu người dùng tạo mật khẩu mới. Nếu mật khẩu có độ dài nhỏ hơn 8 ký tự, báo lỗi "Mật khẩu quá ngắn" và bắt nhập lại.

5. Bài tập về nhà

  • Bài 1: Viết chương trình nhập vào một câu văn bất kỳ. Hãy in câu văn đó ra màn hình nhưng theo thứ tự đảo ngược lại (Từ cuối lên đầu) (Gợi ý: Dùng vòng lặp for lùi).
  • Bài 2: Viết chương trình đăng ký tài khoản. Nhập vào Username và Password. In ra lời chào có dạng "Xin chào [Username], mật khẩu của bạn dài [số lượng] ký tự".
