Buổi 04: Chia nguyên, chia dư và bài toán chẵn lẻ

Bài giảng chi tiết cho tiết học 90 phút: lý thuyết, ví dụ code, giải thích từng bước, bài tập trên lớp và bài tập về nhà.

1. Mục tiêu buổi học

  • Nắm vững cơ chế phép chia nguyên / khi hai toán hạng đều là số nguyên.
  • Hiểu cách dùng toán tử chia lấy dư % và ý nghĩa của phần dư.
  • Biết cách kiểm tra một số là chẵn hay lẻ bằng biểu thức n % 2.
  • Biết kiểm tra phép tính chia hết và xử lý trường hợp mẫu số bằng 0.
  • Biết ứng dụng phép / và % vào các bài toán thực tế như đổi thời gian, tách chữ số, chia nhóm.
  • Học sinh viết được các bài tập: xét tính chẵn lẻ, xét tính chia hết, đổi từ giây sang định dạng giờ-phút-giây.

2. Lý thuyết chi tiết

Phép chia nguyên (/): Khi cả tử và mẫu là số nguyên (int), phép chia / chỉ giữ lại phần thương nguyên. Ví dụ: 14 / 3 = 4 (bỏ qua phần lẻ).

Phép chia lấy dư (%): Toán tử % chỉ lấy phần dư của phép chia. Phép tính này chỉ áp dụng cho số nguyên. Ví dụ: 14 % 3 = 2 (vì 14 chia 3 được 4, dư 2).

Minh họa chi tiết

Ý tưởng trực quan: Phép tính đặt tính rồi tính thời Tiểu học, khoanh tròn vào phần "Thương" ứng với dấu /, và phần "Số dư" ứng với dấu %

  • Cách trình bày: Vẽ phép chia tiểu học 17 : 5 = 3 dư 2, tô màu 3 là thương và 2 là số dư.
  • Ví dụ thao tác: Đặt cạnh biểu thức C++: 17 / 5 == 3 và 17 % 5 == 2. Sau đó thử thêm 20 / 5 và 20 % 5.
  • Điểm cần chốt: Chốt rằng / với số nguyên lấy phần nguyên, % lấy phần dư; % rất hữu ích để kiểm tra chẵn lẻ và chia hết.
  • Câu hỏi kiểm tra nhanh: Nếu n % 2 == 0, ta kết luận được điều gì về n?

Ứng dụng kiểm tra chẵn / lẻ: Một số khi chia lấy dư cho 2 (n % 2) thì chỉ có 2 khả năng: Nếu dư 0 thì là số chẵn; nếu dư 1 thì là số lẻ.

Kiểm tra chia hết: Số A chia hết cho B khi và chỉ khi A % B == 0 (nghĩa là số dư bằng 0). Lưu ý, tuyệt đối không được để số chia (mẫu số) bằng 0, nếu không chương trình sẽ bị sập (crash).

Các ứng dụng kinh điển: Phép / và % là "cặp bài trùng" để tách các con số (tách hàng chục, đơn vị) hoặc quy đổi các đại lượng (ví dụ: chia giây thành phút, giờ).

3. Ví dụ minh họa

Ví dụ 1: Bài toán chia nhóm

#include <iostream>
using namespace std;

int main() {
    int soHocSinh = 23;
    int kichThuocNhom = 5;

    // Dùng / để tìm số nhóm nguyên vẹn
    int soNhom = soHocSinh / kichThuocNhom;

    // Dùng % để tìm số bạn còn dư lại
    int soBanDu = soHocSinh % kichThuocNhom;

    cout << "Co " << soNhom << " nhom day du." << endl;
    cout << "Con le " << soBanDu << " ban." << endl;

    return 0;
}

Giải thích: Phép chia 23 / 5 cho kết quả phần nguyên là 4 (nhóm). Phép chia lấy dư 23 % 5 trả về phần dư là 3 (bạn lẻ ra).

Ví dụ 2: Tách chữ số

#include <iostream>
using namespace std;

int main() {
    int so = 85;

    int hangChuc = so / 10; // 85 / 10 = 8
    int hangDonVi = so % 10; // 85 % 10 = 5

    cout << "Chu so hang chuc: " << hangChuc << endl;
    cout << "Chu so hang don vi: " << hangDonVi << endl;

    return 0;
}

Giải thích: Bất kỳ số nào khi chia cho 10 bằng toán tử / sẽ mất đi hàng đơn vị. Khi dùng toán tử % 10, ta luôn luôn lấy được chữ số tận cùng (hàng đơn vị).

Ví dụ 3: Đổi thời gian (Giây sang Phút, Giây)

#include <iostream>
using namespace std;

int main() {
    int tongGiay = 135;

    int phut = tongGiay / 60; // Lấy số phút nguyên
    int giayLe = tongGiay % 60; // Lấy phần giây dư ra

    cout << tongGiay << " giay tuong duong voi: ";
    cout << phut << " phut va " << giayLe << " giay." << endl; // Đổi giây sang giờ-phút-giây

    return 0;
}

Giải thích: Một phút có 60 giây. Chia cho 60 (/) sẽ ra được tổng số phút. Chia dư cho 60 (%) sẽ ra được số giây lẻ không đủ tạo thành 1 phút.

4. Bài tập thực hành trên lớp

  • Bài 1: Nhập vào một số nguyên. Tính và in ra phần dư của số đó khi chia cho 7.
  • Bài 2: Viết chương trình nhập vào một số tự nhiên (là thời gian tính bằng giây). Hãy quy đổi và in ra màn hình dưới dạng: Giờ - Phút - Giây (Gợi ý: 1 giờ = 3600 giây).
  • Bài 3: Có N cái kẹo chia đều cho M em bé. Hỏi mỗi em nhận được bao nhiêu cái kẹo đầy đủ và cô giáo còn giữ lại bao nhiêu cái? (Nhập N và M từ bàn phím) .

5. Bài tập về nhà

  • Bài 1: Viết chương trình nhập vào một số nguyên dương có 2 chữ số (từ 10 đến 99). Hãy in ra con số đảo ngược của số đó (Ví dụ: Nhập 47 -> In ra 74). (Gợi ý: Dùng / 10 và % 10 để tách số, sau đó ghép lại) .
  • Bài 2: (Tìm hiểu trước cho bài hôm sau): Hãy thử tìm hiểu xem nếu mình muốn làm một bài kiểm tra "Số này có lớn hơn 5 không?", mình sẽ dùng lệnh gì trong C++?

6. Checklist cuối buổi

Học sinh tự trả lời các câu hỏi:

  • Toán tử / và % khác nhau như thế nào với số nguyên?
  • Làm sao để biết một số là chẵn hay lẻ bằng toán tử %?
  • Muốn lấy chữ số hàng đơn vị của một số, ta chia lấy dư cho mấy?
  • Tại sao mẫu số trong phép chia hoặc phép lấy dư không được bằng 0?
