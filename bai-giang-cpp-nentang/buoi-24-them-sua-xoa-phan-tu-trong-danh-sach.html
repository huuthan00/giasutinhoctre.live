Buổi 24: Thêm, sửa, xóa phần tử trong danh sách

Bài giảng chi tiết cho tiết học 90 phút: lý thuyết, ví dụ code, giải thích từng bước, bài tập trên lớp và bài tập về nhà.

Lý thuyếtNội dung được triển khai chi tiết theo từng khái niệm.
Code mẫuCác ví dụ C++ console có giải thích từng bước.
Thực hànhBài tập trên lớp và bài tập về nhà rõ yêu cầu.

1. Mục tiêu buổi học

  • Biết thêm phần tử mới vào vector.
  • Biết tìm phần tử cần sửa hoặc xóa theo mã.
  • Biết sửa từng trường dữ liệu của một phần tử.
  • Biết xóa phần tử bằng erase.
  • Biết kiểm tra mã có tồn tại trước khi thao tác.
  • Học sinh viết được chức năng thêm, sửa, xóa cho danh sách struct.

2. Lý thuyết chi tiết

  • Thêm mới (Create): Khởi tạo một biến struct tạm thời, cho người dùng nhập thông tin vào biến đó (lưu ý dùng cin.ignore() nếu nhập chữ sau số), cuối cùng đẩy cả khối struct đó vào vector bằng .push_back().
  • Cơ chế tìm trước khi Sửa/Xóa: Bạn không thể sửa đồ nếu không biết nó nằm ở đâu. Do đó, phải viết vòng lặp tìm kiếm xem Mã sản phẩm mà người dùng nhập có khớp với bất kỳ sản phẩm nào trong mảng không. Nếu tìm thấy, ta lưu lại vị trí (index i). Nếu duyệt hết mảng mà không thấy, ta báo lỗi.
Minh họa chi tiết

Ý tưởng trực quan: Một robot rà quét dọc theo kệ hàng (Vector). Robot quét mã vạch (ID) từng món đồ. Khi tìm thấy mã khớp, robot tiến hành dán nhãn giá mới (Sửa) hoặc gắp món đồ đó ném ra khỏi kệ (Xóa)

  • Cách trình bày: Vẽ robot đi dọc vector, quét từng mã. Khi mã khớp, robot dừng lại để sửa nhãn hoặc gắp phần tử ra.
  • Ví dụ thao tác: Minh họa tìm id = 103 trong danh sách sản phẩm rồi cho phép sửa price hoặc xóa sản phẩm.
  • Điểm cần chốt: Chốt rằng sửa/xóa thường bắt đầu bằng bước tìm vị trí phần tử cần thao tác.
  • Câu hỏi kiểm tra nhanh: Nếu không tìm thấy mã, chương trình nên in thông báo gì?
  • Xóa bằng .erase(): Khi đã có vị trí index cần xóa, ta dùng lệnh ds.erase(ds.begin() + index);. Lệnh này sẽ rút món đồ đó ra, và các phần tử phía sau sẽ tự động dồn lên lấp khoảng trống.

3. Ví dụ minh họa

Ví dụ 1: Thêm phần tử vào danh sách

#include <iostream>
#include <vector>
#include <string>
using namespace std;

struct MonAn { int id; string ten; int gia; };

void themMonAn(vector<MonAn> &ds) {
    MonAn monMoi;
    cout << "Nhap ID mon: "; cin >> monMoi.id;
    cin.ignore();
    cout << "Nhap ten mon: "; getline(cin, monMoi.ten);
    cout << "Nhap gia: "; cin >> monMoi.gia;

    ds.push_back(monMoi); // Đẩy vào danh sách
    cout << "Them mon an thanh cong!\n";
}

Ví dụ 2: Sửa thông tin theo Mã ID

void suaGiaMonAn(vector<MonAn> &ds) {
    int idCanSua;
    cout << "Nhap ID mon an can sua: ";
    cin >> idCanSua;

    int viTri = -1; // Biến cờ hiệu, -1 là chưa tìm thấy
    for (int i = 0; i < ds.size(); i++) {
        if (ds[i].id == idCanSua) {
            viTri = i; // Đã tìm thấy vị trí
            break;
        }
    }

    if (viTri != -1) {
        cout << "Gia cu la " << ds[viTri].gia << ". Nhap gia moi: ";
        cin >> ds[viTri].gia; // Sửa trường dữ liệu
        cout << "Cap nhat thanh cong!\n";
    } else {
        cout << "Khong tim thay mon an co ID " << idCanSua << "!\n";
    }
}

Ví dụ 3: Xóa phần tử theo Mã ID

void xoaMonAn(vector<MonAn> &ds) {
    int idCanXoa;
    cout << "Nhap ID mon an can xoa: ";
    cin >> idCanXoa;

    int viTri = -1;
    for (int i = 0; i < ds.size(); i++) {
        if (ds[i].id == idCanXoa) {
            viTri = i; break;
        }
    }

    if (viTri != -1) {
        ds.erase(ds.begin() + viTri); // Xóa tại vị trí tìm được
        cout << "Da xoa mon an khoi thuc don!\n";
    } else {
        cout << "Loi! Ma ID khong ton tai.\n";
    }
}

4. Bài tập thực hành trên lớp

  • Bài 1: Dựa trên cấu trúc SinhVien, hãy viết hàm cập nhật điểm số cho một sinh viên. Yêu cầu nhập Mã SV, tìm kiếm, nếu có thì cho nhập điểm mới, nếu không có thì báo lỗi "Không tìm thấy mã".
  • Bài 2: Viết một chương trình nhỏ tạo sẵn mảng gồm 3 sinh viên. Gọi hàm xóa sinh viên để người dùng nhập mã xóa. Sau khi xóa, dùng vòng lặp in danh sách còn lại để kiểm chứng.

6. Checklist cuối buổi
