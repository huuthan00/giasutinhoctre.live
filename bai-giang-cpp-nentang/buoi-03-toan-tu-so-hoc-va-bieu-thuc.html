Buổi 03: Toán tử số học và biểu thức

Bài giảng chi tiết cho tiết học 90 phút: lý thuyết, ví dụ code, giải thích từng bước, bài tập trên lớp và bài tập về nhà.

Lý thuyếtNội dung được triển khai chi tiết theo từng khái niệm.
Code mẫuCác ví dụ C++ console có giải thích từng bước.
Thực hànhBài tập trên lớp và bài tập về nhà rõ yêu cầu.

1. Mục tiêu buổi học

  • Biết dùng các phép toán +, -, *, / trong các bài toán tính toán cơ bản.
  • Hiểu được thứ tự ưu tiên của phép tính và vai trò quan trọng của dấu ngoặc.
  • Nhận biết và phân biệt được phép chia số nguyên và chia số thực.
  • Biết dùng biến trung gian để giúp đoạn code dễ đọc, dễ hiểu hơn.
  • Biết cách chọn kiểu dữ liệu double cho các giá trị như điểm số, tiền bạc, diện tích hay những kết quả có phần lẻ.
  • Học sinh tự viết được chương trình tính điểm trung bình, tính tiền hóa đơn, chu vi và diện tích.

2. Lý thuyết chi tiết

Các toán tử cơ bản: Trong C++, các phép tính cộng, trừ, nhân, chia được biểu diễn bằng các ký hiệu lần lượt là +, -, *, /.

Thứ tự ưu tiên: Giống hệt như toán học ở trường, C++ tính nhân chia trước, cộng trừ sau. Nếu muốn thay đổi thứ tự này, bắt buộc phải dùng dấu ngoặc tròn ( ).

Minh họa chi tiết

Ý tưởng trực quan: Biểu đồ thứ tự ưu tiên phép toán - Dấu ngoặc () -> Nhân/Chia -> Cộng/Trừ

  • Cách trình bày: Vẽ tháp ưu tiên 3 tầng: tầng 1 (), tầng 2 * / %, tầng 3 + -. Mũi tên đi từ tầng trên xuống tầng dưới.
  • Ví dụ thao tác: Cho học sinh tính tay 3 biểu thức: 2 + 3 * 4, (2 + 3) * 4, 20 / 5 + 6 * 2. Gạch chân phép được tính trước ở từng bước.
  • Điểm cần chốt: Chốt rằng dấu ngoặc có quyền ưu tiên cao nhất; nhân/chia/chia dư làm trước cộng/trừ; cùng mức thì thường tính từ trái sang phải.
  • Câu hỏi kiểm tra nhanh: Trong biểu thức 10 - 2 * 3 + 4, phép nào được thực hiện đầu tiên và vì sao?

Lưu ý cực kỳ quan trọng về phép chia: Trong C++, nếu bạn lấy một số nguyên chia cho một số nguyên (ví dụ 5 / 2), kết quả sẽ bị cắt bỏ phần thập phân và chỉ lấy phần nguyên (kết quả là 2). Để có kết quả là số thực (2.5), ít nhất một trong hai số phải là số thực (ví dụ 5.0 / 2), hoặc phải ép kiểu.

Dùng biến trung gian: Thay vì viết một biểu thức tính toán dài ngoằng và phức tạp vào lệnh in cout, hãy tính toán rồi lưu kết quả vào một biến trung gian trước. Việc này giúp code rất dễ đọc và dễ tìm lỗi.

Lựa chọn kiểu dữ liệu: Khi làm việc với điểm số, tính tiền, hay tính diện tích, hãy tạo thói quen sử dụng kiểu double vì kết quả thường sẽ có phần thập phân.

3. Ví dụ minh họa

Ví dụ 1: Tính chu vi và diện tích hình chữ nhật

#include <iostream>
using namespace std;

int main() {
    double chieuDai = 5.5; // Dùng double cho diện tích
    double chieuRong = 3.0;

    // Dùng biến trung gian để code dễ đọc
    double chuVi = (chieuDai + chieuRong) * 2; // Cần dấu ngoặc để cộng trước
    double dienTich = chieuDai * chieuRong; // Dùng toán tử *

    cout << "Chu vi: " << chuVi << endl;
    cout << "Dien tich: " << dienTich << endl;

    return 0;
}

Giải thích: Ở dòng 9, nếu ta không dùng dấu ngoặc (), máy tính sẽ lấy chieuRong * 2 trước, dẫn đến sai kết quả chu vi. Ở dòng 9 và 10, ta dùng biến trung gian chuVi và dienTich thay vì tính trực tiếp bên trong lệnh cout.

Ví dụ 2: Tính điểm trung bình môn học

#include <iostream>
using namespace std;

int main() {
    double toan = 8.0, van = 7.5; // Điểm số dùng double

    // Dùng ngoặc để tính tổng trước khi chia
    double diemTrungBinh = (toan + van) / 2;

    cout << "Diem trung binh cua ban la: " << diemTrungBinh << endl;

    return 0;
}

Giải thích: Vì biến toan và van đã là double, nên phép chia ở dòng 8 là phép chia số thực, trả về kết quả chính xác có phần lẻ (7.75).

Ví dụ 3: Lỗi phép chia số nguyên

#include <iostream>
using namespace std;

int main() {
    int a = 7;
    int b = 2;

    cout << "Ket qua 7 / 2 la: " << a / b << endl; // Sẽ in ra 3, không phải 3.5

    // Cách sửa để ra số thực
    cout << "Ket qua dung: " << (double)a / b << endl;
    return 0;
}

Giải thích: Khi hai toán hạng là số nguyên, C++ dùng phép chia nguyên. Bằng cách thêm (double) trước biến a, ta ép nó thành số thực, từ đó phép tính trở thành chia số thực.

4. Bài tập thực hành trên lớp

  • Bài 1: Viết chương trình nhập vào độ dài 3 cạnh của một hình tam giác. Tính chu vi của hình tam giác đó.
  • Bài 2: Một quán trà sữa bán mỗi ly giá 35.000 VNĐ. Viết chương trình nhập vào số lượng ly khách mua, tính tổng số tiền khách phải trả (dùng biến double cho tiền).
  • Bài 3: Viết chương trình tính nhiệt độ. Nhập vào nhiệt độ theo độ F, chuyển đổi sang độ C theo công thức: C = (F - 32) * 5 / 9. (Nhắc học sinh cẩn thận phép chia nguyên).

5. Bài tập về nhà

  • Bài 1: Viết chương trình tính điểm xét tuyển. Nhập vào điểm 3 môn Toán, Lý, Hóa. Biết Toán nhân hệ số 2, hãy tính tổng điểm xét tuyển và in ra màn hình.
  • Bài 2: Viết chương trình tính chu vi và diện tích hình tròn khi biết bán kính R (Gợi ý dùng số Pi = 3.14).

6. Checklist cuối buổi

Học sinh tự trả lời các câu hỏi:

  • Ký hiệu phép nhân và phép chia trong C++ là gì?
  • Tại sao 5 / 2 trong C++ lại bằng 2? Làm sao để kết quả ra 2.5?
  • Vì sao nên dùng biến trung gian?
  • Khi làm việc với điểm số, nên khai báo biến kiểu dữ liệu nào?
