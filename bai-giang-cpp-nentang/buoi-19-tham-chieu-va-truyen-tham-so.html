Buổi 19: Tham chiếu và truyền tham số

Bài giảng chi tiết cho tiết học 90 phút: lý thuyết, ví dụ code, giải thích từng bước, bài tập trên lớp và bài tập về nhà.

Lý thuyếtNội dung được triển khai chi tiết theo từng khái niệm.
Code mẫuCác ví dụ C++ console có giải thích từng bước.
Thực hànhBài tập trên lớp và bài tập về nhà rõ yêu cầu.

1. Mục tiêu buổi học

  • Hiểu truyền tham trị và truyền tham chiếu khác nhau như thế nào, biết khi nào dùng dấu & trong tham số hàm.
  • Biết viết hàm hoán đổi hai số bằng tham chiếu và biết truyền vector vào hàm để xử lý.
  • Biết tránh sửa dữ liệu ngoài ý muốn và học sinh viết được hàm nhập vector, sửa giá trị, tính tổng bằng tham số.
  • Mọi ví dụ cần được minh họa bằng code chi tiết, dễ đọc.

2. Lý thuyết chi tiết

  • Truyền Tham Trị (Pass by Value): Khi bạn đưa biến x vào hàm, máy tính đi "photocopy" giá trị của x đưa cho hàm. Hàm có sửa bản copy đó thế nào thì bản gốc x ở bên ngoài cũng không bị suy suyển.
  • Truyền Tham Chiếu (Pass by Reference): Bằng cách thêm dấu và (&) vào trước tên tham số (ví dụ int &a), bạn không đưa bản copy nữa, mà đưa thẳng chìa khóa bản gốc cho hàm. Lúc này, hàm sửa a tức là biến truyền vào ở ngoài main bị đổi theo.
Minh họa chi tiết

Ý tưởng trực quan: Minh họa sự khác biệt: Tham trị (Copy tờ giấy đưa cho bạn xem, bạn xé đi tờ giấy gốc vẫn còn) vs Tham chiếu (Cùng chia sẻ chung 1 tài liệu trên Google Docs, một người xóa chữ thì tài liệu gốc mất chữ)

  • Cách trình bày: Vẽ hai cảnh: tham trị là bản photocopy, tham chiếu là cùng sửa một tài liệu gốc.
  • Ví dụ thao tác: Chạy hàm tang(x) bản tham trị và bản tham chiếu tang(int &x) để so sánh giá trị x sau khi gọi hàm.
  • Điểm cần chốt: Chốt rằng tham trị không làm đổi biến gốc, tham chiếu có thể làm đổi biến gốc.
  • Câu hỏi kiểm tra nhanh: Khi muốn hàm hoán đổi hai biến thật sự, cần truyền tham trị hay tham chiếu?
  • Ứng dụng lớn nhất của Tham chiếu:
  1. Dùng để viết hàm sửa đổi dữ liệu (như hàm hoanDoi()).
  2. Truyền Vector: Vector chứa cả ngàn dữ liệu. Nếu dùng tham trị (copy), máy tính mất rất nhiều công để photocopy cả ngàn dữ liệu đó -> Giật, lag. Truyền bằng & giúp truy cập cực nhanh.

3. Ví dụ minh họa

Ví dụ 1: Sự khác biệt cực lớn của dấu &

#include <iostream>
using namespace std;

// Hàm 1: Photocopy (Tham trị)
void tangThem_ThamTri(int a) {
    a = a + 10;
}

// Hàm 2: Sửa bản gốc (Tham chiếu)
void tangThem_ThamChieu(int &a) {
    a = a + 10;
}

int main() {
    int diem = 5;

    tangThem_ThamTri(diem);
    cout << "Sau ham 1: " << diem << endl; // Vẫn in ra 5

    tangThem_ThamChieu(diem);
    cout << "Sau ham 2: " << diem << endl; // In ra 15
    return 0;
}

Ví dụ 2: Hàm Hoán đổi (Kinh điển)

#include <iostream>
using namespace std;

// Buộc phải dùng & vì ta muốn hoán đổi thật sự ở bản gốc
void hoanDoi(int &x, int &y) {
    int tam = x;
    x = y;
    y = tam;
}

int main() {
    int a = 100, b = 200;
    hoanDoi(a, b);
    cout << "a=" << a << " va b=" << b << endl; // In ra a=200, b=100
    return 0;
}

Ví dụ 3: Truyền Vector vào hàm

#include <iostream>
#include <vector>
using namespace std;

// Hàm thêm điểm vào danh sách. Phải dùng & để danh sách thực sự nhận thêm phần tử.
void themDiem(vector<double> &ds) {
    double d;
    cout << "Nhap diem can them: ";
    cin >> d;
    ds.push_back(d);
}

int main() {
    vector<double> danhSachDiem;
    themDiem(danhSachDiem);
    cout << "Danh sach hien co " << danhSachDiem.size() << " diem.\n";
    return 0;
}

4. Bài tập thực hành trên lớp

  • Bài 1: Thử xóa dấu & ở hàm themDiem() trong Ví dụ 3, chạy lại chương trình và giải thích tại sao kích thước vector lại in ra là 0 (Vì hàm chỉ thêm vào bản copy).
  • Bài 2: Viết hàm void nhapDanhSach(vector<int> &v, int soLuong). Gọi hàm này trong main để nhập 5 phần tử vào mảng.
  • Bài 3: Viết hàm void resetMang(vector<int> &v). Hàm này sẽ duyệt qua toàn bộ mảng và biến tất cả các phần tử thành số 0.
