Buổi 05: Điều kiện if/else cơ bản

Bài giảng chi tiết cho tiết học 90 phút: lý thuyết dễ hiểu, ví dụ code Python, lỗi thường gặp, thực hành trên lớp và bài tập về nhà.

Lý thuyếtDiễn giải bằng ngôn ngữ gần gũi cho học sinh 11-12 tuổi.
Code mẫuVí dụ Python 3 có giải thích từng bước, ưu tiên rõ ràng và dễ sửa.
Thực hànhBài tập trên lớp, bài tập về nhà và mục học sinh tự nói lại.

1. Mục tiêu bài học

  • Hiểu khái niệm điều kiện Đúng/Sai trong lập trình giống như việc đưa ra quyết định ở ngã ba đường.
  • Biết cách sử dụng cấu trúc if, else và dấu hai chấm :.
  • Nắm bắt quy tắc "thụt lề" (indentation) bắt buộc trong Python.
  • Sử dụng thành thạo các toán tử so sánh: == (bằng nhau), != (khác nhau), >, <, >=, <=.
  • Viết được chương trình kiểm tra tuổi, điểm thi đạt/không đạt.

2. Lý thuyết chi tiết

  • Ngã ba đường và Quyết định: Bình thường máy tính chạy code thẳng từ trên xuống dưới. Nhưng đôi khi ta muốn máy tính biết "suy nghĩ": Nếu trời mưa thì ở nhà, ngược lại thì đi chơi. Lệnh if (Nếu) và else (Ngược lại) sinh ra để làm việc này.
  • Toán tử so sánh (Cặp kính lúp): Để biết điều kiện đúng hay sai, ta phải so sánh.
  • Chú ý đặc biệt: Dấu = đứng một mình là để Gán (bỏ đồ vào hộp). Muốn So sánh bằng nhau, ta BẮT BUỘC phải dùng hai dấu bằng == đứng cạnh nhau.
  • Dấu khác nhau là chấm than và dấu bằng !=.
  • Dấu hai chấm : và Quy tắc thụt lề:
  • Cuối dòng if hoặc else luôn phải có dấu :. Nó báo hiệu "Sau đây là những việc cần làm".
  • Thụt lề (Indentation): Các câu lệnh nằm bên trong if phải lùi vào trong 1 khoảng (bằng phím Tab). Python dùng việc thụt lề để biết lệnh nào thuộc về if, lệnh nào nằm ngoài.

3. Ví dụ minh họa (Gõ code cùng giáo viên)

Ví dụ 1: Kiểm tra điểm Đậu/Rớt

diem = 8
if diem >= 5:
print("Chúc mừng bạn đã Đậu!")
else:
print("Bạn rớt rồi, cố lên nhé!")

Vì điểm là 8 (lớn hơn 5), điều kiện là ĐÚNG. Lệnh print bên trong if sẽ chạy, và bỏ qua phần else.

Ví dụ 2: Rạp chiếu phim 13+

tuoi = int(input("Bạn mấy tuổi? "))
if tuoi >= 13:
print("Mời bạn vào xem phim.")
else:
print("Phim này chỉ dành cho người từ 13 tuổi.")

Lấy input, ép thành số rồi so sánh. Nếu nhập 11, điều kiện SAI, sẽ chạy phần else.

Ví dụ 3: Tầm quan trọng của thụt lề

tien = 10
if tien > 0:
print("Bạn có tiền")
print("Tạm biệt!")

Lệnh in "Tạm biệt" không bị thụt lề, nên nó KHÔNG phụ thuộc vào lệnh if. Dù có tiền hay không, nó vẫn luôn in ra "Tạm biệt".

4. Lỗi thường gặp & Cách khắc phục

  • Lỗi: IndentationError: expected an indented block (Lỗi quên thụt lề)
  • Nguyên nhân: Xuống dòng sau dấu : nhưng lại viết code sát lề trái, không ấn phím Tab.
  • Cách sửa: Đặt con trỏ chuột ở đầu dòng báo lỗi, ấn phím Tab để lùi vào trong.
  • Lỗi: SyntaxError: invalid syntax do thiếu dấu :
  • Sai: if tuoi > 18 -> Quên dấu hai chấm ở cuối.
  • Cách sửa: Thêm dấu hai chấm: if tuoi > 18:

5. Bài tập thực hành trên lớp

1. Cấp độ 1: Viết chương trình nhập vào số tiền tiêu vặt của em. Nếu số tiền >= 20000, in ra "Đủ tiền mua trà sữa". Ngược lại in ra "Chưa đủ tiền rồi".
  1. Cấp độ 2 (Chẵn hay Lẻ?): Yêu cầu nhập vào một số nguyên. Dùng phép chia dư (% 2) để kiểm tra: Nếu chia dư cho 2 bằng 0 thì in "Đây là số chẵn", ngược lại in "Đây là số lẻ".
  2. Cấp độ 3 (Số âm hay dương?): Viết chương trình yêu cầu nhập một số. Nếu số đó lớn hơn 0, in ra "Số dương". Nếu nhỏ hơn 0, in ra "Số âm". (Chưa cần xét trường hợp bằng 0).
  3. Cấp độ 4 (Sửa lỗi code): Sửa đoạn code bị lỗi sau:
mat_khau = "12345"
if mat_khau = "12345"
print("Mở khóa thành công")

else

print("Sai mật khẩu")
(Gợi ý: Dòng 2 thiếu dấu `==` và dấu `:`, dòng 3 thiếu thụt lề, dòng 4 thiếu dấu `:`).

6. Bài tập về nhà

  • Hệ thống Đăng Nhập Mini: Cài đặt sẵn một biến mk_dung = "python123". Yêu cầu người dùng nhập mật khẩu vào từ bàn phím. Nếu mật khẩu nhập vào giống hệt mật khẩu đúng, in ra "Đăng nhập thành công, chào mừng sếp!". Ngược lại, in ra "Báo động! Có kẻ đột nhập!".

7. Học sinh cần tự nói lại được gì?

  • "Lệnh if/else giúp chương trình biết đưa ra quyết định."
  • "So sánh bằng nhau phải dùng hai dấu ==, không được dùng một dấu."
  • "Sau if và else phải có dấu hai chấm : và dòng bên dưới phải thụt lề (bấm Tab)."
