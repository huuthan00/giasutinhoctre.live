Buổi 25: Menu console và cấu trúc chương trình

Bài giảng chi tiết cho tiết học 90 phút: lý thuyết dễ hiểu, ví dụ code Python, lỗi thường gặp, thực hành trên lớp và bài tập về nhà.

Lý thuyếtDiễn giải bằng ngôn ngữ gần gũi cho học sinh 11-12 tuổi.
Code mẫuVí dụ Python 3 có giải thích từng bước, ưu tiên rõ ràng và dễ sửa.
Thực hànhBài tập trên lớp, bài tập về nhà và mục học sinh tự nói lại.

1. Mục tiêu bài học

  • Biết cách thiết kế một chương trình phần mềm có giao diện điều khiển bằng văn bản (Menu Console).
  • Hiểu cách tổ chức chương trình thành các Hàm (def) riêng biệt để code không bị rối rắm.
  • Kết hợp vòng lặp while True và cấu trúc if/elif để điều hướng lựa chọn của người dùng.

2. Lý thuyết chi tiết

  • Giao diện Menu Nhà Hàng: Phần mềm chuyên nghiệp không bao giờ tự động chạy tuồn tuột từ đầu đến cuối rồi tắt. Nó sẽ in ra một cái Menu giống như trong nhà hàng: "1. Xem món, 2. Gọi món, 3. Thanh toán (Thoát)". Người dùng gõ phím nào thì nó làm việc đó.
  • Vòng lặp bất tử chờ lệnh: Vòng lặp while True giúp tạo vòng chơi vô tận. Máy tính sẽ liên tục in lại cái Menu và chờ em ra lệnh, cho đến khi em chọn chức năng dùng lệnh break để thoát.
  • Tư duy Kiến trúc sư (Gói code vào Hàm): Nếu em viết tất cả lệnh thêm, xóa, sửa vào chung một chỗ while True, file code sẽ dài hàng trăm dòng, rất dễ lỗi. Tư duy đúng là: Chức năng Thêm tách ra một def them(), chức năng In tách ra một def in_danh_sach(). Ở trong while, ta chỉ việc gọi tên các hàm đó. Code sẽ cực kỳ sạch sẽ!

3. Ví dụ minh họa (Gõ code cùng giáo viên)

Bước 1: Thiết kế các tính năng (def)

def xem():
print("Đang mở kho xem đồ...")
def them():
print("Đang nhét đồ mới vào kho...")

Mỗi tính năng gói vào một hộp hàm gọn gàng, không dính líu đến nhau. Dễ kiểm tra, dễ sửa lỗi.

Bước 2: Xây dựng Menu tổng điều khiển

while True:
print("\n--- MENU ---")
print("1. Xem  2. Thêm  3. Thoát")
chon = input("Mời chọn: ")
if chon == '1':

xem()

elif chon == '2':

them()

elif chon == '3':
break

Vòng lặp liên tục hiển thị Menu. Dùng if/elif để chuyển hướng. Gọi hàm tương ứng khi người dùng nhập số.

4. Lỗi thường gặp & Cách khắc phục

  • Lỗi: Gọi hàm bên dưới Menu báo NameError (Không tìm thấy hàm).
  • Cách sửa: Trong Python, em phải chế tạo máy (viết def) ở TRÊN CÙNG của file code, rồi mới được sử dụng nó (chạy vòng lặp while) ở BÊN DƯỚI. Nếu đảo ngược, Python không nhìn thấy.

5. Bài tập thực hành trên lớp

  1. Cấp độ 1: Viết 3 hàm siêu ngắn: def xin_chao(), def tam_biet(), def chui_mang(). Trong mỗi hàm chỉ cần dùng lệnh print một câu phù hợp.
  2. Cấp độ 2: Dựng một khung Menu while True hiển thị: "1. Khen, 2. Chửi, 3. Chào thoát".
  3. Cấp độ 3: Nối kết: Cài đặt điều kiện if/elif để khi người dùng gõ phím 1, máy gọi hàm xin_chao(), tương tự cho phím 2 và 3.

6. Bài tập về nhà

  • Máy ATM mini: Khởi tạo một biến so_du = 50000. Thiết kế một Menu ATM gồm 3 chức năng:
  1. Kiểm tra số dư (In ra so_du).
  2. Nạp tiền (Dùng input() hỏi số tiền nạp, ép kiểu int(), cộng vào so_du).
  3. Rút thẻ (Thoát chương trình).

7. Học sinh cần tự nói lại được gì?

  • "Phần mềm luôn chạy trong vòng lặp vô hạn while True để chờ mình ra lệnh."
  • "Mỗi tính năng của phần mềm phải được gói gọn vào một Hàm def để dễ quản lý."
