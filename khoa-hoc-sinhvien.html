Sinh viên CNTT / Kỹ thuật

Đang học tại HUST, UET, UIT, PTIT, HCMUT hoặc các trường kỹ thuật toàn quốc

Tôi có thể giúp bạn nếu…

  • Bị hổng kiến thức lập trình từ đầu, không theo kịp bài giảng trên lớp
  • Sắp thi lại môn C++, Java, Python hoặc môn Cấu trúc dữ liệu & Giải thuật
  • Đang làm đồ án môn học / tốt nghiệp nhưng không hiểu code mình đang viết
  • Cần debug gấp một lỗi khó hoặc hoàn thiện tính năng trước deadline
  • Muốn tự tin trình bày và bảo vệ đồ án trước hội đồng
  • Muốn học thêm Web/App để có portfolio xin việc sau tốt nghiệp

Tôi Có Thể Giúp Bạn Với

Từ môn học nền tảng đến dự án cuối khoá — tôi đồng hành theo từng bước cụ thể.

🖥️ Lập Trình Nền Tảng

Kỹ thuật lập trình C/C++, Python, Java. Từ cú pháp cơ bản đến con trỏ, đệ quy, cấu trúc file, OOP — học theo giáo trình thực tế của trường bạn đang học.

C/C++PythonJava Kỹ thuật lập trìnhOOP

🧩 Cấu Trúc Dữ Liệu & Giải Thuật

Linked List, Stack, Queue, Tree, Graph, Hash Table. Sắp xếp, tìm kiếm, BFS/DFS, Dijkstra, DP — giải thích từng dòng code cho đến khi bạn tự vẽ được sơ đồ tư duy.

DSALinked ListTree/Graph Dynamic Programming

🌐 Web & Cơ Sở Dữ Liệu

HTML/CSS/JS cơ bản, Node.js + Express REST API, ReactJS, MySQL / SQL Server / MongoDB. Thiết kế ERD, viết query, kết nối backend-frontend trong đồ án.

HTML/CSS/JSReactJSNode.js SQLMongoDB

🎓 Đồ Án Môn Học & Tốt Nghiệp

Đồng hành từ lúc chọn đề tài → phân tích → thiết kế DB → code từng tính năng → debug → viết báo cáo → luyện tập trả lời câu hỏi hội đồng. Bạn hiểu 100% hệ thống của mình.
