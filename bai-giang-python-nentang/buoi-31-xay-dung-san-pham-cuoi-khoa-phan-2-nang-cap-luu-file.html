Buổi 31: Xây dựng sản phẩm cuối khóa (Phần 2 - Nâng cấp & Lưu file)

Bài giảng chi tiết cho tiết học 90 phút: lý thuyết dễ hiểu, ví dụ code Python, lỗi thường gặp, thực hành trên lớp và bài tập về nhà.

Lý thuyếtDiễn giải bằng ngôn ngữ gần gũi cho học sinh mới học lập trình.
Code mẫuVí dụ Python 3 có giải thích từng bước, ưu tiên rõ ràng và dễ sửa.
Thực hànhBài tập trên lớp, bài tập về nhà và mục học sinh tự nói lại.

1. Mục tiêu bài học

  • Hoàn thành các tính năng tính toán logic phức tạp (Xóa đồ, Chiến đấu tính điểm, Đếm số câu đúng).
  • Tích hợp công nghệ JSON để dữ liệu của phần mềm có thể lưu lại trên máy tính người dùng mãi mãi.
  • Trang trí console để giao diện đẹp hơn (in thêm đường gạch ngang ---, khoảng trống chèn \n).

2. Hoạt động trên lớp

  • Khởi động tính năng JSON (10 phút): Giáo viên code mẫu lại một lần quy trình lưu file.
  1. Đầu file code: Đọc file data.json, loads() vào biến. Nếu chưa có file (lần đầu chơi) thì dùng try-except FileNotFoundError gán biến bằng rỗng [].
2. Chức năng thoát: dumps() biến và write vào file data.json.
  • Thực hành Tính năng Nâng cao (40 phút): Học sinh hoàn thiện các hàm logic còn lại.
  • Dự án Pokedex/Game: Viết hàm chiến đấu dựa vào sức mạnh và đổ xúc xắc ngẫu nhiên random.randint().
  • Dự án Siêu thị: Viết vòng lặp tính hóa đơn, hỏi khách mua bao nhiêu lượng, trừ đi trong Tồn Kho, cộng tiền vào Tổng.
  • Hoàn thiện & Trang trí (10 phút): Căn chỉnh lại nội dung in ra màn hình. Thay vì chỉ in "An 10 điểm", hãy in "👑 Học sinh xuất sắc: An - 10đ".

3. Chuẩn bị cho buổi bảo vệ

  • Giáo viên phát hướng dẫn Kịch bản Thuyết trình:
  1. Giới thiệu Bản thân và Tên Ứng dụng.
  2. Ứng dụng này sinh ra để giải quyết vấn đề gì? (Giúp học từ mới, hay để giải trí?).
  3. Demo chạy thử từ đầu đến cuối.
  4. Trình bày 1 đoạn Code mà mình tự hào nhất hoặc tốn nhiều công sức nhất để sửa lỗi.

4. Bài tập về nhà

  • Tập luyện Kịch bản thuyết trình ở nhà ít nhất 3 lần trước gương. Mở sẵn file code lên, kiểm tra lần cuối đảm bảo phần mềm chạy trơn tru không lỗi.
