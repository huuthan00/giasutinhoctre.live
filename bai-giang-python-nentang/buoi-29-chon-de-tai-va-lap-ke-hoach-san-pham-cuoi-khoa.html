Buổi 29: Chọn đề tài và lập kế hoạch sản phẩm cuối khóa

Bài giảng chi tiết cho tiết học 90 phút: lý thuyết dễ hiểu, ví dụ code Python, lỗi thường gặp, thực hành trên lớp và bài tập về nhà.

Lý thuyếtDiễn giải bằng ngôn ngữ gần gũi cho học sinh mới học lập trình.
Code mẫuVí dụ Python 3 có giải thích từng bước, ưu tiên rõ ràng và dễ sửa.
Thực hànhBài tập trên lớp, bài tập về nhà và mục học sinh tự nói lại.

1. Mục tiêu bài học

  • Học sinh tự chọn được đề tài phần mềm hoặc game phù hợp với khả năng trong số các dự án mẫu.
  • Rèn luyện kỹ năng phân tích: Phác thảo thiết kế, liệt kê tính năng (Features List).
  • Áp dụng Tư duy Máy tính để chia nhỏ dự án lớn thành các bước code nhỏ theo ngày.

2. Lý thuyết chi tiết

  • Quy trình làm Phần mềm (Agile cho lập trình viên nhí): Làm một dự án cuối khóa không phải là cắm cúi viết code 500 dòng. Ta phải làm theo quy trình: Ý tưởng -> Phác thảo giao diện -> Danh sách Tính năng -> Code từng tính năng một -> Test lỗi (Debug).
  • Các ý tưởng dự án phù hợp:
  • Dự án 1: Pokedex nâng cao: Quản lý Pokemon, chiến đấu tính điểm, lưu kết quả xuống file.
  • Dự án 2: Siêu thị mini: Quản lý kho hàng, giao diện tính tiền cho khách, in hóa đơn.
  • Dự án 3: Sổ tay Sinh từ (Flashcard): Phần mềm học từ vựng tiếng Anh. Thêm từ, kiểm tra từ ngẫu nhiên (random), thống kê điểm số.
  • Dự án 4: Game Text Adventure: Trò chơi phiêu lưu khám phá hầm ngục dựa trên văn bản, bốc thăm ngẫu nhiên quái vật, lưu lượng máu.

3. Các bước triển khai thực tế trên lớp

  • Bước 1: Giới thiệu (15 phút): Giáo viên chạy thử file Demo (mẫu) của 4 dự án trên để học sinh nhìn thấy thành phẩm và có cảm hứng.
  • Bước 2: Lựa chọn (5 phút): Học sinh chốt 1 đề tài (Không đổi lại sau buổi này).
  • Bước 3: Bản thiết kế (Thiết kế hệ thống) (25 phút): Giáo viên phát giấy hoặc yêu cầu dùng Word. Học sinh phải viết ra:
  • Dữ liệu chính: Mình sẽ dùng List hay Dictionary? Nếu Dictionary thì có những Nhãn nào?
  • Cấu trúc Menu: Sẽ có mấy số, hiển thị ra sao?
  • Các Hàm chức năng: Liệt kê tên các hàm def mình dự định viết.
  • Bước 4: Trình bày ý tưởng (15 phút): Mỗi học sinh nói nhanh 2 phút về phần mềm mình sẽ làm.

4. Bài tập về nhà

  • Khởi tạo Bộ khung: Em hãy mở máy tính ở nhà, tạo file du_an_cuoi_khoa.py. Xây dựng sẵn bộ khung chương trình bao gồm: Vòng lặp while True, in ra Menu Console, và các lựa chọn if/elif rỗng (bên trong chỉ ghi lệnh pass để chờ Buổi 30 lên lớp điền code vào).
